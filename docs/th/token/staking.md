# สเตกกิ้ง

สเตก $AGNT ในสัญญา `AGNTStaking` เพื่อรับ BNB จากค่าธรรมเนียมลอนช์แพด

- ผู้สเตกได้รับ **30% ของค่าธรรมเนียมเคิร์ฟทุกครั้ง** เป็น BNB
- BNB ทุกก้อนที่เข้ามาจะ **ทยอยจ่ายตลอด 7 วันถัดไป** แบ่งให้ทุกคนที่สเตกอยู่ในช่วงนั้น การสเตกก่อนการจ่ายไม่นาน
  ไม่ทำให้คว้ารางวัลไปได้
- BNB ที่เข้ามาขณะไม่มีใครสเตกจะรออยู่ และเริ่มทยอยจ่ายเมื่อผู้สเตกคนแรกเข้ามา
- ไม่มีการล็อก: ถอนสเตกได้ทุกเมื่อ เคลม BNB ได้ทุกเมื่อ

## สิทธิพิเศษ

AGNT ที่สเตกมา **อย่างน้อย 7 วัน** นับเป็นสิทธิพิเศษ การเพิ่ม AGNT จะเริ่มนับ 7 วันใหม่สำหรับทั้งตำแหน่ง จึงซื้อสิทธิพิเศษแค่ชั่วบล็อกเดียวไม่ได้

| สิทธิพิเศษ | เงื่อนไข |
| --- | --- |
| ลอนช์ฟรีบนลอนช์แพด | สเตก 100,000 AGNT เป็นเวลา 7 วัน |
| ครึ่งราคาที่โรงงานโทเคนมาตรฐาน | สเตก 100,000 AGNT เป็นเวลา 7 วัน |
| น้ำหนักโหวตบน Snapshot | AGNT ใดก็ได้ที่สเตกมา 7 วัน (`maturedStake`) |
| ตัวคูณแอร์ดรอปซีซัน 2 | ประกาศพร้อมซีซัน 2 |

เกณฑ์นี้ Safe ของเจ้าของเปลี่ยนได้ ทุกการเปลี่ยนแปลงเปิดเผยที่
[Site integrity](https://agenticstarter.xyz/integrity?lang=th)

สเตกกิ้งเปิดพร้อมการลิสต์ $AGNT

| ฟังก์ชัน | ผล |
| --- | --- |
| `stake(amount)` | ฝาก AGNT (approve ก่อน) |
| `unstake(amount)` | ถอน AGNT รางวัลยังอยู่ |
| `claim()` | ถอน BNB ที่สะสม |
| `pendingBnb(address)` | ดู BNB ที่สะสม |
| `maturedStake(address)` | AGNT ที่นับเป็นสิทธิพิเศษและการโหวต |
| `hasPerks(address)` | เป็นจริงเมื่อเกินเกณฑ์สิทธิพิเศษ |
