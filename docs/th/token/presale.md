# พรีเซล

เข้าร่วมที่ [presale.agenticstarter.xyz](https://presale.agenticstarter.xyz?lang=th) ด้วยวอลเล็ตบนเบราว์เซอร์ที่รองรับ BNB Chain ไม่ต้อง KYC
ไม่ต้องใช้อีเมล ใช้แค่วอลเล็ต เป็นรอบสาธารณะรอบเดียวที่ **ราคาเดียวสำหรับทุกคน**

::: warning ซื้อบนหน้าพรีเซลเท่านั้น
ห้ามส่ง BNB ให้ใคร และห้ามส่งไปที่ที่อยู่สัญญาโดยตรง: การโอนธรรมดาจะถูกปฏิเสธ แอดมินไม่ทักก่อนเด็ดขาด
เทียบที่อยู่สัญญากับ [Site integrity](https://agenticstarter.xyz/integrity?lang=th)
:::

## BNB ของคุณได้รับการปกป้องอย่างไร

1. BNB ของคุณอยู่ในสัญญาพรีเซล ทีมถอนไม่ได้ก่อนการขายจบ
2. ต่ำกว่าซอฟต์แคป การขายล้มเหลวและผู้ซื้อทุกคนขอคืน 100% ได้บนหน้าพรีเซล
3. หลังการขาย 80% ของ BNB จะเข้าพูล PancakeSwap ตอนลิสต์ และ LP ถูกเบิร์น ทุกขั้นตอนมีลิงก์บนเช็กลิสต์การลิสต์ของหน้าพรีเซล
   ดู [การลิสต์](/th/token/listing)

## ชวนเพื่อน

เชื่อมต่อวอลเล็ตในหน้าพรีเซลเพื่อรับลิงก์ชวน (`presale.agenticstarter.xyz/?ref=<วอลเล็ตของคุณ>`) เมื่อมีคนซื้อผ่านลิงก์นี้
สัญญาพรีเซลจะบันทึกการชวนไว้พร้อมการซื้อ (`contributeWithRef`) ผู้ซื้อไม่ต้องจ่ายเพิ่ม และยอดจัดสรรไม่เปลี่ยน

- ทุกกระเป๋าที่ซื้อ 0.05 BNB ขึ้นไปผ่านลิงก์ของคุณเพิ่ม **100 แต้มแอร์ดรอป** (เควสต์ Q6 สูงสุด 50 คน)
- การร่วมพรีเซลเองคือเควสต์ Q5: ตั้งแต่ 0.05 BNB **+500 แต้ม** จากนั้น +100 ทุก 0.01 BNB (สูงสุด 10,000) และซื้อใน 48
  ชั่วโมงแรกได้เพิ่ม **500** ซื้อด้วยกระเป๋าที่ไม่ใช่กระเป๋าแอร์ดรอป? เชื่อมครั้งเดียวในหน้าแอร์ดรอป (การ์ด Q5)
- แต้มจะนับเมื่อวอลเล็ตของคุณทำภารกิจบังคับทั้งสามของแอร์ดรอปครบ
- ซื้อผ่านลิงก์ตัวเองไม่นับ และการซื้อที่ถูกคืนเงินจะถูกหักออก

## หลังการขาย

1. **สรุปการขาย**: BNB เข้า Treasury Safe และ AGNT ที่ขายไม่หมดถูกเบิร์น
2. **ลิสต์** วันถัดไปเวลา 14:00 UTC: 80% ของ BNB เข้าพูล AGNT/BNB ที่ราคาพรีเซลสุดท้าย LP ถูกเบิร์น แล้วจึงเปิดเคลม
3. คุณเคลม AGNT 100% (และโบนัสช่วงแรก) ได้ที่หน้าพรีเซล

แต่ละขั้นตอนจะถูกติ๊กบนเช็กลิสต์การลิสต์ของหน้าพรีเซลพร้อมลิงก์ไปยังธุรกรรม เปิดการแจ้งเตือนที่นั่น (Telegram หรือปฏิทิน)
เพื่อรู้ว่าเมื่อไรเปิดเคลม

## การคืนเงิน

การร่วมพรีเซลถือเป็นที่สิ้นสุด ยกเว้นสองกรณี:

- **การขายล้มเหลว**: จบลงต่ำกว่าซอฟต์แคป การคืนเงินจะเปิดอัตโนมัติ
- **ทีมเปิดโหมดคืนเงิน** ก่อนเปิดเคลม หากเกิดหลังสรุปการขายแล้ว ทีมต้องส่งเงินทั้งหมดกลับเข้าสัญญาพรีเซลก่อน เพื่อให้ผู้ซื้อทุกคนได้รับ
  เงินคืนเต็มจำนวน

ทั้งสองกรณี คุณขอคืน BNB 100% ได้ที่หน้าพรีเซล
