## คำมั่นเรื่องการล็อก

| การจัดสรร | กฎ |
| --- | --- |
| ทีม (120M) | สัญญาเวสติ้ง: คลิฟ 12 เดือน แล้วทยอยปลดเชิงเส้น 24 เดือน เจ้าของเลื่อนวันเริ่มได้เท่านั้น |
| คลังและอีโคซิสเต็ม | ไม่ขายในตลาดก่อนลิสต์ + 6 เดือน |
| สภาพคล่อง (Liquidity Safe) | ใช้เฉพาะกับพูลและการลิสต์ |
| คอมมูนิตี้ (Community Safe) | ใช้เฉพาะกับแอร์ดรอปและโบนัสผู้ซื้อพรีเซลช่วงแรก |

หาก Safe ใดของโปรเจกต์ย้าย AGNT ไปยังคู่เทรดบน DEX เราเตอร์ หรือที่อยู่ฝากของกระดานเทรดที่รู้จัก จะมีการแจ้งเตือนสาธารณะในช่อง
และกลุ่ม Telegram โดยอัตโนมัติ

## ตรวจสอบได้ด้วยตัวเอง

- [Liquidity proof](https://agenticstarter.xyz/liquidity?lang=th): ที่อยู่พูล สำรองสด และธุรกรรมเบิร์น LP อ่านจากเชนโดยตรง
- เช็กลิสต์การลิสต์ของหน้าพรีเซล: สรุปการขาย → เพิ่ม BNB เข้าพูล → เบิร์น LP → เปิดเคลม แต่ละขั้นมีธุรกรรมกำกับ
- [ที่อยู่ Safe](https://agenticstarter.xyz/integrity?lang=th) พร้อมทุกการเปลี่ยนพารามิเตอร์
