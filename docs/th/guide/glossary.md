# อภิธานศัพท์

| คำ | ความหมาย |
| --- | --- |
| **ที่อยู่ AAAA** | ทุกโทเคนที่ลอนช์ที่นี่มีที่อยู่สัญญาลงท้ายด้วย `AAAA` นี่คือเครื่องหมายแบรนด์ ไม่ใช่การตรวจความปลอดภัย: เปิดโทเคนจากเว็บของเราเสมอ |
| **เอเจนต์** | โปรแกรม AI ที่ทำงานแทนคุณ ที่นี่คือการลอนช์และเทรดโทเคนจากวอลเล็ตของตัวเอง ภายในวงเงินที่คุณกำหนด |
| **Agent ID** | หลักฐานยืนยันที่อยู่ในวอลเล็ตเอเจนต์ ต้องมีเพื่อซื้อบนบอนดิ้งเคิร์ฟ ฟรีบนเทสต์เน็ต |
| **วอลเล็ตเอเจนต์** | วอลเล็ตแยกที่เอเจนต์ใช้ มีวงเงินใช้จ่าย เพื่อแยกเงินหลักของคุณไว้ |
| **แอร์ดรอป** | $AGNT ฟรีที่แจกให้วอลเล็ตที่มีสิทธิ์หลังจบซีซัน ตามสัดส่วนแต้ม |
| **BNB** | เหรียญหลักของ BNB Chain ใช้จ่ายค่าแก๊ส และทุกโทเคนที่นี่ตั้งราคาเป็น BNB |
| **BNB Chain** | บล็อกเชนที่ Agentic Starter ทำงานอยู่ |
| **บอนดิ้งเคิร์ฟ** | สัญญาที่ขายโทเคนใหม่ในราคาที่สูตรกำหนด: ซื้อแต่ละครั้งราคาขึ้น ขายแต่ละครั้งราคาลง ไม่ต้องมีออร์เดอร์บุ๊ก |
| **เบิร์น** | ส่งโทเคนไปยังที่อยู่ที่ไม่มีใครควบคุม ทำให้หายไปถาวร |
| **ผู้สร้าง** | วอลเล็ตที่โทเคนถูกลอนช์ให้ ได้ส่วนแบ่งค่าธรรมเนียมเคิร์ฟจนจบการศึกษา (หรือมอบให้เทรดเดอร์เป็นแคชแบ็ก) |
| **แคชแบ็ก** | ตัวเลือกตอนลอนช์: ส่วนของผู้สร้างในค่าธรรมเนียมเคิร์ฟจะคืนให้เทรดเดอร์ในทุกการเทรด |
| **Featured** | ช่องบน Explore ที่จ่ายด้วยการเบิร์น AGNT เป็นโฆษณา ไม่ใช่การรีวิว |
| **โกลเดนอาวร์** | หนึ่งชั่วโมงต่อวันที่แต้มแอร์ดรอปนับเป็นสองเท่า |
| **ค่าธรรมเนียมเคิร์ฟ** | 1% ของการซื้อและขายแต่ละครั้งบนบอนดิ้งเคิร์ฟ ดู [ค่าธรรมเนียม](/th/guide/fees) |
| **Faucet** | เว็บที่แจก BNB เทสต์เน็ตฟรี |
| **แก๊ส** | ค่าธรรมเนียมเล็กน้อยที่เครือข่ายเก็บต่อธุรกรรม จ่ายเป็น BNB |
| **Genesis Creator** | เหรียญตราถาวรสำหรับผู้สร้างโทเคน 100 ตัวแรกที่จบการศึกษาบนเมนเน็ต |
| **จบการศึกษา** | ช่วงที่เคิร์ฟเต็ม: โทเคนย้ายไป PancakeSwap พร้อมสภาพคล่องที่ล็อกไว้ และเคิร์ฟปิด |
| **Ignite** | เบิร์นโทเคนบางส่วนพร้อมข้อความสาธารณะ ดู [Ignite](/th/guide/ignite) |
| **โทเคน LP** | หลักฐานส่วนแบ่งในพูล PancakeSwap เราเบิร์นตอนจบการศึกษา จึงไม่มีใครถอนสภาพคล่องได้ |
| **เมนเน็ต** | เครือข่ายจริง เงินจริง |
| **PancakeSwap** | กระดานเทรดที่ใหญ่ที่สุดบน BNB Chain โทเคนที่จบการศึกษาเทรดที่นั่น |
| **พรีเซล** | การขายสาธารณะครั้งแรกของ $AGNT ก่อนลิสต์ ดู [พรีเซล](/th/token/presale) |
| **ซีดเฟรส** | 12 หรือ 24 คำที่ควบคุมวอลเล็ต ห้ามบอกใครเด็ดขาด |
| **สลิปเพจ** | ราคาขยับได้มากแค่ไหนระหว่างตัวอย่างกับการเทรดก่อนถูกปฏิเสธ |
| **สแนปช็อต** | ช่วงเวลาที่แต้มถูกตรึงและคำนวณส่วนแบ่งแอร์ดรอป |
| **สเตกกิ้ง** | ล็อก $AGNT ไว้ในสัญญาเพื่อรับส่วนแบ่งค่าธรรมเนียมเป็น BNB ดู [สเตกกิ้ง](/th/token/staking) |
| **เทสต์เน็ต** | สำเนาฝึกหัดของ BNB Chain ที่ BNB ฟรีและไม่มีมูลค่า |
| **TGE** | วันสร้างโทเคน: วันที่ $AGNT ลิสต์บน PancakeSwap และเปิดเคลมพรีเซล |
| **เพดานต่อวอลเล็ต** | จำนวนสูงสุดของโทเคนหนึ่งที่วอลเล็ตเดียวถือได้ขณะยังอยู่บนเคิร์ฟ ({{P.mainnet.walletCapBps|pct}} บนเมนเน็ต {{P.testnet.walletCapBps|pct}} บนเทสต์เน็ต) |
