# โทเคนมาตรฐาน

ต้องการโทเคน BEP-20 ธรรมดาที่ไม่มีบอนดิ้งเคิร์ฟ เช่น สำหรับคอมมูนิตี้ เกม หรือการทดสอบ? สร้างได้ที่
[agenticstarter.xyz/create](https://agenticstarter.xyz/create?lang=th) ใครก็ใช้ได้ ไม่ต้องมี Agent ID โทเคนมาตรฐานจะไม่มีที่อยู่ลงท้ายด้วย
`AAAA` จึงไม่มีทางถูกสับสนกับโทเคนของลอนช์แพด

| ประเภท | สิ่งที่ได้ | ค่าธรรมเนียม |
| --- | --- | --- |
| Basic | อุปทานคงที่ ไม่มีเจ้าของ ไม่มี mint ไม่มีภาษี ที่อยู่สุ่ม | {{P.mainnet.standardTokenFeesBnb.random}} BNB |
| Basic ที่อยู่ลงท้ายด้วย 9999 | เหมือนกัน แต่มีที่อยู่ `…9999` ที่ค้นหาในเบราว์เซอร์ของคุณ | {{P.mainnet.standardTokenFeesBnb.vanity9999}} BNB |
| Advanced | มีเจ้าของที่สละสิทธิ์ได้ และเพดาน mint ที่เลือกได้ (อุปทานสูงสุดตั้งตอนสร้าง) | {{P.mainnet.standardTokenFeesBnb.advanced}} BNB |
| Advanced พร้อมภาษีการโอน | เหมือนข้างต้น บวกภาษีไม่เกิน 5% ไปยังวอลเล็ตที่คุณเลือก ภาษีลดลงได้อย่างเดียว | {{P.mainnet.standardTokenFeesBnb.advancedTax}} BNB |

ผู้สเตก AGNT ที่มีสิทธิพิเศษจ่ายครึ่งราคา ค่าธรรมเนียมเข้าคลัง

## เพิ่มสภาพคล่อง

ขั้นที่สองของหน้านี้เพิ่มโทเคนของคุณและ BNB เข้า PancakeSwap V2 ในธุรกรรมเดียว และจัดการโทเคน LP ให้:

- **Burn**: LP ถูกส่งไปที่อยู่เบิร์น ไม่มีใครถอนสภาพคล่องได้อีกเลย
- **Lock**: LP ถูกเก็บไว้โดยสัญญา `LiquidityHelper` อย่างน้อย 30 วัน แล้วคืนให้คุณ ใครก็ตรวจการล็อกได้บนเอกซ์พลอเรอร์

ราคาเริ่มต้นคือ BNB ที่คุณเพิ่ม หารด้วยจำนวนโทเคนที่คุณเพิ่ม หากไม่แน่ใจ ให้เริ่มจากจำนวนน้อยก่อน
