# ตั้งค่าวอลเล็ตเอเจนต์

คุณต้องมีสามอย่าง: วอลเล็ตแบบเอเจนติก Agent ID บนวอลเล็ตนั้น และ BNB เล็กน้อย

1. **สร้างวอลเล็ตแบบเอเจนติก** ในแอปวอลเล็ตที่รองรับเอเจนต์ AI เป็นวอลเล็ตย่อยแยกต่างหาก ไม่มีคีย์เปิดเผย และมียอดเงิน
   ของตัวเอง เงินหลักของคุณจึงแยกออกจากกัน
2. **ตั้งค่าการป้องกัน:** วงเงินใช้จ่ายรายวัน โทเคนที่เอเจนต์เทรดได้ และวิธียืนยันธุรกรรมที่มีความเสี่ยง เปิดการลงนาม
   อัตโนมัติเพื่อให้เอเจนต์ทำงานได้ภายในขีดจำกัดเหล่านั้น
3. **รับ Agent ID** สำหรับวอลเล็ตนั้น ลอนช์แพดจะตรวจสอบออนเชนทุกครั้งที่ซื้อบนเคิร์ฟ
4. **เติม BNB** สำหรับค่าแก๊สและการซื้อ (0.05 BNB ก็พอสำหรับเริ่มต้น)
5. **ติดตั้งสกิลและ CLI** ให้เอเจนต์:

```bash
npx skills add agenticstarter/agentic-starter-agnt/skill
npm i -g @agenticstarter/cli
```

6. **เชื่อมต่อผู้ลงนาม** ตั้งให้ CLI ใช้คำสั่งลงนามของวอลเล็ตคุณ (ดู [ผู้ลงนาม](/agents/signers))
7. **ตรวจสอบ:** ให้เอเจนต์รัน `agentic preflight` รายการที่ไม่ผ่านจะบอกวิธีแก้ไขไว้

คุณยังวางแอดเดรสวอลเล็ตใน [Agent check](https://agenticstarter.xyz/check?lang=th) เพื่อดูสถานะ Agent ID และสินทรัพย์ที่ถือได้ด้วย

::: warning
ห้ามให้ซีดเฟรสของวอลเล็ตหลักกับเอเจนต์เด็ดขาด ใช้วอลเล็ตเอเจนต์เฉพาะที่มีการจำกัดวงเงิน
:::
