# คอมมูนิตี้ Telegram

| ที่ไหน | ลิงก์ | ใช้ทำอะไร |
| --- | --- | --- |
| ช่อง | [t.me/agenticstarter](https://t.me/agenticstarter) | ประกาศเท่านั้น |
| กลุ่ม | [t.me/agentic_starter](https://t.me/agentic_starter) | แชต ควิซรายวัน ถาม Agen |
| Agen (บอท) | [t.me/agenticstarter_bot](https://t.me/agenticstarter_bot) | มินิแอปแอร์ดรอป การแจ้งเตือน การลอนช์บนเทสต์เน็ต |

## เข้ากลุ่ม

สมาชิกใหม่ต้องกด **I'm not a bot** ในข้อความต้อนรับก่อนจึงจะพิมพ์ได้ ข้อความต้อนรับและข้อความเข้ากลุ่มจะถูกลบหลังผ่านไปครู่หนึ่ง
เพื่อให้แชตสะอาด

## ถาม Agen

เขียน `@Agen` ตรงไหนก็ได้ในข้อความของคุณในกลุ่ม เช่น `@Agen การจบการศึกษาทำงานอย่างไร?` Agen ตอบเป็นภาษาของคุณจากเอกสารนี้และข้อมูลสด คำถามเรื่องโปรเจกต์ตอบเฉพาะในกลุ่มเพื่อให้ทุกคนเห็น ส่วนในแชตส่วนตัวช่วยเรื่องของคุณเอง (เปิดตัวโทเคน แต้ม การเตือน)

Agen ไม่ตอบคำถามที่อาจทำให้คุณหรือโปรเจกต์เสี่ยง (คีย์ ซีดเฟรส วิธีโจมตีสัญญา) หรือคำถามที่ไม่เกี่ยวกับ Agentic Starter
คำถามที่ถูกถามบ่อยจะได้ลิงก์ไปยังหน้าเอกสารที่ตรงกัน

## คำสั่ง

| คำสั่ง | ที่ไหน | ทำอะไร |
| --- | --- | --- |
| `@Agen <คำถาม>` | กลุ่ม | ถาม Agen (`/agen` ก็ได้) |
| `/points` | ส่วนตัว | แต้มแอร์ดรอปของคุณและสิ่งที่ยังขาด |
| `/earn` | กลุ่มหรือแชทส่วนตัว | สิ่งที่ยังทำได้เพื่อแต้ม เรียงจากมากที่สุด |
| `/challenge` | กลุ่มหรือส่วนตัว | ภารกิจวันนี้และสตรีคของคุณ |
| `/help` | กลุ่มหรือส่วนตัว | คำสั่งทั้งหมด |
| `/watch <token>` | ส่วนตัว | ข้อความแจ้งที่ 80%, 90% และตอนจบการศึกษา |
| `/remind presale` · `claim` · `mainnet` | ส่วนตัว | ข้อความแจ้งเมื่อเปิด |
| `/report` | ตอบกลับข้อความในกลุ่ม | รายงานสแกมหรือแอดมินปลอมให้ทีม |
| `/launch <code>` | ส่วนตัว | ลอนช์บนเทสต์เน็ตจากเว็บไซต์ (ดู [ลอนช์โทเคน](/th/guide/launch#testnet-telegram)) |
| `/faucet` | ส่วนตัว | ที่รับ BNB ทดสอบ (หน้าแอร์ดรอปเติมให้ได้หนึ่งครั้งหลังทำ Q2) |
| `/settings` | แชตส่วนตัว | เลือกข้อความส่วนตัวที่ Agen ส่งให้คุณ: กล่อง การแจ้งเตือนควิซ สรุป และอื่น ๆ |
| `/agentid` | ส่วนตัว | ตรวจ Agent ID |

ทุกข้อความส่วนตัวจาก Agen มีปุ่ม **ปิดข้อความแบบนี้** เปิดใหม่ได้ทุกเมื่อด้วย `/settings`

## กฎของกลุ่ม

- ใจดีต่อกัน ห้ามด่าทอ ห้ามปั่น FUD ห้ามสแปม ห้ามโปรโมตโปรเจกต์อื่น
- ลิงก์: เฉพาะลิงก์ทางการ (ดู [ปลอดภัยไว้ก่อน](/th/guide/safety)) ลิงก์อื่นจะถูกลบ
- สไตรก์: การด่าทอรุนแรงได้สไตรก์ทันที ส่วนการล่วงเกินเบา ๆ ที่ทำซ้ำได้หลังถูกเตือน **5 สไตรก์** ใน 20 วันหมายถึงถูกแบน สไตรก์หมดอายุใน 20 วัน
- แอดมินไม่ทักก่อนและไม่ขอคีย์ ซีดเฟรส หรือ BNB เด็ดขาด
- ชื่อที่เลียนแบบทีม (admin, support, Agentic Starter, Agen) จะถูกปิดการพิมพ์ และข้อความ "DM มา" ขอ seed phrase หรือ "ยืนยันกระเป๋า" จะถูกลบ

หากคิดว่าการดำเนินการของผู้ดูแลไม่ถูกต้อง ให้เขียนถึงแอดมินในกลุ่ม
