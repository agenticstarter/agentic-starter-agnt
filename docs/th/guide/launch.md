# ลอนช์โทเคน

บอกเอเจนต์ว่าจะลอนช์อะไร ตรวจตัวอย่าง แล้วอนุมัติ แค่นั้นเอง

```text
Launch a token on Agentic Starter: name "Nova Agent", symbol NOVA, description "Scouts fresh launches",
logo https://…/nova.png, X @nova_agent, and buy 0.2 BNB of it in the same transaction.
Show me the preview first and wait for my OK.
```

เอเจนต์จะรัน:

```bash
agentic create --name "Nova Agent" --symbol NOVA \
  --description "Scouts fresh launches" --logo https://…/nova.png --twitter @nova_agent \
  --telegram https://t.me/nova_agent --buy 0.2
agentic execute --request-id <id>
```

ก่อนแสดงตัวอย่าง CLI จะค้นหา salt ที่ทำให้ที่อยู่โทเคนลงท้ายด้วย `AAAA` ใช้เวลาไม่กี่วินาที

บนเว็บ ฟอร์มลอนช์มีสามขั้นตอน พิมพ์หนึ่งประโยคเกี่ยวกับไอเดียของคุณแล้วกด **Fill it in** เพื่อได้ชื่อ สัญลักษณ์ และคำอธิบายที่แก้ไขได้
จากนั้นลากโลโก้ใส่: โลโก้จะถูกปักไว้บน IPFS และพรอมต์ใช้ลิงก์ `ipfs://` (ใน CLI ใช้ `--logo ./nova.png` ได้เหมือนกัน)
แล้วเลือกว่าค่าธรรมเนียมผู้สร้างจะไปที่ไหน ตรวจการ์ดตัวอย่าง และคัดลอกพรอมต์ไปให้เอเจนต์ของคุณ ตัวจำลองเคิร์ฟแสดงราคาและมูลค่าตลาด
ในแต่ละช่วง

| ช่อง | ข้อจำกัด |
| --- | --- |
| ชื่อ | 1–32 ตัวอักษร |
| สัญลักษณ์ | ตัวพิมพ์ใหญ่หรือตัวเลข 2–10 ตัว สัญลักษณ์อย่าง AGNT, BNB, BTC, ETH, USDT, USDC และ CAKE ถูกสงวนไว้ |
| ระบบตัวอักษรของชื่อและสัญลักษณ์ | หนึ่งชื่อใช้ได้ระบบตัวอักษรเดียว ตัวอักษรหน้าตาคล้ายจากระบบอื่นจึงถูกปฏิเสธ |
| เมทาดาทา (คำอธิบาย URL โลโก้ ลิงก์) | เก็บบนเชน สูงสุดราว 1 KB |
| โลโก้ | URL `https://` / `ipfs://` หรือไฟล์ PNG, JPG, GIF, WebP ในเครื่องไม่เกิน 1 MB (อัปโหลดขึ้น IPFS) |
| การซื้อครั้งแรก | ไม่บังคับ ต้องมี Agent ID ใช้เพดานต่อวอลเล็ต |
| X | ลิงก์หรือ `@handle` (เก็บเป็นแฮนเดิล) |
| Telegram | ลิงก์ `t.me` เท่านั้น |
| ค่าลอนช์ | {{P.mainnet.launchFeeBnb}} BNB บนเมนเน็ต ฟรีบนเทสต์เน็ตและสำหรับผู้สเตก AGNT ที่มีสิทธิพิเศษ บวกค่าแก๊ส |
| คู่เทรด | BNB คู่อื่นจะมาภายหลัง |

โทเคนไม่มีภาษี ไม่มีฟังก์ชัน mint และไม่มีเจ้าของ

## ค่าธรรมเนียมผู้สร้างไปที่ไหน

| ตัวเลือก | CLI | เว็บไซต์ |
| --- | --- | --- |
| วอลเล็ตที่ใช้ลอนช์ (ค่าเริ่มต้น) | — | เว้นช่องวอลเล็ตรับค่าธรรมเนียมไว้ว่าง |
| วอลเล็ตอื่น | `--fee-to 0xWallet:100` | ช่อง **Creator fee wallet** |
| แบ่งให้ได้สูงสุด 10 ผู้รับ | `--fee-to 0xA:60,0xB:40` | ตั้งที่ My tokens หลังลอนช์ |
| บัญชี X หรือ GitHub | `--fee-to 0xA:80,x:@alice:20` | ตั้งที่ My tokens หลังลอนช์ |
| แคชแบ็กให้เทรดเดอร์ | `--cashback` | **Reward mode → Cashback** |

ส่วนแบ่งของบัญชีจะรออยู่ในเอสโครว์จนกว่าเจ้าของบัญชีจะพิสูจน์ความเป็นเจ้าของและผูกวอลเล็ต ส่วนที่ไม่มีใครเคลมจะกลับไปที่ผู้สร้าง
หลัง 90 วัน การเปลี่ยนการแบ่งมีผล 24 ชั่วโมงหลังเสนอ ดู [ค่าธรรมเนียม](/th/guide/fees#creator-fee-options)

## เทสต์เน็ต: ลอนช์ด้วยบอท Telegram {#testnet-telegram}

บน BNB Chain เทสต์เน็ต คุณลอนช์ได้โดยไม่ต้องตั้งค่าเอเจนต์ บอท Agen ทำหน้าที่เป็นเอเจนต์และจ่ายแก๊สให้ วอลเล็ตของคุณถูกบันทึก
เป็นผู้สร้าง

1. เปิด [Launch](https://agenticstarter.xyz/launch?lang=th) เชื่อมวอลเล็ตที่จะเป็นเจ้าของโทเคน แล้วกรอกชื่อ สัญลักษณ์ โลโก้ คำอธิบาย
   และลิงก์
2. กด **Open in Telegram** บอทจะเปิดพร้อมรหัสลอนช์และแสดงตัวอย่าง
3. แตะ **🚀 Launch now** ไม่กี่วินาทีต่อมาบอทจะตอบกลับพร้อมที่อยู่โทเคน และโทเคนจะปรากฏในหน้า Explore

ถ้า Telegram ไม่เปิด ให้คัดลอกบรรทัด `/launch ABCD2345` จากหน้าเว็บส่งให้บอท รหัสใช้ได้ 24 ชั่วโมงและใช้ได้ครั้งเดียว แต่ละบัญชี
Telegram ลอนช์ได้สูงสุดวันละ 3 โทเคน

บอทไม่ซื้อแทนคุณ หากต้องการซื้อ ให้เปิดหน้าโทเคน รับ Agent ID เทสต์เน็ตฟรี แล้วซื้อด้วย BNB ทดสอบ บนเทสต์เน็ตโทเคนจบการศึกษา
ที่ **{{P.testnet.graduationTargetBnb}} BNB**

## หลังลอนช์

หน้าลอนช์จะแสดง **ชุดเครื่องมือหลังลอนช์**: โพสต์ X สำเร็จรูป ข้อความ Telegram รูปสำหรับแชร์ และวิดเจ็ตฝังในเว็บของคุณ ที่
[My tokens](https://agenticstarter.xyz/me?lang=th) คุณทำได้ดังนี้:

| การทำงาน | รายละเอียด |
| --- | --- |
| ติดตามความคืบหน้า | ความคืบหน้าเคิร์ฟ BNB ที่ระดมได้ ผู้ถือ |
| เคลมรางวัลผู้สร้าง | 20% ของค่าธรรมเนียมเคิร์ฟทุกครั้งบนโทเคนของคุณ เป็น BNB จนจบการศึกษา บวกโบนัสจบการศึกษา |
| อัปเดตข้อมูล | เปลี่ยนโลโก้ คำอธิบาย และลิงก์ด้วย {{P.mainnet.metaUpdateFeeBnb}} BNB บนเมนเน็ต ชื่อและสัญลักษณ์ไม่มีวันเปลี่ยน ผู้ถือเห็นประกาศ 7 วัน และประวัติทั้งหมดเปิดเผยเสมอ |
| การแบ่งค่าธรรมเนียม | เสนอการแบ่งใหม่ จะมีผลหลัง 24 ชั่วโมง |
| โอนสิทธิ์ผู้สร้าง | เสนอวอลเล็ตผู้สร้างใหม่ วอลเล็ตนั้นรับช่วงเมื่อกดยอมรับบนหน้าโทเคน รางวัลที่ได้แล้วยังเป็นของคุณและเคลมได้ |
| ส่วนจัดสรรของผู้สร้าง | ในที่ที่ใช้ (ตอนนี้คือเทสต์เน็ต) เคลมส่วนที่ปลดล็อกแล้วหลังจบการศึกษา |
| ยืนยัน X | ผูกบัญชี X เพื่อแสดงเหรียญตราผู้สร้างที่ยืนยันแล้วบนหน้าโทเคน |

ผู้สร้างโทเคน 100 ตัวแรกที่จบการศึกษาบนเมนเน็ตจะได้รับเหรียญตรา **Genesis Creator** ถาวร
