# ติดตั้งแอปบนมือถือ

Agentic Starter ใช้งานบนมือถือได้เหมือนแอป: เต็มหน้าจอ มีแท็บด้านล่าง แตะครั้งเดียวจากหน้าจอหลัก
เป็นตัวเว็บไซต์เอง จึงไม่ต้องอัปเดตและไม่ต้องใช้สโตร์ กระเป๋าของคุณยังถามก่อนการลงนามทุกครั้ง

## iPhone และ iPad

1. เปิด [agenticstarter.xyz](https://agenticstarter.xyz?lang=th) ใน **Safari** ถ้าอยู่ใน Telegram, X หรือแอปกระเป๋า
   ให้เปิดหน้าใน Safari ก่อน เพราะเบราว์เซอร์อื่นบน iPhone อาจเพิ่มเว็บแอปไม่ได้
2. แตะ **แชร์** (สี่เหลี่ยมมีลูกศร) ในแถบของ Safari ถ้าไม่เห็น ให้แตะ **⋯** ก่อน
3. แตะ **เพิ่มไปยังหน้าจอโฮม** แล้วแตะ **เพิ่ม**
4. เปิด Agentic Starter จากหน้าจอหลัก

## Android

### Chrome

1. เปิด [agenticstarter.xyz](https://agenticstarter.xyz?lang=th) ใน **Chrome** ถ้าลิงก์เปิดอยู่ใน Telegram, X หรือแอปกระเป๋า
   ให้แตะ **⋮** ที่มุมขวาบนแล้วเลือก **เปิดใน Chrome** ก่อน เพราะติดตั้งแอปจากตรงนั้นไม่ได้
2. แตะ **⋮** ที่มุมขวาบนของ Chrome
3. แตะ **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก** แล้วแตะ **ติดตั้ง**
4. เปิด Agentic Starter จากหน้าจอหลักหรือรายการแอป

ถ้า Chrome แสดงปุ่ม **ติดตั้ง** บนหน้าเว็บหรือในแถบที่อยู่ แตะปุ่มนั้นก็ได้ผลเหมือนกัน

### Samsung Internet

1. แตะ **☰** ด้านล่าง
2. แตะ **เพิ่มหน้าไปยัง** แล้วเลือก **หน้าจอหลัก**

### ไฟล์แอป (APK)

อยากใช้ไฟล์ติดตั้ง? [ดาวน์โหลด agentic-starter.apk](https://agenticstarter.xyz/download/agentic-starter.apk?lang=th) (เวอร์ชัน 1.0, 1.7 MB) แอปจะเปิดเว็บเดียวกันแบบเต็มหน้าจอผ่าน Chrome และ Android จะถามหนึ่งครั้งว่าอนุญาตให้ติดตั้งจากเบราว์เซอร์หรือไม่ ตรวจสอบไฟล์ก่อนติดตั้ง:

- SHA-256 ของไฟล์: `be55ac38090acbcf8ddcbf732463176306ad6a10365d9402b63fac81cd135479`
- SHA-256 ของใบรับรองการลงนาม: `A2:7C:83:5E:EE:EF:C6:39:0B:CC:79:77:53:29:DD:84:7D:E2:6D:47:93:1E:2A:A5:66:D2:86:76:AD:E9:A7:5B`

## ในแอป

- **ภาษา:** แตะรูปของคุณที่มุมซ้ายบนเพื่อเปิดเมนู แล้วไปที่ **การตั้งค่า → ภาษา** เพื่อเลือกจากรายการ
- **ล็อกแอป:** **การตั้งค่า → ล็อกแอป** จะขอ Face ID ลายนิ้วมือ รหัสผ่านเครื่อง หรือรหัสผ่านของคุณเองก่อนเปิดแอป
  การล็อกเก็บไว้บนมือถือของคุณเท่านั้น
- **อวาตาร์:** แตะรูปของคุณในเมนูเพื่อเลือกรูปหรือสี เก็บไว้บนมือถือเท่านั้น ไม่มีการอัปโหลด

## คำถาม

**ไม่เห็นติดตั้งแอป** อัปเดต Chrome จาก Play Store แล้วโหลดหน้าใหม่ ถ้าติดตั้งแล้ว เมนูเดียวกันจะแสดง **เปิดแอป** แทน

**ปลอดภัยไหม** เป็นเว็บเดียวกับ agenticstarter.xyz และเข้าถึงคีย์ของกระเป๋าไม่ได้ ทุกธุรกรรมจะเปิดกระเป๋าให้คุณอนุมัติ
ติดตั้งจาก agenticstarter.xyz เท่านั้น ทีมงานไม่เคยส่งไฟล์หรือลิงก์แอปทางข้อความส่วนตัว

**ลบอย่างไร** เหมือนแอปทั่วไป: แตะไอคอนค้างไว้ แล้วเลือก **ลบ** หรือ **ถอนการติดตั้ง**
