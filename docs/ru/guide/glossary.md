# Глоссарий

| Слово | Значение |
| --- | --- |
| **Адрес AAAA** | У каждого запущенного здесь токена адрес контракта заканчивается на `AAAA`. Это фирменный знак, а не проверка безопасности: всегда открывайте токены с нашего сайта. |
| **Агент** | ИИ-программа, действующая за вас; здесь она запускает токены и торгует ими со своего кошелька в заданных вами лимитах. |
| **Agent ID** | Удостоверение в кошельке агента. Нужно для покупки на бондинг-кривой. В тестнете бесплатно. |
| **Кошелёк агента** | Отдельный кошелёк, которым пользуется агент, с лимитами трат, чтобы основные средства были отдельно. |
| **Аирдроп** | Бесплатные $AGNT, которые после сезона получают подходящие кошельки пропорционально своим очкам. |
| **BNB** | Нативная монета BNB Chain. Ею платят за газ, и все токены здесь оцениваются в ней. |
| **BNB Chain** | Блокчейн, на котором работает Agentic Starter. |
| **Бондинг-кривая** | Контракт, продающий новый токен по цене из формулы: каждая покупка поднимает цену, каждая продажа снижает. Книга заявок не нужна. |
| **Сжигание** | Отправка токенов на адрес, который никто не контролирует, — они исчезают навсегда. |
| **Создатель** | Кошелёк, для которого запущен токен. До выпуска получает часть комиссий кривой (или отдаёт её трейдерам в виде кешбэка). |
| **Кешбэк** | Опция запуска: часть комиссии кривой, предназначенная создателю, возвращается трейдеру при каждой сделке. |
| **Featured** | Место в Explore, оплачиваемое сжиганием AGNT. Это реклама, а не обзор. |
| **Золотой час** | Один час в сутки, когда очки аирдропа считаются вдвое. |
| **Комиссия кривой** | 1% от каждой покупки и продажи на бондинг-кривой. См. [Комиссии](/ru/guide/fees). |
| **Кран (faucet)** | Сайт, бесплатно раздающий BNB тестнета. |
| **Газ** | Небольшая плата сети за каждую транзакцию, в BNB. |
| **Genesis Creator** | Постоянный значок для создателей первых 100 токенов, вышедших в мейннете. |
| **Выпуск (graduation)** | Момент заполнения кривой: токен переходит на PancakeSwap с заблокированной ликвидностью, кривая закрывается. |
| **Ignite** | Сжигание части токена с публичным сообщением. См. [Ignite](/ru/guide/ignite). |
| **LP-токены** | Подтверждение доли в пуле PancakeSwap. Мы сжигаем их при выпуске, поэтому ликвидность нельзя вывести. |
| **Мейннет** | Настоящая сеть с настоящими деньгами. |
| **PancakeSwap** | Крупнейшая биржа в BNB Chain. Там торгуются вышедшие токены. |
| **Пресейл** | Первая публичная продажа $AGNT до листинга. См. [Пресейл](/ru/token/presale). |
| **Сид-фраза** | 12 или 24 слова, управляющие кошельком. Никогда никому не сообщайте. |
| **Проскальзывание** | Насколько цена может сдвинуться между предпросмотром и сделкой, прежде чем сделка будет отклонена. |
| **Снапшот** | Момент, когда очки фиксируются и рассчитываются доли аирдропа. |
| **Стейкинг** | Блокировка $AGNT в контракте ради доли комиссий в BNB. См. [Стейкинг](/ru/token/staking). |
| **Тестнет** | Тренировочная копия BNB Chain, где BNB бесплатный и ничего не стоит. |
| **TGE** | Событие генерации токена: день, когда $AGNT выходит на PancakeSwap и открывается получение токенов пресейла. |
| **Лимит на кошелёк** | Максимум одного токена, который может держать один кошелёк, пока токен на кривой ({{P.mainnet.walletCapBps|pct}} в мейннете, {{P.testnet.walletCapBps|pct}} в тестнете). |
