# Запуск токена

Скажите агенту, что запустить, проверьте предпросмотр и одобрите. Вот и весь процесс.

```text
Launch a token on Agentic Starter: name "Nova Agent", symbol NOVA, description "Scouts fresh launches",
logo https://…/nova.png, X @nova_agent, and buy 0.2 BNB of it in the same transaction.
Show me the preview first and wait for my OK.
```

Агент выполняет:

```bash
agentic create --name "Nova Agent" --symbol NOVA \
  --description "Scouts fresh launches" --logo https://…/nova.png --twitter @nova_agent \
  --telegram https://t.me/nova_agent --buy 0.2
agentic execute --request-id <id>
```

Перед предпросмотром CLI ищет соль, при которой адрес токена заканчивается на `AAAA`. Это занимает несколько секунд.

На сайте форма запуска состоит из трёх шагов. Напишите одно предложение о вашей идее и нажмите **Fill it in**, чтобы
получить название, тикер и описание, которые можно отредактировать. Перетащите логотип: он закрепляется в IPFS, а запрос
использует ссылку `ipfs://` (в CLI то же делает `--logo ./nova.png`). Затем выберите, куда пойдут комиссии создателя,
проверьте карточку предпросмотра и скопируйте промпт для вашего агента. Симулятор кривой показывает цену и капитализацию на
каждом этапе.

| Поле | Ограничение |
| --- | --- |
| Название | 1–32 символа |
| Тикер | 2–10 заглавных букв или цифр. Тикеры вроде AGNT, BNB, BTC, ETH, USDT, USDC и CAKE зарезервированы |
| Алфавит названия и тикера | Один алфавит на название, поэтому похожие буквы из других алфавитов отклоняются |
| Метаданные (описание, URL логотипа, ссылки) | хранятся в блокчейне, до ~1 КБ |
| Логотип | URL `https://` / `ipfs://` или локальный PNG, JPG, GIF, WebP до 1 МБ (загружается в IPFS) |
| Первая покупка | по желанию, нужен Agent ID, действует лимит на кошелёк |
| X | ссылка или `@handle` (хранится ник) |
| Telegram | только ссылка `t.me` |
| Комиссия запуска | {{P.mainnet.launchFeeBnb}} BNB в мейннете, бесплатно в тестнете и для стейкеров AGNT с привилегиями, плюс газ |
| Пара | BNB. Другие пары появятся позже |

У токенов нет налога, функции минта и владельца.

## Куда идут комиссии создателя

| Вариант | CLI | Сайт |
| --- | --- | --- |
| Ваш кошелёк запуска (по умолчанию) | — | оставьте поле кошелька комиссий пустым |
| Другой кошелёк | `--fee-to 0xWallet:100` | поле **Creator fee wallet** |
| Разделение, до 10 получателей | `--fee-to 0xA:60,0xB:40` | настраивается на My tokens после запуска |
| Аккаунт X или GitHub | `--fee-to 0xA:80,x:@alice:20` | настраивается на My tokens после запуска |
| Кешбэк трейдерам | `--cashback` | **Reward mode → Cashback** |

Доли аккаунтов ждут в эскроу, пока владелец аккаунта не подтвердит его и не привяжет кошелёк; невостребованные доли
возвращаются создателю через 90 дней. Изменение разделения вступает в силу через 24 часа после предложения. См.
[Комиссии](/ru/guide/fees#creator-fee-options).

## Тестнет: запуск через Telegram-бота {#testnet-telegram}

В тестнете BNB Chain можно запустить токен без настройки агента. Наш бот Agen действует как агент и платит газ; ваш
кошелёк записывается как создатель.

1. Откройте [Launch](https://agenticstarter.xyz/launch?lang=ru), подключите кошелёк, который будет владеть токеном, и заполните
   название, тикер, логотип, описание и ссылки.
2. Нажмите **Open in Telegram**. Бот откроется с вашим кодом запуска и покажет предпросмотр.
3. Нажмите **🚀 Launch now**. Через несколько секунд бот пришлёт адрес токена, и токен появится на странице Explore.

Если Telegram не открылся, скопируйте строку `/launch ABCD2345` со страницы и отправьте её боту. Коды действуют 24 часа и
работают один раз. Каждый аккаунт Telegram может запускать до 3 токенов в день.

Бот не покупает за вас. Чтобы купить, откройте страницу токена, получите бесплатный тестовый Agent ID и купите за тестовый
BNB. В тестнете токен выходит при **{{P.testnet.graduationTargetBnb}} BNB**.

## После запуска

Затем страница запуска показывает **набор после запуска**: готовый пост для X, текст для Telegram, картинку для шеринга и
встраиваемый виджет для вашего сайта. На [My tokens](https://agenticstarter.xyz/me?lang=ru) можно:

| Действие | Подробности |
| --- | --- |
| Следить за прогрессом | Прогресс кривой, собранный BNB, держатели |
| Забрать награды создателя | 20% каждой комиссии кривой по вашему токену, в BNB, до выпуска, плюс бонус за выпуск |
| Обновить информацию | Сменить логотип, описание и ссылки за {{P.mainnet.metaUpdateFeeBnb}} BNB в мейннете. Название и тикер не меняются никогда. Держатели видят уведомление 7 дней, вся история остаётся публичной. |
| Разделение комиссий | Предложить новое разделение; оно вступает в силу через 24 часа |
| Передать роль создателя | Предложить новый кошелёк создателя; он вступает в роль, когда примет её на странице токена. Уже заработанные награды остаются за вами. |
| Аллокация создателя | Там, где она действует (сегодня тестнет), забрать разблокированную часть после выпуска |
| Подтвердить X | Привязать аккаунт X, чтобы на странице токена был значок подтверждённого создателя |

Создатели первых 100 токенов, вышедших в мейннете, получают постоянный значок **Genesis Creator**.
