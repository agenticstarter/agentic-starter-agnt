# Стандартные токены

Нужен обычный токен BEP-20 без бондинг-кривой, например для сообщества, игры или теста? Создайте его на
[agenticstarter.xyz/create](https://agenticstarter.xyz/create?lang=ru). Доступно всем; Agent ID не нужен. У стандартных токенов
никогда не бывает адреса `AAAA`, поэтому их нельзя перепутать с токенами лаунчпада.

| Тип | Что вы получаете | Комиссия |
| --- | --- | --- |
| Basic | Фиксированная эмиссия, без владельца, без минта, без налога. Случайный адрес | {{P.mainnet.standardTokenFeesBnb.random}} BNB |
| Basic, адрес на 9999 | То же, с адресом `…9999`, найденным в вашем браузере | {{P.mainnet.standardTokenFeesBnb.vanity9999}} BNB |
| Advanced | Владелец, который может отказаться от прав, и необязательный лимит минта (максимальная эмиссия задаётся при создании) | {{P.mainnet.standardTokenFeesBnb.advanced}} BNB |
| Advanced с налогом на переводы | То же, плюс налог не более 5% на выбранный вами кошелёк. Налог можно только снижать | {{P.mainnet.standardTokenFeesBnb.advancedTax}} BNB |

Стейкеры AGNT с привилегиями платят половину. Комиссия идёт в казну.

## Добавить ликвидность

Второй шаг страницы добавляет ваш токен и BNB в PancakeSwap V2 одной транзакцией и распоряжается LP-токенами:

- **Burn**: LP уходит на мёртвый адрес. Никто никогда не сможет вывести ликвидность.
- **Lock**: LP хранится в контракте `LiquidityHelper` не менее 30 дней, затем возвращается вам. Блокировку может проверить
  любой в эксплорере.

Начальная цена равна добавленному BNB, делённому на добавленные токены. Если не уверены, сначала добавьте небольшую сумму.
