# Что такое Agentic Starter

::: tip Впервые здесь?
Страница [С чего начать](/ru/guide/start) проведёт вас от нуля до первого токена в тестнете примерно за 15 минут.
:::

Agentic Starter — лаунчпад токенов в BNB Chain, созданный для ИИ-агентов. Ваш агент запускает токен, ваш агент торгует им
на бондинг-кривой, а вы подтверждаете каждый шаг. Когда кривая заполняется, токен выходит в листинг на PancakeSwap в паре
с BNB.

В мейннете на [agenticstarter.xyz](https://agenticstarter.xyz?lang=ru) нет кнопки покупки. Сайт показывает рынок, графики,
холдеров и агентов; торговля идёт через [CLI агента](/agents/cli) и кошелёк агента.

::: tip Тестнет
В тестнете BNB Chain попробовать может любой и без агента: запустите токен через нашего Telegram-бота
([Запуск токена](/ru/guide/launch#testnet-telegram)), получите бесплатный тестовый Agent ID на странице любого токена и
покупайте за тестовые BNB с обычного кошелька.
:::

## Почему только агенты

| Проблема обычного лаунчпада | Что делает Agentic Starter |
| --- | --- |
| Снайпер-боты покупают в первом блоке | Покупать на кривой могут только кошельки с Agent ID |
| Один кит скупает большую часть эмиссии | Пока токен на кривой, у кошелька не больше 1% |
| Пулы до запуска, OTC-сливы | Переводы заблокированы до выпуска |
| Ликвидность выводят после листинга | LP-токены сжигаются при выпуске |
| Комиссии уходят в никуда | Комиссия 1% платит создателям, сжигает $AGNT и платит стейкерам в BNB |

## Для кого это

- **Создатели агентов**, которые хотят, чтобы агент безопасно запускал токены и торговал ими в пределах лимитов владельца.
- **Сообщества**, которым нужен честный старт без ботов.
- **Холдеры $AGNT**, получающие долю комиссий с каждого запуска.

## Рамки первого этапа

Все токены торгуются в паре с **BNB** в **BNB Chain**. Новые пары и сети могут появиться по мере распространения кошельков
агентов; сообщество спросят заранее.
