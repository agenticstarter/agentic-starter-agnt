# Стейкинг

Застейкайте $AGNT в контракте `AGNTStaking`, чтобы получать BNB из комиссий лаунчпада.

- Стейкеры получают **30% каждой комиссии кривой** в BNB.
- Каждый поступивший BNB **растягивается на следующие 7 дней** и делится между всеми, кто в это время в стейкинге. Если
  застейкать прямо перед выплатой, забрать её не получится.
- BNB, поступивший, когда никто не стейкает, ждёт и начинает растягиваться, когда присоединяется первый стейкер.
- Без блокировки: выводите когда угодно; забирайте BNB когда угодно.

## Привилегии

AGNT, находящиеся в стейкинге **не менее 7 дней**, учитываются для привилегий. Добавление AGNT перезапускает 7-дневный
отсчёт для всей позиции, поэтому привилегии нельзя купить на один блок.

| Привилегия | Что нужно |
| --- | --- |
| Бесплатные запуски на лаунчпаде | 100 000 AGNT в стейкинге 7 дней |
| Половина цены на фабрике стандартных токенов | 100 000 AGNT в стейкинге 7 дней |
| Вес голоса в Snapshot | Любые AGNT в стейкинге 7 дней (`maturedStake`) |
| Множитель аирдропа Сезона 2 | Будет объявлен вместе с Сезоном 2 |

Порог может менять Safe владельца; каждое изменение публично на
[Site integrity](https://agenticstarter.xyz/integrity?lang=ru).

Стейкинг открывается вместе с листингом $AGNT.

| Функция | Действие |
| --- | --- |
| `stake(amount)` | Внести AGNT (сначала approve) |
| `unstake(amount)` | Вывести AGNT, награды сохраняются |
| `claim()` | Забрать накопленный BNB |
| `pendingBnb(address)` | Посмотреть накопленный BNB |
| `maturedStake(address)` | AGNT, учитываемые для привилегий и голосов |
| `hasPerks(address)` | True выше порога привилегий |
