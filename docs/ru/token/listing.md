# Листинг и использование средств

$AGNT выходит на PancakeSwap V2 на следующий день после окончания пресейла, в 14:00 UTC.

## Правило листинга

| | |
| --- | --- |
| Цена листинга | Итоговая цена пресейла. Покупатели пресейла и первые покупатели на рынке платят одинаково |
| BNB в пул | {{P.presale.listing.bnbToPoolPct}}% всего собранного BNB |
| AGNT в пул | 80% собранного BNB ÷ итоговая цена: {{P.presale.listing.maxPoolAgnt|n}} AGNT, если собрано {{P.presale.floorCapBnb}} BNB или больше, и 800 000 AGNT на BNB, если меньше |
| Откуда берутся AGNT | Safe ликвидности (150 млн) плюс до 50 млн из 60 млн резерва листинга. Ненужные AGNT остаются в Safe ликвидности |
| LP-токены | Сжигаются на том же шаге. Никто не сможет вывести ликвидность |

Оставшиеся {{P.presale.listing.bnbToTreasuryPct}}% BNB идут в Safe казны.

## Использование средств (часть казны, 20%)

| Использование | Доля |
| --- | --- |
| Безопасность и аудиты | {{P.presale.useOfFundsPct.security}}% |
| Листинги на биржах | {{P.presale.useOfFundsPct.listing}}% |
| Маркетинг и сообщество | {{P.presale.useOfFundsPct.marketing}}% |
| Операции (серверы, API) | {{P.presale.useOfFundsPct.operations}}% |

Распределение можно менять до открытия пресейла. После этого каждое изменение публично фиксируется на
[Site integrity](https://agenticstarter.xyz/integrity?lang=ru) и объявляется в Telegram. Расходы отслеживаются в еженедельном
[отчёте Transparency](https://agenticstarter.xyz/transparency?lang=ru).

## Обязательства по блокировке

| Аллокация | Правило |
| --- | --- |
| Команда (120 млн) | Контракт вестинга: клифф 12 месяцев, затем линейно 24 месяца. Владелец может только отложить начало |
| Казна и экосистема | Никаких продаж на рынке до листинга + 6 месяцев |
| Ликвидность (Safe ликвидности) | Используется только для пула и листингов |
| Сообщество (Safe сообщества) | Используется только для аирдропов и раннего бонуса пресейла |

Если любой Safe проекта переводит AGNT на пару DEX, в роутер или на известный адрес депозита биржи, в канале и группе
Telegram автоматически публикуется публичное оповещение.

## Проверьте сами

- [Liquidity proof](https://agenticstarter.xyz/liquidity?lang=ru): адрес пула, текущие резервы и транзакция сжигания LP, считанные из
  блокчейна.
- Чек-лист листинга на странице пресейла: финализация → BNB добавлен в пул → LP сожжён → клейм открыт, у каждого шага своя
  транзакция.
- [Адреса Safe](https://agenticstarter.xyz/integrity?lang=ru) со всеми изменениями параметров.
