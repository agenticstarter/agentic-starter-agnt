# الإدراج واستخدام الأموال

يُدرج $AGNT على PancakeSwap V2 في اليوم التالي لانتهاء البيع المسبق، الساعة 14:00 UTC.

## قاعدة الإدراج

| | |
| --- | --- |
| سعر الإدراج | سعر البيع المسبق النهائي. يدفع مشترو البيع المسبق وأوائل مشتري السوق السعر نفسه |
| BNB إلى المجمّع | {{P.presale.listing.bnbToPoolPct}}% من كل BNB المجموع |
| AGNT إلى المجمّع | 80% من BNB المجموع ÷ السعر النهائي: {{P.presale.listing.maxPoolAgnt|n}} AGNT عند جمع {{P.presale.floorCapBnb}} BNB أو أكثر، و800,000 AGNT لكل BNB دون ذلك |
| من أين يأتي AGNT | Safe السيولة (150M) إضافة إلى ما يصل إلى 50M من احتياطي الإدراج البالغ 60M. AGNT غير المطلوب يبقى في Safe السيولة |
| توكنات LP | تُحرق في الخطوة نفسها. لا يستطيع أحد سحب السيولة |

يذهب الـ {{P.presale.listing.bnbToTreasuryPct}}% المتبقية من BNB إلى Safe الخزينة.

## التزامات القفل

| التخصيص | القاعدة |
| --- | --- |
| الفريق (120M) | عقد الاستحقاق: قفل 12 شهرًا، ثم تحرير خطي على 24 شهرًا. يمكن للمالك تأجيل البداية فقط |
| الخزينة والنظام البيئي | لا بيع في السوق قبل الإدراج + 6 أشهر |
| السيولة (Safe السيولة) | تُستخدم للمجمّع وللإدراجات فقط |
| المجتمع (Safe المجتمع) | تُستخدم للإيردروب ومكافأة المشاركة المبكرة في البيع المسبق فقط |

إذا نقلت أي محفظة Safe للمشروع AGNT إلى زوج DEX أو موجّه أو عنوان إيداع معروف لمنصة تداول، يصدر تنبيه علني تلقائيًا في
قناة Telegram ومجموعتها.

  السلسلة.
- قائمة فحص الإدراج في صفحة البيع المسبق: الإنهاء ← إضافة BNB إلى المجمّع ← حرق LP ← فتح المطالبات، ولكل خطوة معاملتها.
