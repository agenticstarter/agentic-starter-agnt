# إطلاق توكن

أخبر وكيلك بما يطلقه، وراجع المعاينة، ووافق. هذا كل شيء.

```text
Launch a token on Agentic Starter: name "Nova Agent", symbol NOVA, description "Scouts fresh launches",
logo https://…/nova.png, X @nova_agent, and buy 0.2 BNB of it in the same transaction.
Show me the preview first and wait for my OK.
```

يشغّل الوكيل:

```bash
agentic create --name "Nova Agent" --symbol NOVA \
  --description "Scouts fresh launches" --logo https://…/nova.png --twitter @nova_agent \
  --telegram https://t.me/nova_agent --buy 0.2
agentic execute --request-id <id>
```

قبل المعاينة تبحث أداة CLI عن قيمة salt تجعل عنوان التوكن ينتهي بـ `AAAA`. يستغرق ذلك بضع ثوانٍ.

على الموقع يعمل نموذج الإطلاق في ثلاث خطوات. اكتب جملة واحدة عن فكرتك واضغط **Fill it in** لتحصل على اسم ورمز ووصف
يمكنك تعديلها. أفلت الشعار: يُثبّت على IPFS ويستخدم الطلب رابط `ipfs://` (في CLI يفعل `--logo ./nova.png` الشيء نفسه).
ثم اختر وجهة رسوم المُنشئ، وراجع بطاقة المعاينة، وانسخ الطلب لوكيلك. ويعرض محاكي المنحنى السعر والقيمة السوقية في كل
مرحلة.

| الحقل | الحد |
| --- | --- |
| الاسم | 1–32 حرفًا |
| الرمز | 2–10 أحرف كبيرة أو أرقام. الرموز مثل AGNT وBNB وBTC وETH وUSDT وUSDC وCAKE محجوزة |
| أبجدية الاسم والرمز | أبجدية واحدة في الاسم الواحد، فتُرفض الأحرف المتشابهة من أبجديات أخرى |
| البيانات الوصفية (الوصف، رابط الشعار، الروابط) | مخزّنة على السلسلة، حتى نحو 1 KB |
| الشعار | رابط `https://` / `ipfs://` أو ملف PNG أو JPG أو GIF أو WebP محلي حتى 1 MB (يُرفع إلى IPFS) |
| الشراء الأول | اختياري، يتطلب Agent ID، ويخضع لحد المحفظة |
| X | رابط أو `@handle` (يُخزَّن اسم الحساب) |
| Telegram | رابط `t.me` فقط |
| رسوم الإطلاق | {{P.mainnet.launchFeeBnb}} BNB على الشبكة الرئيسية، مجانًا على التجريبية ولمراهني AGNT أصحاب المزايا، إضافة إلى الغاز |
| الزوج | BNB. أزواج أخرى قادمة لاحقًا |

لا ضريبة على التوكنات ولا دالة سكّ ولا مالك.

## وجهة رسوم المُنشئ

| الخيار | CLI | الموقع |
| --- | --- | --- |
| محفظة الإطلاق (الافتراضي) | — | اترك محفظة الرسوم فارغة |
| محفظة أخرى | `--fee-to 0xWallet:100` | حقل **Creator fee wallet** |
| تقسيم حتى 10 مستلمين | `--fee-to 0xA:60,0xB:40` | يُضبط في My tokens بعد الإطلاق |
| حساب على X أو GitHub | `--fee-to 0xA:80,x:@alice:20` | يُضبط في My tokens بعد الإطلاق |
| استرداد نقدي للمتداولين | `--cashback` | **Reward mode → Cashback** |

حصص الحسابات تنتظر في حساب ضمان إلى أن يثبت صاحب الحساب ملكيته ويربط محفظة؛ وتعود الحصص غير المطالَب بها إلى المُنشئ بعد
90 يومًا. تغيير التقسيم يسري بعد 24 ساعة من اقتراحه. انظر [الرسوم](/ar/guide/fees#creator-fee-options).

## الشبكة التجريبية: الإطلاق عبر روبوت Telegram {#testnet-telegram}

على الشبكة التجريبية لـ BNB Chain يمكنك الإطلاق دون إعداد وكيل. يعمل روبوتنا Agen كوكيل ويدفع الغاز، وتُسجّل محفظتك
بصفتها المُنشئ.

1. افتح [Launch](https://agenticstarter.xyz/launch?lang=ar)، واربط المحفظة التي ستملك التوكن، واملأ الاسم والرمز والشعار والوصف
   والروابط.
2. اضغط **Open in Telegram**. يفتح الروبوت برمز الإطلاق الخاص بك ويعرض معاينة.
3. اضغط **🚀 Launch now**. بعد ثوانٍ يرد الروبوت بعنوان التوكن، ويظهر التوكن في صفحة Explore.

إن لم يُفتح Telegram، انسخ سطر `/launch ABCD2345` من الصفحة وأرسله إلى الروبوت. الرموز صالحة 24 ساعة وتعمل مرة واحدة.
يمكن لكل حساب Telegram إطلاق 3 توكنات يوميًا كحد أقصى.

الروبوت لا يشتري نيابة عنك. للشراء افتح صفحة التوكن، واحصل على Agent ID تجريبي مجاني، واشترِ بـ BNB تجريبي. على الشبكة
التجريبية يتخرّج التوكن عند **{{P.testnet.graduationTargetBnb}} BNB**.

## بعد الإطلاق

تعرض صفحة الإطلاق بعدها **حزمة ما بعد الإطلاق**: منشور X جاهز، ونص Telegram، وصورة للمشاركة، وأداة تضمين لموقعك. في
[My tokens](https://agenticstarter.xyz/me?lang=ar) يمكنك:

| الإجراء | التفاصيل |
| --- | --- |
| متابعة التقدّم | تقدّم المنحنى، BNB المجموع، الحاملون |
| طلب مكافآت المُنشئ | 20% من كل رسوم منحنى على توكنك، بـ BNB، حتى التخرّج، إضافة إلى مكافأة التخرّج |
| تحديث المعلومات | غيّر الشعار والوصف والروابط مقابل {{P.mainnet.metaUpdateFeeBnb}} BNB على الشبكة الرئيسية. الاسم والرمز لا يتغيران أبدًا. يرى الحاملون إشعارًا لمدة 7 أيام ويبقى السجل كاملًا علنيًا. |
| تقسيم الرسوم | اقترح تقسيمًا جديدًا؛ يسري بعد 24 ساعة |
| نقل صفة المُنشئ | اقترح محفظة مُنشئ جديدة؛ تتسلّم الدور عندما تقبل في صفحة التوكن. المكافآت المكتسبة تبقى قابلة للمطالبة من جهتك. |
| حصة المُنشئ | حيثما تنطبق (على الشبكة التجريبية اليوم)، اطلب الجزء المفتوح بعد التخرّج |
| توثيق X | اربط حسابك على X لإظهار شارة مُنشئ موثّق في صفحة التوكن |

يحصل مُنشئو أول 100 توكن تتخرّج على الشبكة الرئيسية على شارة **Genesis Creator** دائمة.
