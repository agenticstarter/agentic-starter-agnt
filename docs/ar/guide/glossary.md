# المصطلحات

| الكلمة | المعنى |
| --- | --- |
| **عنوان AAAA** | كل توكن يُطلق هنا ينتهي عنوان عقده بـ `AAAA`. هذه علامة تجارية لا فحص أمان: افتح التوكنات دائمًا من موقعنا. |
| **الوكيل** | برنامج ذكاء اصطناعي يتصرف نيابة عنك؛ هنا يطلق التوكنات ويتداولها من محفظته الخاصة ضمن الحدود التي تضعها. |
| **Agent ID** | اعتماد تحمله محفظة الوكيل. مطلوب للشراء على منحنى الربط. مجاني على الشبكة التجريبية. |
| **محفظة الوكيل** | محفظة منفصلة يستخدمها وكيلك، بحدود إنفاق، لتبقى أموالك الرئيسية بعيدة. |
| **الإيردروب** | $AGNT مجاني يُوزّع على المحافظ المؤهلة بعد كل موسم بنسبة نقاطها. |
| **BNB** | العملة الأصلية لـ BNB Chain. تُدفع بها رسوم الغاز وتُسعّر بها كل التوكنات هنا. |
| **BNB Chain** | سلسلة الكتل التي يعمل عليها Agentic Starter. |
| **منحنى الربط** | عقد يبيع توكنًا جديدًا بسعر تحدده معادلة: كل شراء يرفع السعر وكل بيع يخفضه. لا حاجة لدفتر أوامر. |
| **الحرق** | إرسال التوكنات إلى عنوان لا يتحكم فيه أحد، فتختفي إلى الأبد. |
| **المُنشئ** | المحفظة التي أُطلق التوكن لها. تحصل على حصة من رسوم المنحنى حتى التخرّج (أو تمنحها للمتداولين كاسترداد نقدي). |
| **الاسترداد النقدي (Cashback)** | خيار عند الإطلاق: حصة المُنشئ من رسوم المنحنى تعود إلى المتداول في كل صفقة. |
| **Featured (مميّز)** | موضع في صفحة Explore يُدفع ثمنه بحرق AGNT. هو إعلان وليس تقييمًا. |
| **الساعة الذهبية** | ساعة واحدة يوميًا تُحتسب فيها نقاط الإيردروب مضاعفة. |
| **رسوم المنحنى** | 1% من كل شراء وبيع على منحنى الربط. انظر [الرسوم](/ar/guide/fees). |
| **الصنبور** | موقع يوزّع BNB الشبكة التجريبية مجانًا. |
| **الغاز** | الرسوم الصغيرة التي تأخذها الشبكة عن كل معاملة، تُدفع بـ BNB. |
| **Genesis Creator** | شارة دائمة لمُنشئي أول 100 توكن تتخرّج على الشبكة الرئيسية. |
| **التخرّج** | لحظة امتلاء المنحنى: ينتقل التوكن إلى PancakeSwap بسيولة مقفلة ويُغلق المنحنى. |
| **Ignite** | حرق جزء من توكن مع رسالة علنية. انظر [Ignite](/ar/guide/ignite). |
| **توكنات LP** | إثبات حصة في مجمّع PancakeSwap. نحرقها عند التخرّج فلا يمكن سحب السيولة أبدًا. |
| **الشبكة الرئيسية** | الشبكة الحقيقية بأموال حقيقية. |
| **PancakeSwap** | أكبر منصة تداول على BNB Chain. تُتداول فيها التوكنات المتخرّجة. |
| **البيع المسبق** | أول بيع عام لـ $AGNT قبل الإدراج. انظر [البيع المسبق](/ar/token/presale). |
| **عبارة الاسترداد** | 12 أو 24 كلمة تتحكم في المحفظة. لا تشاركها مع أي أحد أبدًا. |
| **الانزلاق** | مقدار تحرك السعر المسموح بين المعاينة والصفقة قبل رفضها. |
| **اللقطة** | اللحظة التي تُجمّد فيها النقاط وتُحسب حصص الإيردروب. |
| **المراهنة (Staking)** | قفل $AGNT في عقد لكسب حصة من الرسوم بـ BNB. انظر [المراهنة](/ar/token/staking). |
| **الشبكة التجريبية** | نسخة تدريبية من BNB Chain فيها BNB مجاني وبلا قيمة. |
| **TGE** | حدث توليد التوكن: يوم إدراج $AGNT على PancakeSwap وفتح مطالبات البيع المسبق. |
| **حد المحفظة** | أقصى كمية من توكن يمكن لمحفظة واحدة حملها ما دام على المنحنى ({{P.mainnet.walletCapBps|pct}} على الشبكة الرئيسية، {{P.testnet.walletCapBps|pct}} على التجريبية). |
