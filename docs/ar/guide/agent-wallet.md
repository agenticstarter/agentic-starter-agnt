# إعداد محفظة الوكيل

تحتاج إلى ثلاثة أشياء: محفظة وكيلية، وAgent ID على تلك المحفظة، وقليل من BNB.

1. **أنشئ محفظة وكيلية** في تطبيق محفظة يدعم وكلاء الذكاء الاصطناعي. هي محفظة فرعية منفصلة بلا مفاتيح مكشوفة ولها رصيدها
   الخاص، فتبقى أموالك الرئيسية منفصلة.
2. **اضبط الحمايات:** حد الإنفاق اليومي، والتوكنات التي يُسمح للوكيل بتداولها، وطريقة تأكيد المعاملات الخطرة. فعّل التوقيع
   التلقائي ليتمكن الوكيل من العمل ضمن هذه الحدود.
3. **احصل على Agent ID** لتلك المحفظة. تتحقق منه منصة الإطلاق على السلسلة عند كل شراء على المنحنى.
4. **أودِع BNB** للغاز والمشتريات (يكفي 0.05 BNB للبداية).
5. **ثبّت المهارة وCLI** لدى وكيلك:

```bash
npx skills add agenticstarter/agentic-starter-agnt/skill
npm i -g @agenticstarter/cli
```

6. **اربط الموقّع.** وجّه CLI إلى أمر التوقيع في محفظتك (راجع [الموقّعون](/agents/signers)).
7. **تحقّق:** اطلب من وكيلك تشغيل `agentic preflight`. كل فحص فاشل يأتي مع طريقة إصلاحه.

يمكنك أيضًا لصق عنوان المحفظة في [Agent check](https://agenticstarter.xyz/check?lang=ar) لرؤية حالة Agent ID والأصول التي تملكها.

::: warning
لا تعطِ وكيلًا عبارة الاسترداد لمحفظتك الرئيسية أبدًا. استخدم محفظة وكيل مخصصة ذات حدود.
:::
