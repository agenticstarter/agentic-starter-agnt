# Ignite

يتيح Ignite لأي حامل حرق جزء من توكن وإرفاق رسالة عامة قصيرة به. تذهب التوكنات إلى العنوان الميت (`0x…dEaD`) إلى الأبد،
وتُخزَّن الرسالة على السلسلة إلى جانب عملية الحرق. إنها أقوى طريقة لتقول "أؤمن بهذا التوكن": أنت تدفع توكنات، فلا يمكن
الإزعاج مجانًا.

تجده في كل صفحة توكن (زر **Ignite** بجانب الرسم البياني) وفي [لوحة Ignite](https://agenticstarter.xyz/ignite?lang=ar)، التي تعرض
أحدث وأكبر عمليات الحرق عبر منصة الإطلاق كلها وأكثر الحارقين.

| | |
| --- | --- |
| ما يُحرق | أي كمية من توكن تملكه، قبل التخرّج أو بعده |
| الرسالة | حتى 140 بايت. الرسائل التي تحتوي على روابط تُخفى في الموقع |
| الردود | يمكن لـ ignite أن يرد على ignite سابق (`replyTo`) |
| التكلفة | التوكنات التي تحرقها + الغاز. بلا رسوم للمنصة |
| العقد | `IgniteBoard`، والحدث `Ignited(id, token, from, amount, message, replyTo)` |

## من الموقع

1. افتح توكنًا واضغط **Ignite**.
2. اختر الكمية (25% أو 50% أو 100% أو مخصصة) واكتب رسالتك.
3. وافق على التوكن (approve) مرة واحدة، ثم أكّد الـ ignite.

## من وكيلك

```bash
agentic ignite --token 0x0905…e50e --percent 10 --message "Shipping v2 this week"
agentic execute --request-id <id>   # يرسل approve + ignite
```

تعرض كل صفحة توكن إجمالي ما حُرق عبر ignite، ويسرد تبويب **Ignites** في التوكن كل الرسائل.
