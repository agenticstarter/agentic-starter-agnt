# Telegram کمیونٹی

| جگہ | لنک | کس لیے ہے |
| --- | --- | --- |
| چینل | [t.me/agenticstarter](https://t.me/agenticstarter) | صرف اعلانات |
| گروپ | [t.me/agentic_starter](https://t.me/agentic_starter) | چیٹ، روزانہ کوئز، Agen سے سوالات |
| Agen (بوٹ) | [t.me/agenticstarter_bot](https://t.me/agenticstarter_bot) | ایئرڈراپ Mini App، یاد دہانیاں، ٹیسٹ نیٹ لانچ |

## گروپ میں شامل ہونا

نئے ممبرز کو لکھنے سے پہلے خوش آمدید پیغام میں **I'm not a bot** دبانا ہوتا ہے۔ چیٹ صاف رکھنے کے لیے خوش آمدید اور شمولیت کے
پیغامات تھوڑی دیر بعد ہٹا دیے جاتے ہیں۔

## Agen سے پوچھیں

گروپ میں اپنے پیغام میں کہیں بھی `@Agen` لکھیں، مثلاً `@Agen گریجویشن کیسے کام کرتی ہے؟`۔ Agen ان دستاویزات اور لائیو ڈیٹا سے آپ کی زبان میں جواب دیتا ہے۔ پروجیکٹ کے سوالوں کا جواب صرف گروپ میں دیتا ہے تاکہ سب دیکھ سکیں؛ نجی چیٹ میں آپ کے اپنے کاموں (لانچ، پوائنٹس، یاد دہانیاں) میں مدد کرتا ہے۔

Agen ایسے سوالوں کے جواب نہیں دیتا جو آپ کو یا پروجیکٹ کو خطرے میں ڈال سکیں (کیز، سیڈ فریز، کنٹریکٹ پر حملہ کیسے کریں)، یا جن کا
Agentic Starter سے کوئی تعلق نہ ہو۔ جو سوال بار بار پوچھے جائیں ان کے جواب میں متعلقہ دستاویزی صفحے کا لنک دیا جاتا ہے۔

## کمانڈز

| کمانڈ | کہاں | کیا کرتی ہے |
| --- | --- | --- |
| `@Agen <سوال>` | گروپ | Agen سے پوچھیں (`/agen` بھی چلتا ہے) |
| `/points` | نجی | آپ کے ایئرڈراپ پوائنٹس اور کیا باقی ہے |
| `/earn` | گروپ یا نجی | پوائنٹس کے لیے ابھی کیا کر سکتے ہیں، سب سے بڑا پہلے |
| `/challenge` | گروپ یا نجی | آج کا چیلنج اور آپ کا اسٹریک |
| `/help` | گروپ یا نجی | تمام کمانڈز |
| `/watch <token>` | نجی | 80%، 90% اور گریجویشن پر پیغام |
| `/remind presale` · `claim` · `mainnet` | نجی | کھلنے پر پیغام |
| `/report` | گروپ میں کسی پیغام کا جواب | ٹیم کو اسکیم یا جعلی ایڈمن کی رپورٹ کریں |
| `/launch <code>` | نجی | ویب سائٹ سے ٹیسٹ نیٹ لانچ (دیکھیں [لانچ](/ur/guide/launch#testnet-telegram)) |
| `/faucet` | نجی | ٹیسٹ BNB کہاں سے ملے (Q2 کے بعد ایئرڈراپ صفحہ ایک بار آپ کو ٹاپ اپ دے سکتا ہے) |
| `/settings` | نجی | Agen آپ کو کون سے نجی پیغامات بھیجے: باکس، کوئز یاد دہانیاں، خلاصہ وغیرہ |
| `/agentid` | نجی | Agent ID جانچیں |

Agen کے ہر نجی پیغام میں **انہیں بند کریں** بٹن ہوتا ہے۔ کسی بھی وقت `/settings` سے دوبارہ آن کریں۔

## گروپ کے اصول

- مہربان رہیں۔ توہین نہیں، FUD مہم نہیں، اسپام نہیں، دوسرے پروجیکٹس کی تشہیر نہیں۔
- لنکس: صرف سرکاری لنکس (دیکھیں [محفوظ رہیں](/ur/guide/safety))۔ دوسرے لنکس ہٹا دیے جاتے ہیں۔
- اسٹرائیکس: سخت توہین پر فوراً اسٹرائیک ملتا ہے؛ ہلکی توہین بار بار ہو تو وارننگ کے بعد۔ 20 دن میں **5 اسٹرائیکس** پر پابندی لگتی ہے۔
  اسٹرائیکس 20 دن بعد ختم ہو جاتے ہیں۔
- ایڈمنز کبھی پہلے DM نہیں کرتے اور کبھی کیز، سیڈ فریز یا BNB نہیں مانگتے۔
- ٹیم جیسے نام (admin، support، Agentic Starter، Agen) میوٹ کر دیے جاتے ہیں، اور "DM کریں"، سیڈ فریز اور "والیٹ ویلیڈیٹ کریں" والے پیغامات ہٹا دیے جاتے ہیں۔

اگر آپ کو لگے کہ کوئی ماڈریشن کارروائی غلط تھی تو گروپ میں کسی ایڈمن کو لکھیں۔
