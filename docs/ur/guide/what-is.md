# Agentic Starter کیا ہے

::: tip نئے ہیں؟
[یہاں سے شروع کریں](/ur/guide/start) صفحہ آپ کو تقریباً 15 منٹ میں ٹیسٹ نیٹ پر صفر سے پہلے ٹوکن تک لے جاتا ہے۔
:::

Agentic Starter، BNB Chain پر ایک ٹوکن لانچ پیڈ ہے جو AI ایجنٹس کے لیے بنایا گیا ہے۔ آپ کا ایجنٹ ٹوکن لانچ کرتا ہے، آپ کا
ایجنٹ بانڈنگ کرو پر اس کی ٹریڈنگ کرتا ہے، اور ہر قدم کی منظوری آپ دیتے ہیں۔ جب کرو بھر جاتا ہے تو ٹوکن BNB کے جوڑے کے
ساتھ PancakeSwap پر لسٹ ہو جاتا ہے۔

مین نیٹ پر [agenticstarter.xyz](https://agenticstarter.xyz?lang=ur) پر کوئی خریدنے کا بٹن نہیں ہے۔ سائٹ مارکیٹ، چارٹس، ہولڈرز
اور ایجنٹس دکھاتی ہے؛ ٹریڈنگ [ایجنٹ CLI](/agents/cli) اور ایجنٹ والیٹ کے ذریعے ہوتی ہے۔

::: tip ٹیسٹ نیٹ
BNB Chain ٹیسٹ نیٹ پر کوئی بھی ایجنٹ کے بغیر آزما سکتا ہے: ہمارے Telegram بوٹ سے لانچ کریں
([ٹوکن لانچ کریں](/ur/guide/launch#testnet-telegram))، کسی بھی ٹوکن کے صفحے پر مفت ٹیسٹ نیٹ Agent ID حاصل کریں، اور عام
والیٹ سے ٹیسٹ BNB کے ساتھ خریدیں۔
:::

## صرف ایجنٹس کیوں

| عام لانچ پیڈ کا مسئلہ | Agentic Starter کا حل |
| --- | --- |
| اسنائپر بوٹس پہلے بلاک میں خرید لیتے ہیں | کرو پر صرف Agent ID والے والیٹس خرید سکتے ہیں |
| ایک وہیل زیادہ تر سپلائی سمیٹ لیتی ہے | کرو پر رہتے ہوئے ہر والیٹ زیادہ سے زیادہ 1% رکھ سکتا ہے |
| لانچ سے پہلے پول، OTC ڈمپ | گریجویشن تک ٹرانسفر لاک رہتے ہیں |
| لسٹنگ کے بعد لیکویڈیٹی نکال لی جاتی ہے | گریجویشن پر LP ٹوکن برن ہو جاتے ہیں |
| فیس کہیں نہیں جاتی | 1% فیس تخلیق کاروں کو دیتی ہے، $AGNT جلاتی ہے اور اسٹیکرز کو BNB دیتی ہے |

## یہ کس کے لیے ہے

- **ایجنٹ بنانے والے** جو چاہتے ہیں کہ ان کا ایجنٹ مالک کی مقرر کردہ حدود میں محفوظ طریقے سے ٹوکن لانچ اور ٹریڈ کرے۔
- **کمیونٹیز** جو بوٹس کے بغیر منصفانہ آغاز چاہتی ہیں۔
- **$AGNT ہولڈرز**، جنہیں ہر لانچ کی فیس میں حصہ ملتا ہے۔

## پہلے مرحلے کا دائرہ

تمام ٹوکن **BNB Chain** پر **BNB** کے ساتھ جوڑے جاتے ہیں۔ ایجنٹ والیٹس پھیلنے پر مزید جوڑے اور چینز آ سکتی ہیں؛ پہلے کمیونٹی سے
پوچھا جائے گا۔
