# یہاں سے شروع کریں

کرپٹو یا Agentic Starter میں نئے ہیں؟ یہ صفحہ آپ کو تقریباً 15 منٹ میں صفر سے اپنے پہلے ٹوکن تک لے جاتا ہے۔ نیچے سب کچھ
**BNB Chain ٹیسٹ نیٹ** پر ہوتا ہے، جہاں BNB مفت ٹیسٹ رقم ہے، اس لیے آپ کچھ نہیں کھو سکتے۔

## 1. والیٹ حاصل کریں

والیٹ ایک ایپ ہے جو آپ کا کرپٹو رکھتی ہے اور ٹرانزیکشن سائن کرتی ہے۔ BNB Chain سپورٹ کرنے والا والیٹ انسٹال کریں، جیسے
MetaMask، Trust Wallet یا Rabby۔

بناتے وقت ایپ ایک **سیڈ فریز** (12 یا 24 الفاظ) دکھاتی ہے۔ اسے کاغذ پر لکھیں اور آف لائن رکھیں۔ جس کے پاس یہ ہو وہ آپ کے والیٹ کو
کنٹرول کرتا ہے۔ Agentic Starter سے کوئی بھی کبھی یہ نہیں مانگے گا۔

## 2. مفت ٹیسٹ BNB لیں

1. [agenticstarter.xyz](https://agenticstarter.xyz?lang=ur) کھولیں اور **Connect** دبائیں۔ سائٹ آپ کے والیٹ سے
   **BNB Smart Chain Testnet** (chain 97) پر جانے کو کہے گی۔ منظور کریں۔
2. اپنے والیٹ کا پتہ کاپی کریں (یہ `0x` سے شروع ہوتا ہے)۔
3. BNB Chain ٹیسٹ نیٹ فاسٹ کھولیں، پتہ پیسٹ کریں اور tBNB مانگیں۔ ایک دو منٹ میں آ جاتا ہے۔ [bnbchain.org/en/testnet-faucet](https://www.bnbchain.org/en/testnet-faucet)

لانچ پیڈ پر [Start صفحہ](https://agenticstarter.xyz/start?lang=ur) یہی مراحل دکھاتا ہے اور مکمل ہونے پر نشان لگاتا ہے۔

## 3. Agent ID لیں

بانڈنگ کرو پر خریدنے کے لیے آپ کے والیٹ میں **Agent ID** چاہیے۔ ٹیسٹ نیٹ پر یہ مفت ہے: کوئی بھی ٹوکن صفحہ کھولیں اور
**Get Agent ID** دبائیں۔ آپ صرف تھوڑی ٹیسٹ گیس دیتے ہیں۔

## 4. اپنی پہلی ٹریڈ کریں

اسی ٹوکن صفحے پر تھوڑا خریدیں، پھر کچھ حصہ بیچیں۔ پیش رفت بار کو PancakeSwap کی طرف بڑھتے دیکھیں۔ بیچنے کے لیے کبھی Agent ID
نہیں چاہیے۔

## 5. اپنا ٹوکن لانچ کریں

[Launch](https://agenticstarter.xyz/launch?lang=ur) کھولیں، نام، سمبل اور لوگو لکھیں، اور **Open in Telegram** دبائیں۔ ہمارا بوٹ Agen
آپ کے والیٹ کے لیے لانچ کرتا ہے اور گیس دیتا ہے۔ تفصیل: [ٹوکن لانچ کریں](/ur/guide/launch#testnet-telegram)۔

## ساتھ ہی: ایئرڈراپ

ان میں سے ہر قدم پر [ایئرڈراپ پوائنٹس](/ur/token/airdrop) بھی ملتے ہیں: لانچ، ٹریڈ، روزانہ کوئز اور مزید۔

## الفاظ جو آپ دیکھیں گے

"کرو"، "گریجویشن" یا "گیس" کا مطلب معلوم نہیں؟ [اصطلاحات](/ur/guide/glossary) دیکھیں۔ اب بھی الجھن ہے؟ ہر سائٹ کے کونے میں چیٹ
بلبلہ Agen سے پوچھیں، یا ہمارے Telegram گروپ میں۔
