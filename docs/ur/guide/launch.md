# ٹوکن لانچ کریں

اپنے ایجنٹ کو بتائیں کیا لانچ کرنا ہے، پیش نظارہ دیکھیں، منظور کریں۔ بس اتنا ہی۔

```text
Launch a token on Agentic Starter: name "Nova Agent", symbol NOVA, description "Scouts fresh launches",
logo https://…/nova.png, X @nova_agent, and buy 0.2 BNB of it in the same transaction.
Show me the preview first and wait for my OK.
```

ایجنٹ چلاتا ہے:

```bash
agentic create --name "Nova Agent" --symbol NOVA \
  --description "Scouts fresh launches" --logo https://…/nova.png --twitter @nova_agent \
  --telegram https://t.me/nova_agent --buy 0.2
agentic execute --request-id <id>
```

پیش نظارے سے پہلے CLI ایسا salt ڈھونڈتا ہے جس سے ٹوکن کا پتہ `AAAA` پر ختم ہو۔ اس میں چند سیکنڈ لگتے ہیں۔

ویب سائٹ پر لانچ فارم تین مراحل میں چلتا ہے۔ اپنے آئیڈیا کے بارے میں ایک جملہ لکھیں اور **Fill it in** دبائیں تاکہ نام، سمبل اور تفصیل
مل جائے جسے آپ بدل سکتے ہیں۔ لوگو ڈالیں: یہ IPFS پر پن ہوتا ہے اور پرامپٹ `ipfs://` لنک استعمال کرتا ہے (CLI میں `--logo ./nova.png`
یہی کرتا ہے)۔ پھر منتخب کریں کہ تخلیق کار کی فیس کہاں جائے، پیش نظارہ کارڈ دیکھیں، اور اپنے ایجنٹ کے لیے پرامپٹ کاپی کریں۔ کرو سمیولیٹر ہر
مرحلے پر قیمت اور مارکیٹ کیپ دکھاتا ہے۔

| خانہ | حد |
| --- | --- |
| نام | 1–32 حروف |
| سمبل | 2–10 بڑے حروف یا ہندسے۔ AGNT، BNB، BTC، ETH، USDT، USDC اور CAKE جیسے ٹکر محفوظ ہیں |
| نام اور سمبل کی رسم الخط | ہر نام میں ایک ہی حروف تہجی، اس لیے دوسری زبانوں کے ہم شکل حروف مسترد ہو جاتے ہیں |
| میٹا ڈیٹا (تفصیل، لوگو URL، لنکس) | آن چین محفوظ، تقریباً 1 KB تک |
| لوگو | `https://` / `ipfs://` URL، یا 1 MB تک کی مقامی PNG، JPG، GIF یا WebP فائل (IPFS پر اپ لوڈ) |
| پہلی خرید | اختیاری، Agent ID ضروری، والیٹ حد لاگو |
| X | لنک یا `@handle` (ہینڈل کے طور پر محفوظ ہوتا ہے) |
| Telegram | صرف `t.me` لنک |
| لانچ فیس | مین نیٹ پر {{P.mainnet.launchFeeBnb}} BNB، ٹیسٹ نیٹ پر اور پرکس والے AGNT اسٹیکرز کے لیے مفت، ساتھ میں گیس |
| جوڑا | BNB۔ دوسرے جوڑے بعد میں آئیں گے |

ٹوکنز پر نہ ٹیکس ہے، نہ mint فنکشن، نہ مالک۔

## تخلیق کار کی فیس کہاں جاتی ہے

| آپشن | CLI | ویب سائٹ |
| --- | --- | --- |
| آپ کا لانچ والیٹ (ڈیفالٹ) | — | فیس والیٹ خالی چھوڑیں |
| کوئی اور والیٹ | `--fee-to 0xWallet:100` | **Creator fee wallet** خانہ |
| تقسیم، زیادہ سے زیادہ 10 وصول کنندگان | `--fee-to 0xA:60,0xB:40` | لانچ کے بعد My tokens میں سیٹ کریں |
| X یا GitHub اکاؤنٹ | `--fee-to 0xA:80,x:@alice:20` | لانچ کے بعد My tokens میں سیٹ کریں |
| ٹریڈرز کو کیش بیک | `--cashback` | **Reward mode → Cashback** |

اکاؤنٹ کے حصے ایک ایسکرو میں انتظار کرتے ہیں جب تک اکاؤنٹ کا مالک اکاؤنٹ ثابت کر کے والیٹ نہ جوڑ لے؛ کلیم نہ ہونے والے حصے 90 دن بعد
تخلیق کار کو واپس چلے جاتے ہیں۔ تقسیم کی تبدیلی تجویز کرنے کے 24 گھنٹے بعد لاگو ہوتی ہے۔ دیکھیں [فیس](/ur/guide/fees#creator-fee-options)۔

## ٹیسٹ نیٹ: Telegram بوٹ سے لانچ {#testnet-telegram}

BNB Chain ٹیسٹ نیٹ پر آپ ایجنٹ سیٹ کیے بغیر لانچ کر سکتے ہیں۔ ہمارا بوٹ Agen ایجنٹ بن کر گیس دیتا ہے؛ آپ کا والیٹ تخلیق کار کے
طور پر درج ہوتا ہے۔

1. [Launch](https://agenticstarter.xyz/launch?lang=ur) کھولیں، ٹوکن کا مالک بننے والا والیٹ جوڑیں اور نام، سمبل، لوگو، تفصیل اور لنکس بھریں۔
2. **Open in Telegram** دبائیں۔ بوٹ آپ کے لانچ کوڈ کے ساتھ کھلتا ہے اور پیش نظارہ دکھاتا ہے۔
3. **🚀 Launch now** دبائیں۔ چند سیکنڈ بعد بوٹ ٹوکن پتے کے ساتھ جواب دیتا ہے، اور ٹوکن Explore صفحے پر نظر آتا ہے۔

اگر Telegram نہ کھلے تو صفحے سے `/launch ABCD2345` لائن کاپی کر کے بوٹ کو بھیجیں۔ کوڈ 24 گھنٹے درست رہتے ہیں اور ایک بار چلتے
ہیں۔ ہر Telegram اکاؤنٹ روزانہ 3 ٹوکن تک لانچ کر سکتا ہے۔

بوٹ آپ کے لیے نہیں خریدتا۔ خریدنے کے لیے ٹوکن صفحہ کھولیں، مفت ٹیسٹ نیٹ Agent ID لیں اور ٹیسٹ BNB سے خریدیں۔ ٹیسٹ نیٹ پر ٹوکن
**{{P.testnet.graduationTargetBnb}} BNB** پر گریجویٹ ہوتا ہے۔

پھر لانچ صفحہ **لانچ کے بعد کی کٹ** دکھاتا ہے: تیار X پوسٹ، Telegram متن، شیئر تصویر اور آپ کی ویب سائٹ کے لیے ایمبیڈ ویجٹ۔
[My tokens](https://agenticstarter.xyz/me?lang=ur) پر آپ:

| کام | تفصیل |
| --- | --- |
| پیش رفت دیکھیں | کرو کی پیش رفت، جمع شدہ BNB، ہولڈرز |
| تخلیق کار انعامات کلیم کریں | آپ کے ٹوکن کی ہر کرو فیس کا 20%، BNB میں، گریجویشن تک، ساتھ میں گریجویشن بونس |
| معلومات اپ ڈیٹ کریں | مین نیٹ پر {{P.mainnet.metaUpdateFeeBnb}} BNB میں لوگو، تفصیل اور لنکس بدلیں۔ نام اور سمبل کبھی نہیں بدلتے۔ ہولڈرز کو 7 دن تک اطلاع دکھتی ہے اور پوری تاریخ عوامی رہتی ہے۔ |
| فیس کی تقسیم | نئی تقسیم تجویز کریں؛ یہ 24 گھنٹے بعد لاگو ہوتی ہے |
| تخلیق کار منتقل کریں | نیا تخلیق کار والیٹ تجویز کریں؛ جب وہ ٹوکن صفحے پر قبول کرے تو ذمہ داری اس کے پاس چلی جاتی ہے۔ کمائے ہوئے انعامات آپ ہی کلیم کر سکیں گے۔ |
| تخلیق کار الاٹمنٹ | جہاں یہ لاگو ہو (آج ٹیسٹ نیٹ پر)، گریجویشن کے بعد ان لاک شدہ حصہ کلیم کریں |
| X کی تصدیق | ٹوکن صفحے پر تصدیق شدہ تخلیق کار بیج دکھانے کے لیے اپنا X اکاؤنٹ جوڑیں |

مین نیٹ پر گریجویٹ ہونے والے پہلے 100 ٹوکنز کے تخلیق کاروں کو مستقل **Genesis Creator** بیج ملتا ہے۔
