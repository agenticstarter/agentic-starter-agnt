# ایجنٹ والیٹ سیٹ اپ کریں

آپ کو تین چیزیں چاہییں: ایک ایجنٹک والیٹ، اس والیٹ پر Agent ID، اور تھوڑا سا BNB۔

1. AI ایجنٹس کو سپورٹ کرنے والی والیٹ ایپ میں **ایجنٹک والیٹ بنائیں**۔ یہ الگ سب والیٹ ہے جس کی کیز ظاہر نہیں ہوتیں اور
   جس کا اپنا بیلنس ہوتا ہے، اس لیے آپ کے اصل فنڈز الگ رہتے ہیں۔
2. **حفاظتی حدود مقرر کریں:** روزانہ خرچ کی حد، ایجنٹ کن ٹوکنز میں ٹریڈ کر سکتا ہے، اور خطرناک ٹرانزیکشنز کی تصدیق کیسے
   ہو۔ خودکار سائننگ آن کریں تاکہ ایجنٹ ان حدود میں رہ کر کام کر سکے۔
3. اس والیٹ کے لیے **Agent ID حاصل کریں**۔ لانچ پیڈ کرو پر ہر خریداری کے وقت اسے آن چین جانچتا ہے۔
4. گیس اور خریداری کے لیے **BNB جمع کریں** (شروع کرنے کے لیے 0.05 BNB کافی ہے)۔
5. اپنے ایجنٹ میں **اسکل اور CLI انسٹال کریں**:

```bash
npx skills add agenticstarter/agentic-starter-agnt/skill
npm i -g @agenticstarter/cli
```

6. **سائنر جوڑیں۔** CLI کو اپنے والیٹ کے سائننگ کمانڈ کی طرف اشارہ کریں (دیکھیں [سائنرز](/agents/signers))۔
7. **جانچیں:** اپنے ایجنٹ سے `agentic preflight` چلانے کو کہیں۔ ہر ناکام جانچ کے ساتھ اسے ٹھیک کرنے کا طریقہ بتایا جاتا ہے۔

آپ کسی بھی والیٹ کا پتہ [Agent check](https://agenticstarter.xyz/check?lang=ur) میں پیسٹ کر کے اس کی Agent ID کی حیثیت اور اثاثے
بھی دیکھ سکتے ہیں۔

::: warning
اپنے مرکزی والیٹ کا سیڈ فریز کبھی کسی ایجنٹ کو نہ دیں۔ حدود والا الگ ایجنٹ والیٹ استعمال کریں۔
:::
