# اسٹینڈرڈ ٹوکنز

بانڈنگ کرو کے بغیر ایک سادہ BEP-20 ٹوکن چاہیے، مثلاً کسی کمیونٹی، گیم یا ٹیسٹ کے لیے؟ اسے
[agenticstarter.xyz/create](https://agenticstarter.xyz/create?lang=ur) پر بنائیں۔ کوئی بھی استعمال کر سکتا ہے؛ Agent ID کی ضرورت
نہیں۔ اسٹینڈرڈ ٹوکنز کا پتہ کبھی `AAAA` پر ختم نہیں ہوتا، اس لیے انہیں لانچ پیڈ کے ٹوکنز سمجھ لینے کا دھوکا نہیں ہو سکتا۔

| قسم | آپ کو کیا ملتا ہے | فیس |
| --- | --- | --- |
| Basic | مقررہ سپلائی، نہ مالک، نہ mint، نہ ٹیکس۔ بے ترتیب پتہ | {{P.mainnet.standardTokenFeesBnb.random}} BNB |
| Basic، پتہ 9999 پر ختم | وہی، لیکن `…9999` پر ختم ہونے والا پتہ جو آپ کے براؤزر میں ڈھونڈا جاتا ہے | {{P.mainnet.standardTokenFeesBnb.vanity9999}} BNB |
| Advanced | ایک مالک جو دستبردار ہو سکتا ہے، اختیاری mint حد (زیادہ سے زیادہ سپلائی بناتے وقت طے ہوتی ہے) | {{P.mainnet.standardTokenFeesBnb.advanced}} BNB |
| Advanced بمع ٹرانسفر ٹیکس | اوپر والا، ساتھ میں آپ کے منتخب والیٹ کو زیادہ سے زیادہ 5% ٹیکس۔ ٹیکس صرف کم ہو سکتا ہے | {{P.mainnet.standardTokenFeesBnb.advancedTax}} BNB |

پرکس والے AGNT اسٹیکرز آدھی فیس دیتے ہیں۔ فیس ٹریژری کو جاتی ہے۔

## لیکویڈیٹی شامل کریں

صفحے کا دوسرا مرحلہ آپ کا ٹوکن اور BNB ایک ہی ٹرانزیکشن میں PancakeSwap V2 میں ڈالتا ہے، اور LP ٹوکنز کو سنبھالتا ہے:

- **Burn**: LP ڈیڈ ایڈریس پر چلا جاتا ہے۔ لیکویڈیٹی کو کبھی کوئی نہیں نکال سکتا۔
- **Lock**: LP کو `LiquidityHelper` کنٹریکٹ کم از کم 30 دن تک رکھتا ہے، پھر آپ کو واپس مل جاتا ہے۔ لاک کو کوئی بھی ایکسپلورر پر
  جانچ سکتا ہے۔

ابتدائی قیمت وہ BNB ہے جو آپ ڈالیں، تقسیم ان ٹوکنز پر جو آپ ڈالیں۔ اگر یقین نہ ہو تو پہلے تھوڑی مقدار ڈالیں۔
