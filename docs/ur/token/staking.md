# اسٹیکنگ

لانچ پیڈ فیس سے BNB کمانے کے لیے `AGNTStaking` کنٹریکٹ میں $AGNT اسٹیک کریں۔

- اسٹیکرز کو **ہر کرو فیس کا 30%** ملتا ہے، BNB میں۔
- آنے والا ہر BNB **اگلے 7 دن میں بتدریج** تقسیم ہوتا ہے، اس دوران اسٹیک رکھنے والے سب میں بانٹا جاتا ہے۔ ادائیگی سے ذرا پہلے اسٹیک
  کرنے سے اسے ہتھیایا نہیں جا سکتا۔
- جب کوئی اسٹیک نہ کر رہا ہو تب آنے والا BNB انتظار کرتا ہے اور پہلے اسٹیکر کے شامل ہونے پر بتدریج تقسیم ہونا شروع ہوتا ہے۔
- کوئی لاک نہیں: کبھی بھی ان اسٹیک کریں؛ کبھی بھی BNB کلیم کریں۔

## فوائد

جو AGNT **کم از کم 7 دن** اسٹیک رہا ہو وہ فوائد کے لیے گنا جاتا ہے۔ مزید AGNT شامل کرنے سے پوری پوزیشن کی 7 دن کی گھڑی دوبارہ شروع ہو
جاتی ہے، اس لیے فوائد ایک بلاک کے لیے خریدے نہیں جا سکتے۔

| فائدہ | شرط |
| --- | --- |
| لانچ پیڈ پر مفت لانچ | 7 دن کے لیے 100,000 AGNT اسٹیک |
| اسٹینڈرڈ ٹوکن فیکٹری پر آدھی قیمت | 7 دن کے لیے 100,000 AGNT اسٹیک |
| Snapshot ووٹ کا وزن | 7 دن اسٹیک رہنے والا کوئی بھی AGNT (`maturedStake`) |
| سیزن 2 ایئرڈراپ ملٹی پلائر | سیزن 2 کے ساتھ اعلان ہوگا |

حد کو مالک Safe بدل سکتا ہے؛ ہر تبدیلی [Site integrity](https://agenticstarter.xyz/integrity?lang=ur) پر عوامی ہے۔

اسٹیکنگ $AGNT کی لسٹنگ کے ساتھ کھلتی ہے۔

| فنکشن | اثر |
| --- | --- |
| `stake(amount)` | AGNT جمع کریں (پہلے approve) |
| `unstake(amount)` | AGNT نکالیں، انعامات برقرار رہتے ہیں |
| `claim()` | جمع شدہ BNB نکالیں |
| `pendingBnb(address)` | جمع شدہ BNB دیکھیں |
| `maturedStake(address)` | وہ AGNT جو فوائد اور ووٹوں کے لیے گنا جاتا ہے |
| `hasPerks(address)` | فوائد کی حد سے اوپر ہو تو True |
