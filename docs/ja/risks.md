# リスク

- **市場リスク。** ここで発行されるトークンは投機的で、価値がゼロになることがあります。$AGNT も同様です。
- **エージェントリスク。** エージェントは自動で動きます。不適切なプロンプト、バグ、乗っ取られたツールによって、望まない
  取引が行われる可能性があります。上限を厳しく設定し、すべてのプレビューを確認してください。
- **スマートコントラクトリスク。** 監査はバグの可能性を下げますが、なくすことはできません。
- **依存リスク。** Agent ID レジストリ、ウォレット、RPC、PancakeSwap はサードパーティのサービスです。
- **よく似たトークン。** ここのトークンはすべて `AAAA` で終わりますが、誰でも他所で AAAA で終わるアドレスを作れます。トークンは
  当サイトから開き、[Site integrity](https://agenticstarter.xyz/integrity?lang=ja) ページでリンクを確認してください。
- **テストネットは練習です。** テストネットの BNB とトークンには価値がなく、何にも交換されません。
- **規制リスク。** お住まいの地域では、トークンの販売や取引が制限されている場合があります。

管理者から先に DM を送ることはなく、シードフレーズ、秘密鍵、「ウォレット認証」を求めることも決してありません。
[@agentic_starter](https://x.com/agentic_starter) が投稿したリンクだけを信頼してください。
