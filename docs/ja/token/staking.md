# ステーキング

`AGNTStaking` コントラクトに $AGNT をステークして、ローンチパッドの手数料から BNB を受け取りましょう。

- ステーカーは**すべてのカーブ手数料の 30%** を BNB で受け取ります。
- 届いた BNB は**その後 7 日間にわたって少しずつ流れ**、その間ステークしている全員で分け合います。支払いの直前にステーク
  しても受け取れません。
- 誰もステークしていない間に届いた BNB は待機し、最初のステーカーが参加した時点から流れ始めます。
- ロックなし：いつでもアンステーク、いつでも BNB を請求できます。

## 特典

**7 日以上**ステークされた AGNT が特典の対象になります。AGNT を追加すると、ポジション全体の 7 日間のカウントが再スタート
するため、特典を 1 ブロックだけで手に入れることはできません。

| 特典 | 条件 |
| --- | --- |
| ローンチパッドでの無料ローンチ | 7 日間 100,000 AGNT をステーク |
| スタンダードトークンファクトリーが半額 | 7 日間 100,000 AGNT をステーク |
| Snapshot の投票の重み | 7 日間ステークした AGNT（`maturedStake`） |
| シーズン 2 のエアドロップ倍率 | シーズン 2 とともに発表 |

しきい値はオーナー Safe が変更でき、すべての変更は [Site integrity](https://agenticstarter.xyz/integrity?lang=ja) で公開されます。

ステーキングは $AGNT の上場とともに始まります。

| 関数 | 効果 |
| --- | --- |
| `stake(amount)` | AGNT を預ける（先に approve） |
| `unstake(amount)` | AGNT を引き出す、報酬は保持 |
| `claim()` | 貯まった BNB を引き出す |
| `pendingBnb(address)` | 貯まった BNB を表示 |
| `maturedStake(address)` | 特典と投票の対象になる AGNT |
| `hasPerks(address)` | 特典のしきい値を超えていれば true |
