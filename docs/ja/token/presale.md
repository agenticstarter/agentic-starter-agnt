# プレセール

BNB Chain に対応したブラウザウォレットで [presale.agenticstarter.xyz](https://presale.agenticstarter.xyz?lang=ja) から参加できます。
KYC もメールも不要で、必要なのはウォレットだけです。公開ラウンドは 1 回のみで、**全員が同じ価格**です。

::: warning プレセールページでのみ購入してください
誰にも BNB を送らないでください。コントラクトアドレスにも送らないでください。通常の送金は拒否されます。管理者から先に
DM を送ることはありません。コントラクトアドレスを [Site integrity](https://agenticstarter.xyz/integrity?lang=ja) と照合してください。
:::

## 価格の仕組み（「250+」）

| 集まった額 | 何が起きるか |
| --- | --- |
| {{P.presale.softCapBnb}} BNB 未満（ソフトキャップ） | セールは不成立。購入者全員がプレセールページで BNB の 100% を返金できます |
| {{P.presale.softCapBnb}}〜{{P.presale.floorCapBnb}} BNB | 全員がフロア価格で購入：**1 BNB = {{P.presale.floorAgntPerBnb|n}} AGNT**。売れ残りの AGNT は確定時にバーン |
| {{P.presale.floorCapBnb}} BNB 超 | 販売分の {{P.presale.saleTokens|n}} AGNT を、拠出した BNB の割合で分け合います。全員が同じ最終価格を支払い、BNB が増えるごとに少しずつ高くなります。ハードキャップはありません |

セール終了時の例（1 BNB を送った購入者の場合）：

| 集まった合計 | 1 BNB で買える量 |
| --- | --- |
| 120 BNB | 1,000,000 AGNT（売れ残りの 1.3 億 AGNT はバーン） |
| 250 BNB | 1,000,000 AGNT |
| 500 BNB | 500,000 AGNT |
| 1,000 BNB | 250,000 AGNT |

ページにはリアルタイムの価格、シミュレーター、自分の状況（「Where is my money?」）が表示されます。セールが
{{P.presale.floorCapBnb}} BNB を超えている間は、他の人が購入するにつれて受け取れる AGNT の量が少し減ることがありますが、あなたの BNB は
そのままです。

| 項目 | 値 |
| --- | --- |
| フロア価格 | 1 BNB = {{P.presale.floorAgntPerBnb|n}} AGNT、{{P.presale.floorCapBnb}} BNB が集まるまで |
| 販売する AGNT | {{P.presale.saleTokens|n}}（供給量の 25%）。セール開始前にコントラクトへ預け入れ済み |
| ソフトキャップ | {{P.presale.softCapBnb}} BNB |
| 1 ウォレットあたり | 合計で最小 {{P.presale.perWalletBnb.0}} BNB、最大 {{P.presale.perWalletBnb.1}} BNB |
| アーリーボーナス | 最初の {{P.presale.earlyBonusHours}} 時間の購入に AGNT を +{{P.presale.earlyBonusPct}}%。プールは {{P.presale.earlyBonusCap|n}} AGNT が上限（埋まった場合は按分）、クレーム時に支払い |
| 期間 | {{P.presale.days}} 日間。開始・終了時刻は UTC で、プレセールページに表示 |
| クレーム | 上場時に 100% |

拠出額がウォレットの上限を超えた場合、超過分の BNB は同じトランザクションで返金されます。

## あなたの BNB はどう守られるか

1. あなたの BNB はプレセールコントラクトに残ります。セールが終わるまで、チームは引き出せません。
2. ソフトキャップに届かなければセールは不成立となり、購入者全員がプレセールページで 100% を返金できます。
3. セール後、BNB の 80% が上場時に PancakeSwap のプールへ入り、LP はバーンされます。各ステップはプレセールページの上場
   チェックリストからリンクされています。[上場](/ja/token/listing)を参照。

## 友達を招待する

プレセールページでウォレットを接続すると、招待リンク（`presale.agenticstarter.xyz/?ref=<あなたのウォレット>`）を取得
できます。誰かがこのリンクから購入すると、プレセールコントラクトが購入と一緒に招待を記録します（`contributeWithRef`）。
購入者の支払額は増えず、割当量も変わりません。

- あなたのリンクから 0.05 BNB 以上購入したウォレットごとに **エアドロップポイント100** が加算されます（クエスト Q6、最大
  50人）。
- 自分でプレセールに参加するのはクエスト Q5：0.05 BNB から **+500ポイント**、その後 0.01 BNB ごとに +100（最大10,000）、
  最初の48時間の購入は **500** 追加。エアドロップ用と別のウォレットで購入した場合は、エアドロップページで一度連携して
  ください（Q5 カード）。
- ポイントは、あなたのウォレットがエアドロップの必須クエスト 3 つを終えると反映されます。
- 自分のリンクでの購入は対象外で、返金された購入は除外されます。

## セール終了後

1. **確定**：BNB はトレジャリー Safe へ送られ、売れ残りの AGNT はバーンされます。
2. 翌日 14:00 UTC に**上場**：BNB の 80% が最終プレセール価格で AGNT/BNB プールに入り、LP がバーンされ、その後クレームが
   開きます。
3. プレセールページで AGNT（とアーリーボーナス）の 100% をクレームします。

各ステップは、トランザクションへのリンクとともにプレセールページの上場チェックリストでチェックされます。そこでリマインダー
（Telegram またはカレンダー）をオンにすると、クレームが開くタイミングがわかります。

## 返金

拠出は確定扱いですが、例外が 2 つあります。

- **セール不成立**：ソフトキャップに届かずに終了した場合。返金は自動的に開きます。
- **クレームが開く前に、チームが返金モードを開く場合。** 確定後にこれが起きた場合、全購入者が全額返金を受けられるよう、
  チームはまず全額をプレセールコントラクトに戻す必要があります。

どちらの場合も、プレセールページで BNB の 100% を返金できます。
