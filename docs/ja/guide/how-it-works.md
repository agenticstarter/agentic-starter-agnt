# 仕組み

すべてのトークンは同じ道をたどります：**ローンチ → ボンディングカーブ → PancakeSwap へ卒業**。

<div class="flow">
  <div><b>ローンチ</b><small>10 億トークンを作成。8 億はカーブへ、2 億は流動性用に保持。</small></div>
  <div class="arrow">→</div>
  <div><b>ボンディングカーブ</b><small>エージェントが買い、誰でも売れる。買うたびに価格上昇。取引ごとに 1% の手数料。</small></div>
  <div class="arrow">→</div>
  <div><b>卒業</b><small>{{P.mainnet.graduationTargetBnb}} BNB で PancakeSwap に上場。LP バーン、カーブ終了。</small></div>
</div>

## 1. エージェントウォレットを接続する

エージェントは、あなたが日次上限を決めたエージェントウォレットで動きます。カーブで買うにはウォレットに **Agent ID** が必要
です。[エージェントウォレットの設定](/ja/guide/agent-wallet)を参照。テストネットではどのウォレットでも無料で Agent ID を取得
できます。

## 2. ボンディングカーブでローンチ

ローンチすると、総供給量 **1,000,000,000** 固定のトークンが作られます：

| 区分 | 数量 | 用途 |
| --- | --- | --- |
| カーブ | 800,000,000 | ボンディングカーブに沿って販売 |
| 流動性 | 200,000,000 | 卒業時に PancakeSwap へ追加 |

トークンアドレスは必ず **`AAAA`** で終わります。これはブランドの印であって保証ではないので、トークンは必ず
[agenticstarter.xyz](https://agenticstarter.xyz?lang=ja) から開くか、[Site integrity](https://agenticstarter.xyz/integrity?lang=ja) で確認してください。

価格は定積公式に従います。買うと上がり、売ると下がります。作成者はローンチのトランザクションで最初の購入ができ、全員と同じ
ウォレット上限が適用されます。

カーブ上のルール：

- **購入：** Agent ID 保有者のみ。購入のたびにオンチェーンで確認。
- **売却：** 誰でも可。approve のトランザクションは不要。売却は決して停止されません。
- **ウォレット上限：** メインネットでは 1 ウォレットあたり供給量の {{P.mainnet.walletCapBps|pct}}（テストネットは {{P.testnet.walletCapBps|pct}}）。
  上限を超える購入は切り詰められ、残りの BNB は同じトランザクションで返金されます。この上限のため、メインネットで卒業
  するには少なくとも **{{P.mainnet.minWalletsToGraduate}} の異なるウォレット**が必要です
  （テストネットは {{P.testnet.minWalletsToGraduate}}）。あと何人のホルダーが必要かはトークンページに表示されます。
- **手数料：** 売買ごとに 1%。[手数料](/ja/guide/fees)を参照。
- **送金：** ロック。トークンはカーブとトレーダーの間でしか動かないため、誰も上限を回避したり先にプールを作ったりできません。

各トークンはローンチ時の設定（卒業目標、ウォレット上限、卒業手数料とボーナス）を保持します。チームが後で設定を変えても、
新しいトークンにだけ適用されます。

## 3. PancakeSwap へ卒業

カーブが目標（メインネット **{{P.mainnet.graduationTargetBnb}} BNB**、テストネット
**{{P.testnet.graduationTargetBnb}} BNB**）に達すると、卒業が実行され：

1. 送金を永久にアンロックし、
2. 卒業手数料を受け取ります。目標額の {{P.mainnet.graduationFeeBps|pct}}、上限 2 BNB
   （メインネットの目標では {{P.mainnet.graduationFeeBnb}} BNB）。その 5 分の 1（{{P.mainnet.creatorBonusBps|pct}}）は
   **作成者への卒業ボーナス**、残りはトレジャリーへ。
3. 流動性用の 2 億トークンと残りの BNB を PancakeSwap V2 に追加し、LP を直接バーンアドレスにミントして、流動性を永久に
   ロックします。

カーブを満たす購入が卒業を実行します。そうならない場合（たとえばトークンに最低カーブ期間がある場合）は、目標に達したあと
誰でも `graduate(token)` を呼び出せます。上場価格はカーブ最後の価格と同じなので、価格の跳ね上がりはありません。卒業後は
プラットフォーム手数料がなく、Agent ID の有無にかかわらず誰でも PancakeSwap で取引できます。

::: tip カーブを満たす購入が上場コストを払う
最後の購入が移行を実行するため、ガスが多めにかかります。CLI はこれを `nearGraduation` と表示します。
:::

## 作成者への割り当て（テストネット）

テストネットでは、作成者は供給量の {{P.testnet.creatorAllocBps|pct}} をローンチ価格で、ウォレット上限の外で受け取ります。
これはローンチパッドが保管し、卒業前は売却できず、卒業後 {{P.testnet.creatorAllocUnlockDays}} 日かけて
リニアにアンロックされます。メインネットでは現在 {{P.mainnet.creatorAllocBps|pct}} に設定されています。チームが引き上げられるのは
新しいトークンに対してのみで、すべての変更は [Site integrity](https://agenticstarter.xyz/integrity?lang=ja) で公開されます。

## 安全スイッチ

コントラクトにアップグレード可能なプロキシはありません。オーナーは 2-of-2 のマルチシグ（Safe）です。ガーディアンウォレットは
緊急時に**新規ローンチと購入**を停止できますが、再開できるのはオーナーだけです。**売却、返金、請求、卒業は決して停止
されません。**モジュール（Agent ID の確認、トークンテンプレート、上場アダプター、手数料エスクロー、ステーキング特典）の
入れ替えには、公開の **48 時間タイムロック**の待機が必要です。メインネットでは、手数料と卒業目標は 7 日間で最大 ±50% までしか
動かせず、常にコントラクトに書かれた上限の範囲内です。
