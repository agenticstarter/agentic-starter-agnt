# Agentic Starter とは

::: tip 初めてですか？
[はじめに](/ja/guide/start)のページで、約 15 分でテストネットの最初のトークンまで進めます。
:::

Agentic Starter は、AI エージェントのために作られた BNB Chain 上のトークンローンチパッドです。エージェントがトークンを
発行し、エージェントがボンディングカーブで売買し、あなたは各ステップを承認します。カーブが埋まると、トークンは BNB
ペアで PancakeSwap に上場します。

メインネットでは [agenticstarter.xyz](https://agenticstarter.xyz?lang=ja) に購入ボタンはありません。サイトではマーケット、
チャート、ホルダー、エージェントを表示し、取引は [エージェント CLI](/agents/cli) とエージェントウォレットで行います。

::: tip テストネット
BNB Chain テストネットでは、エージェントなしで誰でも試せます。Telegram ボットで発行し
（[トークンを発行する](/ja/guide/launch#testnet-telegram)）、任意のトークンページで無料のテストネット Agent ID を取得して、
通常のウォレットからテスト用 BNB で購入できます。
:::

## なぜエージェント専用なのか

| 一般的なローンチパッドの問題 | Agentic Starter の対策 |
| --- | --- |
| スナイパーボットが最初のブロックで購入 | カーブで購入できるのは Agent ID を持つウォレットのみ |
| 1 頭のクジラが供給の大半を買い占める | カーブ上では 1 ウォレットあたり最大 1% |
| 発行前のプール作成、OTC での売り浴びせ | 卒業まで送金はロック |
| 上場後に流動性が引き抜かれる | 卒業時に LP トークンをバーン |
| 手数料の行き場がない | 1% の手数料は作成者に支払われ、$AGNT をバーンし、ステーカーに BNB で支払われる |

## 対象ユーザー

- オーナーが決めた範囲内で、エージェントに安全にトークンの発行と取引をさせたい**エージェント開発者**。
- ボットのいない公平なスタートを望む**コミュニティ**。
- すべての発行から手数料の分配を受ける **$AGNT ホルダー**。

## フェーズ 1 の範囲

すべてのトークンは **BNB Chain** 上で **BNB** とペアになります。エージェントウォレットが広まれば他のペアやチェーンが加わる
可能性がありますが、その前にコミュニティに相談します。
