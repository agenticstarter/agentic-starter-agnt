# Telegram コミュニティ

| 場所 | リンク | 用途 |
| --- | --- | --- |
| チャンネル | [t.me/agenticstarter](https://t.me/agenticstarter) | お知らせ専用 |
| グループ | [t.me/agentic_starter](https://t.me/agentic_starter) | チャット、毎日のクイズ、Agen への質問 |
| Agen（ボット） | [t.me/agenticstarter_bot](https://t.me/agenticstarter_bot) | エアドロップ Mini App、リマインダー、テストネットのローンチ |

## グループに参加する

新しいメンバーは、書き込む前にウェルカムメッセージの **I'm not a bot** を押します。ウェルカムと参加のメッセージは、チャットを
すっきり保つため少し経つと削除されます。

## Agen に聞く

グループのメッセージのどこかに `@Agen` と書いてください。例：`@Agen 卒業の仕組みは？`。Agen はこのドキュメントとライブデータをもとに、あなたの言語で答えます。プロジェクトの質問は皆が見られるようグループでのみ答え、個別チャットではあなた自身のこと（ローンチ、ポイント、リマインダー）を手伝います。

あなたやプロジェクトを危険にさらしかねない質問（鍵、シードフレーズ、コントラクトへの攻撃方法）や、Agentic Starter と関係のない
質問には、Agen は答えません。何度も聞かれる質問には、該当するドキュメントページへのリンクが返ります。

## コマンド

| コマンド | 場所 | 内容 |
| --- | --- | --- |
| `@Agen <質問>` | グループ | Agen に質問（`/agen` も可） |
| `/points` | 個別チャット | あなたのエアドロップポイントと不足分 |
| `/earn` | グループまたは個人 | ポイントのためにまだできること（大きい順） |
| `/challenge` | グループまたは個別チャット | 今日のチャレンジと連続記録 |
| `/help` | グループまたは個別チャット | すべてのコマンド |
| `/watch <token>` | 個別チャット | 80%、90%、卒業時にメッセージ |
| `/remind presale` · `claim` · `mainnet` | 個別チャット | 開始時にメッセージ |
| `/report` | グループ内のメッセージに返信 | 詐欺や偽の管理者をチームに報告 |
| `/launch <code>` | 個別チャット | ウェブサイトからのテストネットローンチ（[ローンチ](/ja/guide/launch#testnet-telegram)を参照） |
| `/faucet` | 個別チャット | テスト BNB の入手先（Q2 のあと、エアドロップページで 1 回補給を受けられます） |
| `/settings` | 個別チャット | Agen から届く個別メッセージを選ぶ：ボックス、クイズ通知、まとめなど |
| `/agentid` | 個別チャット | Agent ID を確認 |

Agen からの個別メッセージにはすべて **この通知をオフ** ボタンがあります。いつでも `/settings` で戻せます。

## グループのルール

- 思いやりを持ちましょう。侮辱、FUD キャンペーン、スパム、他プロジェクトの宣伝は禁止です。
- リンク：公式リンクのみ（[安全のために](/ja/guide/safety)を参照）。それ以外のリンクは削除されます。
- ストライク：ひどい侮辱は即座に 1 ストライク、軽い違反は警告後に繰り返した場合。20 日間で **5 ストライク**になると BAN
  です。ストライクは 20 日で失効します。
- 管理者から先に DM を送ることはなく、鍵、シードフレーズ、BNB を求めることもありません。
- チームを装った名前（admin、support、Agentic Starter、Agen）は発言制限され、「DM して」、シードフレーズ、「ウォレットを認証」といったメッセージは削除されます。

対応が間違っていると思う場合は、グループで管理者に連絡してください。
