# スマホにアプリをインストール

Agentic Starter はスマホでアプリのように使えます。全画面表示、下部にタブ、ホーム画面からワンタップで起動。
ウェブサイトそのものなので、アップデートもアプリストアも不要です。署名のたびにウォレットが確認する点は変わりません。

## iPhone と iPad

1. **Safari** で [agenticstarter.xyz](https://agenticstarter.xyz?lang=ja) を開きます。Telegram、X、ウォレットアプリの中にいる場合は、
   まず Safari でページを開いてください。iPhone のほかのブラウザではウェブアプリを追加できないことがあります。
2. Safari のバーにある**共有**（矢印付きの四角）をタップします。見つからない場合は先に **⋯** をタップします。
3. **ホーム画面に追加**をタップし、**追加**をタップします。
4. ホーム画面から Agentic Starter を開きます。

## Android

### Chrome

1. **Chrome** で [agenticstarter.xyz](https://agenticstarter.xyz?lang=ja) を開きます。リンクが Telegram、X、ウォレットアプリの中で
   開いた場合は、右上の **⋮** をタップして先に **Chrome で開く**を選びます。そのままではインストールできません。
2. Chrome の右上にある **⋮** をタップします。
3. **アプリをインストール**または**ホーム画面に追加**をタップし、**インストール**をタップします。
4. ホーム画面またはアプリ一覧から Agentic Starter を開きます。

Chrome のページ上やアドレスバーに**インストール**ボタンが出ている場合は、それをタップしても同じです。

### Samsung Internet

1. 下部の **☰** をタップします。
2. **ページを追加** → **ホーム画面**をタップします。

### アプリファイル（APK）

ファイルで入れたい場合は [agentic-starter.apk をダウンロード](https://agenticstarter.xyz/download/agentic-starter.apk?lang=ja)（バージョン 1.0、1.7 MB）。Chrome を通して同じサイトを全画面で開きます。Android はブラウザからのインストールを許可するか一度だけ確認します。インストール前にファイルを確認してください：

- ファイルの SHA-256： `be55ac38090acbcf8ddcbf732463176306ad6a10365d9402b63fac81cd135479`
- 署名証明書の SHA-256： `A2:7C:83:5E:EE:EF:C6:39:0B:CC:79:77:53:29:DD:84:7D:E2:6D:47:93:1E:2A:A5:66:D2:86:76:AD:E9:A7:5B`

## アプリの中で

- **言語：** 左上の自分のアイコンをタップしてメニューを開き、**設定 → 言語**で一覧から選びます。
- **アプリロック：** **設定 → アプリロック**で、アプリを開く前に Face ID、指紋、端末のパスコード、または自分のパスワードを
  求めます。ロックはスマホの中だけに保存されます。
- **アバター：** メニューで自分のアイコンをタップすると、写真や色を選べます。スマホの中だけに保存され、アップロードはされません。

## よくある質問

**「アプリをインストール」が見つからない。** Play ストアで Chrome を更新し、ページを再読み込みしてください。すでに
インストール済みなら、同じメニューに**アプリを開く**と表示されます。

**安全ですか？** agenticstarter.xyz と同じサイトで、ウォレットの鍵には触れられません。どの取引でも承認のためにウォレットが
開きます。インストールは agenticstarter.xyz からだけにしてください。チームが DM でアプリのファイルやリンクを送ることはありません。

**削除するには？** ほかのアプリと同じです。アイコンを長押しして**削除**または**アンインストール**を選びます。
