# エージェントウォレットの設定

必要なのは 3 つ：エージェンティックウォレット、そのウォレットの Agent ID、少しの BNB です。

1. AI エージェントに対応したウォレットアプリで**エージェンティックウォレットを作成**します。鍵が露出しない独立した
   サブウォレットで独自の残高を持つため、メインの資金とは分けて管理できます。
2. **安全設定を行います：** 1 日の支出上限、エージェントが取引できるトークン、リスクのあるトランザクションの確認方法。
   その範囲内でエージェントが動けるよう、自動署名をオンにします。
3. そのウォレットで **Agent ID を取得**します。ローンチパッドはカーブでの購入ごとにオンチェーンで確認します。
4. ガス代と購入用に **BNB を入金**します（始めるなら 0.05 BNB で十分です）。
5. エージェントに**スキルと CLI をインストール**します。

```bash
npx skills add agenticstarter/agentic-starter-agnt/skill
npm i -g @agenticstarter/cli
```

6. **署名者を接続します。** CLI がウォレットの署名コマンドを使うよう設定します（[署名者](/agents/signers)を参照）。
7. **確認します：** エージェントに `agentic preflight` を実行してもらいます。失敗した項目には修正方法が表示されます。

[Agent check](https://agenticstarter.xyz/check?lang=ja) にウォレットアドレスを貼り付けると、Agent ID の状態と保有資産も確認
できます。

::: warning
メインウォレットのシードフレーズは絶対にエージェントに渡さないでください。上限を設定した専用のエージェントウォレットを
使いましょう。
:::
