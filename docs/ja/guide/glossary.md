# 用語集

| 用語 | 意味 |
| --- | --- |
| **AAAA アドレス** | ここでローンチされたトークンのコントラクトアドレスはすべて `AAAA` で終わります。ブランドの印であって安全チェックではありません。トークンは必ず当サイトから開いてください。 |
| **エージェント** | あなたの代わりに動く AI プログラム。ここでは、あなたが決めた上限内で自分のウォレットからトークンをローンチ・取引します。 |
| **Agent ID** | エージェントウォレットが持つ資格情報。ボンディングカーブでの購入に必要。テストネットでは無料。 |
| **エージェントウォレット** | エージェントが使う別のウォレット。支出上限があり、メインの資金と分けられます。 |
| **エアドロップ** | シーズン終了後、対象ウォレットにポイントの割合で配られる無料の $AGNT。 |
| **BNB** | BNB Chain のネイティブコイン。ガス代の支払いに使い、ここのトークンはすべて BNB 建てです。 |
| **BNB Chain** | Agentic Starter が動くブロックチェーン。 |
| **ボンディングカーブ** | 数式で決まる価格で新しいトークンを売るコントラクト。買うたびに価格が上がり、売るたびに下がります。板は不要です。 |
| **バーン** | 誰も管理しないアドレスへトークンを送り、永久に消すこと。 |
| **作成者** | トークンがローンチされた対象のウォレット。卒業までカーブ手数料の一部を受け取ります（またはトレーダーにキャッシュバックとして渡します）。 |
| **キャッシュバック** | ローンチ時のオプション。カーブ手数料のうち作成者分が、取引のたびにそのトレーダーへ戻ります。 |
| **Featured** | AGNT のバーンで買える Explore の掲載枠。広告であって、レビューではありません。 |
| **ゴールデンアワー** | 1 日 1 時間だけ、エアドロップポイントが 2 倍になる時間。 |
| **カーブ手数料** | ボンディングカーブでの売買ごとに 1%。[手数料](/ja/guide/fees)を参照。 |
| **フォーセット** | テストネットの BNB を無料で配るサイト。 |
| **ガス** | トランザクションごとにネットワークが取る少額の手数料。BNB で支払います。 |
| **Genesis Creator** | メインネットで最初に卒業した 100 トークンの作成者に贈られる永久バッジ。 |
| **卒業** | カーブが満ちた瞬間。トークンはロックされた流動性とともに PancakeSwap に移り、カーブは閉じます。 |
| **Ignite** | トークンの一部を公開メッセージ付きでバーンすること。[Ignite](/ja/guide/ignite)を参照。 |
| **LP トークン** | PancakeSwap プールの持ち分の証明。卒業時にバーンするので、流動性は決して引き出せません。 |
| **メインネット** | 本物のお金を使う本番ネットワーク。 |
| **PancakeSwap** | BNB Chain 最大の取引所。卒業したトークンはそこで取引されます。 |
| **プレセール** | 上場前の $AGNT 最初の公開販売。[プレセール](/ja/token/presale)を参照。 |
| **シードフレーズ** | ウォレットを支配する 12 または 24 単語。誰とも決して共有しないでください。 |
| **スリッページ** | プレビューから取引までに許される価格変動の幅。超えると取引は拒否されます。 |
| **スナップショット** | ポイントが確定し、エアドロップの取り分が計算される時点。 |
| **ステーキング** | BNB で手数料の分配を受けるために $AGNT をコントラクトに預けること。[ステーキング](/ja/token/staking)を参照。 |
| **テストネット** | BNB が無料で価値のない、BNB Chain の練習用コピー。 |
| **TGE** | トークン生成イベント。$AGNT が PancakeSwap に上場し、プレセールの請求が始まる日。 |
| **ウォレット上限** | トークンがカーブ上にある間、1 つのウォレットが保有できる最大量（メインネット {{P.mainnet.walletCapBps|pct}}、テストネット {{P.testnet.walletCapBps|pct}}）。 |
