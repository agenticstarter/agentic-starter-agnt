# はじめに

暗号資産や Agentic Starter は初めてですか？このページでは約 15 分でゼロから最初のトークンまで進めます。以下はすべて
**BNB Chain テストネット**で行います。テストネットの BNB は無料のテスト用なので、何も失うことはありません。

## 1. ウォレットを用意する

ウォレットは暗号資産を保管し、トランザクションに署名するアプリです。MetaMask、Trust Wallet、Rabby など BNB Chain 対応の
ウォレットを入れてください。

作成時にアプリが**シードフレーズ**（12 または 24 単語）を表示します。紙に書いてオフラインで保管してください。これを持つ人が
ウォレットを支配します。Agentic Starter の誰も、これを求めることはありません。

## 2. 無料のテスト BNB をもらう

1. [agenticstarter.xyz](https://agenticstarter.xyz?lang=ja) を開き **Connect** を押します。サイトがウォレットに
   **BNB Smart Chain Testnet**（chain 97）への切り替えを求めるので、承認します。
2. ウォレットアドレス（`0x` で始まる）をコピーします。
3. BNB Chain テストネットのフォーセットを開き、アドレスを貼り付けて tBNB を申請します。1〜2 分で届きます。 [bnbchain.org/en/testnet-faucet](https://www.bnbchain.org/en/testnet-faucet)

ローンチパッドの [Start ページ](https://agenticstarter.xyz/start?lang=ja)が同じ手順を案内し、終わるたびにチェックを付けます。

## 3. Agent ID を取得する

ボンディングカーブで購入するにはウォレットに **Agent ID** が必要です。テストネットでは無料です。どれかのトークンページを開き
**Get Agent ID** を押してください。少しのテストガスだけかかります。

## 4. 初めての取引

同じトークンページで少し買い、そのあと一部を売ってみましょう。進捗バーが PancakeSwap に向かって進むのが見えます。売却に
Agent ID は不要です。

## 5. 自分のトークンをローンチ

[Launch](https://agenticstarter.xyz/launch?lang=ja) を開き、名前・シンボル・ロゴを入力して **Open in Telegram** を押します。ボットの
Agen があなたのウォレットのためにローンチし、ガスを負担します。詳しくは[トークンをローンチする](/ja/guide/launch#testnet-telegram)。

## ついでに：エアドロップ

これらの各ステップで[エアドロップポイント](/ja/token/airdrop)も貯まります。ローンチ、取引、毎日のクイズなど。

## よく出てくる言葉

「カーブ」「卒業」「ガス」の意味がわからない？[用語集](/ja/guide/glossary)をご覧ください。まだ困ったら、各サイトの隅にある
チャットバブルの Agen か、Telegram グループで質問してください。
