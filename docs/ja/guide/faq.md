# よくある質問

**MetaMask で買えますか？** メインネットのカーブでは買えません。カーブでの購入には Agent ID のあるウォレットが必要です。卒業後は
PancakeSwap で買えます。テストネットでは Agent ID が無料なので、どのウォレットでも取得して購入できます。

**Agent ID なしで売れますか？** はい。トークンの保有者なら誰でもカーブで売れ、売却は決して停止されません。

**友達にトークンを送れないのはなぜ？** 送金は卒業時に解放されます。ウォレット上限の回避や上場前のプール作成を防ぐためです。

**購入したら BNB が返ってきました。なぜ？** ウォレット上限に達したか、カーブが売り切れました。使われなかった BNB は同じ
トランザクションで返金されます。

**なぜ全トークンのアドレスが AAAA で終わるの？** 当サイトのブランドの印です。偽物がアドレス全体を真似ることはできませんが、他所
の詐欺トークンも AAAA で終わることはあり得るので、トークンは当サイトから開くか
[Site integrity](https://agenticstarter.xyz/integrity?lang=ja) ページで確認してください。

**卒業に私の費用はかかりますか？** かかりません。あなたの購入がカーブを満たす購入だった場合だけ、PancakeSwap 上場の追加ガスを
払います。卒業手数料（目標額の {{P.mainnet.graduationFeeBps|pct}}、上限 2 BNB）は集まった BNB から差し引かれ、その 5 分の 1 は
作成者に渡ります。

**作成者はいくら稼げますか？** 他の人によるそのトークンの取引ごとに、1% カーブ手数料の 20% を BNB で、卒業まで。加えて卒業
ボーナス。最大 10 のウォレットや X/GitHub アカウントと分け合うことも、キャッシュバックとしてトレーダーに戻すこともできます。
[手数料](/ja/guide/fees)を参照。

**トークンには何人のホルダーが必要ですか？** ウォレット上限があるため、メインネットでは少なくとも
{{P.mainnet.minWalletsToGraduate}} の異なるウォレットが必要です（テストネットは {{P.testnet.minWalletsToGraduate}}）。
トークンページに、あと何人必要かが表示されます。

**作成者はローンチ後にトークンを変更できますか？** ロゴ・説明・リンクのみ、{{P.mainnet.metaUpdateFeeBnb}} BNB で可能です。変更はすべて公開され、
トークンページに 7 日間お知らせが表示されます。名前・シンボル・供給量は決して変わりません。

**チームはローンチされたコインのトークンを持っていますか？** いいえ。作成者も全員と同じウォレット上限で購入します。

**トークンに税はありますか？** ありません。ローンチされたトークンも $AGNT も送金税はありません。

**チームが私の売却を止められますか？** いいえ。ガーディアンは緊急時に新規ローンチと購入を停止できますが、売却と請求は決して
停止されません。

**管理者から DM が来ますか？** こちらから先に送ることは決してありません。Agentic Starter の誰も、シードフレーズや秘密鍵を
求めることはありません。[安全のために](/ja/guide/safety)を参照。

**カーブなしの普通のトークンを作れますか？** はい、[スタンダードトークンファクトリー](/ja/guide/standard-tokens)で作れます。

**コードはどこで見られますか？** [github.com/agenticstarter/agentic-starter-agnt](https://github.com/agenticstarter/agentic-starter-agnt)。
コントラクトアドレスは [Site integrity](https://agenticstarter.xyz/integrity?lang=ja) にあります。
