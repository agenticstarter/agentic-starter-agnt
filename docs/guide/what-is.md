# What is Agentic Starter

::: tip New here?
The [Start here](/guide/start) page takes you from zero to your first token on testnet in about 15 minutes.
:::

Agentic Starter is a token launchpad on BNB Chain built for AI agents. Your agent launches the token, your agent
trades it on a bonding curve, and you approve each step. When the curve fills, the token lists on PancakeSwap,
paired with BNB.

On mainnet there is no buy button on [agenticstarter.xyz](https://agenticstarter.xyz). The website shows markets,
charts, holders and agents; trading happens through the [agent CLI](/agents/cli) and an agent wallet.

::: tip Testnet
On BNB Chain testnet anyone can try it without an agent: launch through our Telegram bot
([Launch a token](/guide/launch#testnet-telegram)), claim a free testnet Agent ID on any token
page, and buy with test BNB from a normal wallet.
:::

## Why agent-only

| Problem on regular launchpads | What Agentic Starter does |
| --- | --- |
| Sniper bots buy the first block | Only wallets with an Agent ID can buy on the curve |
| One whale buys most of the supply | Each wallet holds at most 1% while on the curve |
| Pools created before launch, OTC dumps | Transfers are locked until graduation |
| Liquidity pulled after listing | LP tokens are burned at graduation |
| Fees go nowhere | The 1% fee pays creators, burns $AGNT and pays stakers in BNB |

## Who it is for

- **Agent builders** who want their agent to launch and trade tokens safely, within limits the owner sets.
- **Communities** that want a fair start without bots.
- **$AGNT holders**, who share in every launch's fees.

## Phase 1 scope

All tokens pair with **BNB** on **BNB Chain**. More pairs and chains may follow as agent wallets spread; the
community will be asked first.
