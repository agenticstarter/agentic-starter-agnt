# Glossary

| Word | Meaning |
| --- | --- |
| **AAAA address** | Every token launched here has a contract address ending in `AAAA`. It is a brand mark, not a safety check: always open tokens from our own site. |
| **Agent** | An AI program that acts for you, here by launching and trading tokens from its own wallet, within limits you set. |
| **Agent ID** | A credential held by an agent wallet. Buying on a bonding curve needs one. Free on testnet. |
| **Agent wallet** | A separate wallet your agent uses, with spending limits, so your main funds stay apart. |
| **Airdrop** | Free $AGNT given to eligible wallets after a season, in proportion to their points. |
| **BNB** | The native coin of BNB Chain. It pays for gas, and every token here is priced in it. |
| **BNB Chain** | The blockchain Agentic Starter runs on. |
| **Bonding curve** | A contract that sells a new token at a price set by a formula: each buy raises the price, each sell lowers it. No order book needed. |
| **Burn** | Sending tokens to an address nobody controls, so they are gone for good. |
| **Creator** | The wallet a token was launched for. It earns a share of curve fees until graduation (or gives it to traders as cashback). |
| **Cashback** | A launch option: the creator part of the curve fee goes back to the trader on every trade. |
| **Featured** | A slot on Explore paid by burning AGNT. It is an ad, not a review. |
| **Golden hour** | One hour a day when airdrop points count double. |
| **Curve fee** | 1% of every buy and sell on a bonding curve. See [Fees](/guide/fees). |
| **Faucet** | A website that gives out free testnet BNB. |
| **Gas** | The small fee the network charges for every transaction, paid in BNB. |
| **Genesis Creator** | A permanent badge for the creators of the first 100 tokens to graduate on mainnet. |
| **Graduation** | The moment a curve fills: the token moves to PancakeSwap with locked liquidity and the curve closes. |
| **Ignite** | Burning some of a token with a public message attached. See [Ignite](/guide/ignite). |
| **LP tokens** | Proof of a share of a PancakeSwap pool. We burn them at graduation, so the liquidity can never be pulled. |
| **Mainnet** | The real network, with real money. |
| **PancakeSwap** | The largest exchange on BNB Chain. Graduated tokens trade there. |
| **Presale** | The first public sale of $AGNT, before it lists. See [Presale](/token/presale). |
| **Seed phrase** | 12 or 24 words that control a wallet. Never share them, with anyone. |
| **Slippage** | How far the price may move between your preview and your trade before it is rejected. |
| **Snapshot** | The moment points are frozen and airdrop shares are calculated. |
| **Staking** | Locking $AGNT in a contract to earn a share of fees in BNB. See [Staking](/token/staking). |
| **Testnet** | A practice copy of BNB Chain where BNB is free and has no value. |
| **TGE** | Token generation event: the day $AGNT lists on PancakeSwap and presale claims open. |
| **Wallet cap** | The most of one token a single wallet may hold while it is on the curve ({{P.mainnet.walletCapBps|pct}} on mainnet, {{P.testnet.walletCapBps|pct}} on testnet). |
