# Telegram community

| Place | Link | What it is for |
| --- | --- | --- |
| Channel | [t.me/agenticstarter](https://t.me/agenticstarter) | Announcements only |
| Group | [t.me/agentic_starter](https://t.me/agentic_starter) | Chat, the daily quiz, questions to Agen |
| Agen (bot) | [t.me/agenticstarter_bot](https://t.me/agenticstarter_bot) | Airdrop Mini App, reminders, testnet launches |

## Joining the group

New members press **I'm not a bot** in the welcome message before they can write. The welcome and join messages
are removed after a short while to keep the chat clean.

## Ask Agen

Write `@Agen` anywhere in your message in the group, for example `@Agen how does graduation work?`. Agen answers in your
language from these docs and live numbers. Agen answers project questions in the group only, so everyone sees the
answer; in private it helps with your own things (launches, points, reminders).

Agen does not answer questions that could put you or the project at risk (keys, seed phrases, how to attack a
contract), or questions that have nothing to do with Agentic Starter. Questions asked many times get a link to the
right docs page.

## Commands

| Command | Where | What it does |
| --- | --- | --- |
| `@Agen <question>` | group | Ask Agen (`/agen` works too) |
| `/points` | private | Your airdrop points and what is missing |
| `/earn` | group or private | What you can still do for points, biggest first |
| `/challenge` | group or private | Today's challenge and your streak |
| `/help` | group or private | All commands |
| `/watch <token>` | private | A message at 80%, 90% and graduation |
| `/remind presale` · `claim` · `mainnet` | private | A message when it opens |
| `/report` | reply to a message in the group | Report a scam or a fake admin to the team |
| `/launch <code>` | private | Testnet launch from the website (see [Launch](/guide/launch#testnet-telegram)) |
| `/faucet` | private | Where to get test BNB (the airdrop page can top you up once after Q2) |
| `/settings` | private | Which private messages Agen sends you: boxes, quiz reminders, summary and more |
| `/agentid` | private | Check an Agent ID |

Every private message from Agen has a **Turn these off** button. Turn a kind back on any time with `/settings`.

## Group rules

- Be kind. No insults, no FUD campaigns, no spam, no shilling other projects.
- Links: only official links (see [Stay safe](/guide/safety)). Other links are removed.
- Strikes: hard insults give a strike right away; repeated soft ones after a warning. **5 strikes** in 20 days
  means a ban. Strikes expire after 20 days.
- Admins never DM first and never ask for keys, seed phrases or BNB.
- Names that look like the team (admin, support, Agentic Starter, Agen) are muted, and "DM me", seed-phrase and
  "validate your wallet" messages are removed.

If you think a moderation action was wrong, write to an admin in the group.
