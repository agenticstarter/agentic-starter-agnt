# टोकन लॉन्च करें

अपने एजेंट को बताएँ क्या लॉन्च करना है, प्रीव्यू देखें, मंज़ूर करें। बस इतना ही।

```text
Launch a token on Agentic Starter: name "Nova Agent", symbol NOVA, description "Scouts fresh launches",
logo https://…/nova.png, X @nova_agent, and buy 0.2 BNB of it in the same transaction.
Show me the preview first and wait for my OK.
```

एजेंट चलाता है:

```bash
agentic create --name "Nova Agent" --symbol NOVA \
  --description "Scouts fresh launches" --logo https://…/nova.png --twitter @nova_agent \
  --telegram https://t.me/nova_agent --buy 0.2
agentic execute --request-id <id>
```

प्रीव्यू से पहले CLI ऐसा salt खोजता है जिससे टोकन का पता `AAAA` पर खत्म हो। इसमें कुछ सेकंड लगते हैं।

वेबसाइट पर लॉन्च फ़ॉर्म तीन चरणों में चलता है। अपने आइडिया के बारे में एक वाक्य लिखें और **Fill it in** दबाएँ, आपको नाम,
सिंबल और विवरण मिलेगा जिसे आप बदल सकते हैं। लोगो डालें: यह IPFS पर पिन होता है और प्रॉम्प्ट `ipfs://` लिंक इस्तेमाल करता है
(CLI में `--logo ./nova.png` यही करता है)। फिर चुनें कि क्रिएटर फ़ीस कहाँ जाएगी, प्रीव्यू कार्ड देखें, और अपने एजेंट के लिए प्रॉम्प्ट
कॉपी करें। कर्व सिम्युलेटर हर चरण पर क़ीमत और मार्केट कैप दिखाता है।

| फ़ील्ड | सीमा |
| --- | --- |
| नाम | 1–32 अक्षर |
| सिंबल | 2–10 बड़े अक्षर या अंक। AGNT, BNB, BTC, ETH, USDT, USDC और CAKE जैसे टिकर आरक्षित हैं |
| नाम और सिंबल की लिपि | एक नाम में एक ही वर्णमाला, इसलिए दूसरी लिपियों के मिलते-जुलते अक्षर अस्वीकार हो जाते हैं |
| मेटाडेटा (विवरण, लोगो URL, लिंक) | ऑन-चेन, लगभग 1 KB तक |
| लोगो | `https://` / `ipfs://` URL, या 1 MB तक की लोकल PNG, JPG, GIF, WebP फ़ाइल (IPFS पर अपलोड) |
| पहली खरीद | वैकल्पिक, Agent ID ज़रूरी, वॉलेट सीमा लागू |
| X | लिंक या `@handle` (हैंडल के रूप में सेव होता है) |
| Telegram | केवल `t.me` लिंक |
| लॉन्च फ़ीस | मेननेट पर {{P.mainnet.launchFeeBnb}} BNB, टेस्टनेट पर और परक्स वाले AGNT स्टेकर्स के लिए मुफ़्त, साथ में गैस |
| जोड़ी | BNB। अन्य जोड़ियाँ बाद में आएँगी |

टोकन पर कोई टैक्स, mint फ़ंक्शन या मालिक नहीं होता।

## क्रिएटर फ़ीस कहाँ जाती है

| विकल्प | CLI | वेबसाइट |
| --- | --- | --- |
| आपका लॉन्च वॉलेट (डिफ़ॉल्ट) | — | फ़ीस वॉलेट खाली छोड़ें |
| कोई दूसरा वॉलेट | `--fee-to 0xWallet:100` | **Creator fee wallet** फ़ील्ड |
| बँटवारा, अधिकतम 10 प्राप्तकर्ता | `--fee-to 0xA:60,0xB:40` | लॉन्च के बाद My tokens पर सेट करें |
| X या GitHub अकाउंट | `--fee-to 0xA:80,x:@alice:20` | लॉन्च के बाद My tokens पर सेट करें |
| ट्रेडर्स को कैशबैक | `--cashback` | **Reward mode → Cashback** |

अकाउंट के हिस्से एक एस्क्रो में तब तक रहते हैं जब तक अकाउंट का मालिक अकाउंट साबित करके कोई वॉलेट न जोड़ दे; जो हिस्से क्लेम
नहीं होते वे 90 दिन बाद क्रिएटर को लौट जाते हैं। बँटवारे में बदलाव प्रस्ताव के 24 घंटे बाद लागू होता है। देखें
[फ़ीस](/hi/guide/fees#creator-fee-options)।

## टेस्टनेट: Telegram बॉट से लॉन्च {#testnet-telegram}

BNB Chain टेस्टनेट पर आप एजेंट सेट किए बिना लॉन्च कर सकते हैं। हमारा बॉट Agen एजेंट बनकर गैस देता है; आपका वॉलेट क्रिएटर
के रूप में दर्ज होता है।

1. [Launch](https://agenticstarter.xyz/launch?lang=hi) खोलें, टोकन का मालिक बनने वाला वॉलेट जोड़ें और नाम, सिंबल, लोगो, विवरण और
   लिंक भरें।
2. **Open in Telegram** दबाएँ। बॉट आपके लॉन्च कोड के साथ खुलता है और प्रीव्यू दिखाता है।
3. **🚀 Launch now** दबाएँ। कुछ सेकंड बाद बॉट टोकन पते के साथ जवाब देता है, और टोकन Explore पेज पर दिखता है।

अगर Telegram न खुले, तो पेज से `/launch ABCD2345` लाइन कॉपी करके बॉट को भेजें। कोड 24 घंटे वैध हैं और एक बार चलते हैं। हर
Telegram अकाउंट दिन में 3 टोकन तक लॉन्च कर सकता है।

बॉट आपके लिए नहीं खरीदता। खरीदने के लिए टोकन पेज खोलें, मुफ़्त टेस्टनेट Agent ID लें और टेस्ट BNB से खरीदें। टेस्टनेट पर
टोकन **{{P.testnet.graduationTargetBnb}} BNB** पर ग्रेजुएट होता है।

## लॉन्च के बाद

फिर लॉन्च पेज एक **लॉन्च के बाद की किट** दिखाता है: तैयार X पोस्ट, Telegram टेक्स्ट, शेयर इमेज और आपकी वेबसाइट के लिए एम्बेड
विजेट। [My tokens](https://agenticstarter.xyz/me?lang=hi) पर आप:

| काम | विवरण |
| --- | --- |
| प्रगति देखें | कर्व प्रगति, जुटाया BNB, होल्डर |
| क्रिएटर इनाम क्लेम करें | आपके टोकन की हर कर्व फ़ीस का 20%, BNB में, ग्रेजुएशन तक, साथ में ग्रेजुएशन बोनस |
| जानकारी अपडेट करें | मेननेट पर {{P.mainnet.metaUpdateFeeBnb}} BNB में लोगो, विवरण और लिंक बदलें। नाम और सिंबल कभी नहीं बदलते। होल्डर्स को 7 दिन तक सूचना दिखती है और पूरा इतिहास सार्वजनिक रहता है। |
| फ़ीस बँटवारा | नया बँटवारा प्रस्तावित करें; यह 24 घंटे बाद लागू होता है |
| क्रिएटर ट्रांसफ़र करें | नया क्रिएटर वॉलेट प्रस्तावित करें; टोकन पेज पर उसके स्वीकार करने पर वह कार्यभार सँभालता है। पहले से कमाए इनाम आप ही क्लेम कर सकेंगे। |
| क्रिएटर आवंटन | जहाँ यह लागू है (आज टेस्टनेट पर), ग्रेजुएशन के बाद अनलॉक हुआ हिस्सा क्लेम करें |
| X वेरिफ़ाई करें | टोकन पेज पर वेरिफ़ाइड क्रिएटर बैज दिखाने के लिए अपना X अकाउंट जोड़ें |

मेननेट पर ग्रेजुएट होने वाले पहले 100 टोकनों के क्रिएटर्स को स्थायी **Genesis Creator** बैज मिलता है।
