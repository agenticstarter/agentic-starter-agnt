# शब्दावली

| शब्द | अर्थ |
| --- | --- |
| **AAAA पता** | यहाँ लॉन्च हर टोकन का कॉन्ट्रैक्ट पता `AAAA` पर खत्म होता है। यह ब्रांड निशान है, सुरक्षा जाँच नहीं: टोकन हमेशा हमारी साइट से खोलें। |
| **एजेंट** | एक AI प्रोग्राम जो आपकी ओर से काम करता है; यहाँ यह आपकी तय सीमाओं के भीतर अपने वॉलेट से टोकन लॉन्च और ट्रेड करता है। |
| **Agent ID** | एजेंट वॉलेट में रखी एक पहचान। बॉन्डिंग कर्व पर खरीदने के लिए ज़रूरी। टेस्टनेट पर मुफ़्त। |
| **एजेंट वॉलेट** | आपका एजेंट जो अलग वॉलेट इस्तेमाल करता है, खर्च सीमाओं के साथ, ताकि आपका मुख्य फ़ंड अलग रहे। |
| **एयरड्रॉप** | सीज़न के बाद योग्य वॉलेट्स को उनके पॉइंट के अनुपात में मिलने वाला मुफ़्त $AGNT। |
| **BNB** | BNB Chain का मूल कॉइन। इससे गैस दी जाती है, और यहाँ हर टोकन की क़ीमत इसी में होती है। |
| **BNB Chain** | वह ब्लॉकचेन जिस पर Agentic Starter चलता है। |
| **बॉन्डिंग कर्व** | एक कॉन्ट्रैक्ट जो नए टोकन को फ़ॉर्मूले से तय क़ीमत पर बेचता है: हर खरीद क़ीमत बढ़ाती है, हर बिक्री घटाती है। ऑर्डर बुक की ज़रूरत नहीं। |
| **बर्न** | टोकन को ऐसे पते पर भेजना जिसे कोई नियंत्रित नहीं करता, ताकि वे हमेशा के लिए खत्म हो जाएँ। |
| **क्रिएटर** | वह वॉलेट जिसके लिए टोकन लॉन्च हुआ। ग्रेजुएशन तक कर्व फ़ीस का हिस्सा कमाता है (या उसे ट्रेडर्स को कैशबैक के रूप में दे देता है)। |
| **कैशबैक** | लॉन्च का एक विकल्प: कर्व फ़ीस का क्रिएटर वाला हिस्सा हर ट्रेड पर ट्रेडर को वापस मिल जाता है। |
| **Featured** | Explore पर एक स्लॉट जिसके लिए AGNT बर्न करना पड़ता है। यह विज्ञापन है, समीक्षा नहीं। |
| **गोल्डन आवर** | दिन का एक घंटा जब एयरड्रॉप पॉइंट दोगुने गिने जाते हैं। |
| **कर्व फ़ीस** | बॉन्डिंग कर्व पर हर खरीद और बिक्री का 1%। देखें [फ़ीस](/hi/guide/fees)। |
| **फ़ॉसेट** | मुफ़्त टेस्टनेट BNB देने वाली वेबसाइट। |
| **गैस** | हर ट्रांज़ैक्शन पर नेटवर्क की छोटी फ़ीस, BNB में। |
| **Genesis Creator** | मेननेट पर ग्रेजुएट होने वाले पहले 100 टोकनों के क्रिएटर्स के लिए स्थायी बैज। |
| **ग्रेजुएशन** | कर्व भरने का पल: टोकन लॉक लिक्विडिटी के साथ PancakeSwap पर जाता है और कर्व बंद हो जाता है। |
| **Ignite** | किसी टोकन का कुछ हिस्सा एक सार्वजनिक संदेश के साथ बर्न करना। देखें [Ignite](/hi/guide/ignite)। |
| **LP टोकन** | PancakeSwap पूल में हिस्सेदारी का सबूत। हम इन्हें ग्रेजुएशन पर बर्न करते हैं, इसलिए लिक्विडिटी कभी निकाली नहीं जा सकती। |
| **मेननेट** | असली नेटवर्क, असली पैसा। |
| **PancakeSwap** | BNB Chain का सबसे बड़ा एक्सचेंज। ग्रेजुएट टोकन वहीं ट्रेड होते हैं। |
| **प्रीसेल** | लिस्टिंग से पहले $AGNT की पहली सार्वजनिक बिक्री। देखें [प्रीसेल](/hi/token/presale)। |
| **सीड फ़्रेज़** | वॉलेट नियंत्रित करने वाले 12 या 24 शब्द। कभी किसी से साझा न करें। |
| **स्लिपेज** | प्रीव्यू और ट्रेड के बीच क़ीमत कितनी हिल सकती है, उससे ज़्यादा हिलने पर ट्रेड रद्द। |
| **स्नैपशॉट** | वह पल जब पॉइंट फ़्रीज़ होते हैं और एयरड्रॉप हिस्से गिने जाते हैं। |
| **स्टेकिंग** | BNB में फ़ीस का हिस्सा पाने के लिए $AGNT को कॉन्ट्रैक्ट में लॉक करना। देखें [स्टेकिंग](/hi/token/staking)। |
| **टेस्टनेट** | BNB Chain की अभ्यास कॉपी, जहाँ BNB मुफ़्त है और उसकी कोई क़ीमत नहीं। |
| **TGE** | टोकन जेनरेशन इवेंट: वह दिन जब $AGNT PancakeSwap पर लिस्ट होता है और प्रीसेल क्लेम खुलते हैं। |
| **वॉलेट सीमा** | कर्व पर रहते हुए एक वॉलेट किसी टोकन का अधिकतम कितना रख सकता है (मेननेट पर {{P.mainnet.walletCapBps|pct}}, टेस्टनेट पर {{P.testnet.walletCapBps|pct}})। |
