# एजेंट वॉलेट सेट करें

आपको तीन चीज़ें चाहिए: एक एजेंटिक वॉलेट, उस पर एक Agent ID, और थोड़ा BNB।

1. **एजेंटिक वॉलेट बनाएँ**, किसी ऐसे वॉलेट ऐप में जो AI एजेंट्स को सपोर्ट करता हो। यह अलग, बिना प्राइवेट की वाला सब-वॉलेट है
   जिसका अपना बैलेंस होता है, इसलिए आपका मुख्य पैसा अलग रहता है।
2. **सुरक्षा सीमाएँ तय करें:** रोज़ खर्च की सीमा, एजेंट कौन से टोकन ट्रेड कर सकता है, और जोखिम वाले ट्रांज़ैक्शन कैसे कन्फ़र्म
   हों। ऑटोमेटेड साइनिंग चालू करें ताकि एजेंट इन सीमाओं के भीतर काम कर सके।
3. **उस वॉलेट के लिए Agent ID लें।** लॉन्चपैड कर्व पर हर खरीद पर इसकी ऑन-चेन जाँच करता है।
4. **BNB डालें**, गैस और खरीद के लिए (शुरुआत के लिए 0.05 BNB काफ़ी है)।
5. **अपने एजेंट में स्किल और CLI इंस्टॉल करें:**

```bash
npx skills add agenticstarter/agentic-starter-agnt/skill
npm i -g @agenticstarter/cli
```

6. **साइनर कनेक्ट करें।** CLI को अपने वॉलेट की साइनिंग कमांड से जोड़ें (देखें [साइनर](/agents/signers))।
7. **जाँचें:** अपने एजेंट से `agentic preflight` चलवाएँ। हर फ़ेल जाँच के साथ उसका हल भी मिलता है।

आप वॉलेट एड्रेस को [Agent check](https://agenticstarter.xyz/check?lang=hi) में पेस्ट करके उसका Agent ID स्टेटस और होल्डिंग्स
भी देख सकते हैं।

::: warning
अपने मुख्य वॉलेट का सीड फ़्रेज़ कभी किसी एजेंट को न दें। सीमाओं वाला अलग एजेंट वॉलेट इस्तेमाल करें।
:::
