# स्टेकिंग

लॉन्चपैड फ़ीस से BNB कमाने के लिए `AGNTStaking` कॉन्ट्रैक्ट में $AGNT स्टेक करें।

- स्टेकर्स को **हर कर्व फ़ीस का 30%** मिलता है, BNB में।
- आने वाला हर BNB **अगले 7 दिनों में धीरे-धीरे** बँटता है, उस दौरान स्टेक करने वाले सभी में साझा। भुगतान से ठीक पहले स्टेक करने
  से उसे हथियाया नहीं जा सकता।
- जब कोई स्टेक न कर रहा हो, तब आने वाला BNB इंतज़ार करता है और पहले स्टेकर के जुड़ने पर बँटना शुरू होता है।
- कोई लॉक-अप नहीं: कभी भी अनस्टेक करें; कभी भी BNB क्लेम करें।

## परक्स

**कम से कम 7 दिन** से स्टेक किया गया AGNT परक्स के लिए गिना जाता है। और AGNT जोड़ने पर पूरी पोज़ीशन के लिए 7 दिन की घड़ी फिर से शुरू
होती है, इसलिए परक्स एक ब्लॉक के लिए नहीं खरीदे जा सकते।

| परक | शर्त |
| --- | --- |
| लॉन्चपैड पर मुफ़्त लॉन्च | 7 दिन के लिए 100,000 AGNT स्टेक |
| स्टैंडर्ड टोकन फ़ैक्टरी पर आधी क़ीमत | 7 दिन के लिए 100,000 AGNT स्टेक |
| Snapshot वोट का वज़न | 7 दिन स्टेक किया कोई भी AGNT (`maturedStake`) |
| सीज़न 2 एयरड्रॉप मल्टीप्लायर | सीज़न 2 के साथ घोषित होगा |

सीमा को मालिक Safe बदल सकता है; हर बदलाव [Site integrity](https://agenticstarter.xyz/integrity?lang=hi) पर सार्वजनिक है।

स्टेकिंग $AGNT लिस्टिंग के साथ खुलती है।

| फ़ंक्शन | असर |
| --- | --- |
| `stake(amount)` | AGNT जमा करें (पहले approve) |
| `unstake(amount)` | AGNT निकालें, इनाम बने रहते हैं |
| `claim()` | जमा BNB निकालें |
| `pendingBnb(address)` | जमा BNB देखें |
| `maturedStake(address)` | वह AGNT जो परक्स और वोट के लिए गिना जाता है |
| `hasPerks(address)` | परक्स की सीमा से ऊपर होने पर True |
