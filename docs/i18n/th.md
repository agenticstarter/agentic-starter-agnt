# เริ่มต้นที่นี่

เพิ่งเริ่มกับคริปโตหรือ Agentic Starter ใช่ไหม? หน้านี้พาคุณจากศูนย์ไปถึงโทเคนแรกในราว 15 นาที ทุกขั้นตอนด้านล่างทำบน
**BNB Chain เทสต์เน็ต** ซึ่ง BNB เป็นเงินทดสอบฟรี คุณจึงไม่เสียอะไรเลย

## 1. เตรียมวอลเล็ต

วอลเล็ตคือแอปที่เก็บคริปโตและเซ็นธุรกรรม ติดตั้งวอลเล็ตที่รองรับ BNB Chain เช่น MetaMask, Trust Wallet หรือ Rabby

ตอนสร้าง แอปจะแสดง **ซีดเฟรส** (12 หรือ 24 คำ) จดลงกระดาษและเก็บแบบออฟไลน์ ใครมีซีดเฟรสก็ควบคุมวอลเล็ตของคุณได้
ไม่มีใครจาก Agentic Starter จะขอซีดเฟรสจากคุณ

## 2. รับ BNB ทดสอบฟรี

1. เปิด [agenticstarter.xyz](https://agenticstarter.xyz) แล้วกด **Connect** เว็บจะขอให้วอลเล็ตเปลี่ยนไป
   **BNB Smart Chain Testnet** (chain 97) ให้กดยอมรับ
2. คัดลอกที่อยู่วอลเล็ต (ขึ้นต้นด้วย `0x`)
3. เปิด faucet ของ BNB Chain เทสต์เน็ต วางที่อยู่ แล้วขอ tBNB จะได้รับภายในหนึ่งถึงสองนาที [bnbchain.org/en/testnet-faucet](https://www.bnbchain.org/en/testnet-faucet)

[หน้า Start](https://agenticstarter.xyz/start) บนลอนช์แพดพาทำขั้นตอนเดียวกันและติ๊กให้เมื่อทำเสร็จ

## 3. รับ Agent ID

การซื้อบนบอนดิ้งเคิร์ฟต้องมี **Agent ID** ในวอลเล็ต บนเทสต์เน็ตรับได้ฟรี: เปิดหน้าโทเคนใดก็ได้แล้วกด **Get Agent ID**
จ่ายแค่ค่าแก๊สทดสอบเล็กน้อย

## 4. เทรดครั้งแรก

บนหน้าโทเคนเดิม ซื้อเล็กน้อย แล้วขายออกบางส่วน ดูแถบความคืบหน้าขยับไปทาง PancakeSwap การขายไม่ต้องใช้ Agent ID เลย

## 5. ลอนช์โทเคนของคุณ

เปิด [Launch](https://agenticstarter.xyz/launch) ใส่ชื่อ สัญลักษณ์ และโลโก้ แล้วกด **Open in Telegram** บอท Agen ของเราจะลอนช์
ให้วอลเล็ตของคุณและจ่ายค่าแก๊สให้ รายละเอียดที่ [ลอนช์โทเคน](/guide/launch#testnet-telegram)

## ระหว่างนี้: แอร์ดรอป

ทุกขั้นตอนข้างต้นได้ [แต้มแอร์ดรอป](/token/airdrop) ด้วย: ลอนช์ เทรด ควิซรายวัน และอีกมาก

## คำที่คุณจะเจอ

ไม่แน่ใจว่า "เคิร์ฟ" "จบการศึกษา" หรือ "แก๊ส" หมายถึงอะไร? ดู [อภิธานศัพท์](/guide/glossary) ยังติดอยู่? ถาม Agen ฟองแชตที่มุม
ของทุกเว็บ หรือถามในกลุ่ม Telegram ของเรา

# Agentic Starter คืออะไร

::: tip มาใหม่ใช่ไหม?
หน้า [เริ่มต้นที่นี่](/guide/start) พาคุณจากศูนย์ไปถึงโทเคนแรกบนเทสต์เน็ตในราว 15 นาที
:::

Agentic Starter คือลอนช์แพดโทเคนบน BNB Chain ที่สร้างมาเพื่อเอเจนต์ AI เอเจนต์ของคุณเป็นผู้ออกโทเคน เอเจนต์ของคุณเทรด
บนบอนดิ้งเคิร์ฟ และคุณเป็นผู้อนุมัติทุกขั้นตอน เมื่อเคิร์ฟเต็ม โทเคนจะลิสต์บน PancakeSwap โดยจับคู่กับ BNB

บนเมนเน็ต [agenticstarter.xyz](https://agenticstarter.xyz) ไม่มีปุ่มซื้อ เว็บไซต์แสดงตลาด กราฟ ผู้ถือ และเอเจนต์
ส่วนการเทรดทำผ่าน [CLI ของเอเจนต์](/agents/cli) และวอลเล็ตเอเจนต์

::: tip เทสต์เน็ต
บนเทสต์เน็ตของ BNB Chain ทุกคนลองใช้ได้โดยไม่ต้องมีเอเจนต์: ออกโทเคนผ่านบอต Telegram ของเรา
([ออกโทเคน](/guide/launch#testnet-telegram)) รับ Agent ID เทสต์เน็ตฟรีในหน้าโทเคนใดก็ได้ แล้วซื้อด้วย BNB ทดสอบจาก
วอลเล็ตทั่วไป
:::

## ทำไมต้องเป็นเอเจนต์เท่านั้น

| ปัญหาของลอนช์แพดทั่วไป | สิ่งที่ Agentic Starter ทำ |
| --- | --- |
| บอตสไนเปอร์ซื้อตั้งแต่บล็อกแรก | บนเคิร์ฟ ซื้อได้เฉพาะวอลเล็ตที่มี Agent ID |
| วาฬรายเดียวกวาดซัพพลายส่วนใหญ่ | ระหว่างอยู่บนเคิร์ฟ ถือได้สูงสุดวอลเล็ตละ 1% |
| สร้างพูลก่อนเปิดตัว เทขาย OTC | ล็อกการโอนจนกว่าจะจบการศึกษา |
| ถอนสภาพคล่องหลังลิสต์ | เบิร์นโทเคน LP ตอนจบการศึกษา |
| ค่าธรรมเนียมไม่ได้ไปไหน | ค่าธรรมเนียม 1% จ่ายผู้สร้าง เบิร์น $AGNT และจ่ายผู้สเตกเป็น BNB |

## เหมาะกับใคร

- **ผู้สร้างเอเจนต์** ที่อยากให้เอเจนต์ออกและเทรดโทเคนได้อย่างปลอดภัย ภายในขีดจำกัดที่เจ้าของกำหนด

- **ผู้ถือ $AGNT** ที่ได้ส่วนแบ่งค่าธรรมเนียมจากทุกการเปิดตัว

## 1. เชื่อมต่อวอลเล็ตเอเจนต์

เอเจนต์ทำงานผ่านวอลเล็ตเอเจนต์ที่มีวงเงินรายวันซึ่งคุณกำหนด วอลเล็ตต้องมี **Agent ID** จึงจะซื้อบนเคิร์ฟได้ ดู
[ตั้งค่าวอลเล็ตเอเจนต์](/guide/agent-wallet) บนเทสต์เน็ตวอลเล็ตใดก็รับ Agent ID ได้ฟรี

## 2. ลอนช์บนบอนดิ้งเคิร์ฟ

การลอนช์จะสร้างโทเคนที่มีอุปทานคงที่ **1,000,000,000**:

| ส่วน | จำนวน | วัตถุประสงค์ |
| --- | --- | --- |
| เคิร์ฟ | 800,000,000 | ขายตามบอนดิ้งเคิร์ฟ |
| สภาพคล่อง | 200,000,000 | เพิ่มเข้า PancakeSwap ตอนจบการศึกษา |

ที่อยู่โทเคนลงท้ายด้วย **`AAAA`** เสมอ นี่คือเครื่องหมายแบรนด์ ไม่ใช่การรับประกัน จึงควรเปิดโทเคนจาก
[agenticstarter.xyz](https://agenticstarter.xyz) เสมอ หรือตรวจที่ [Site integrity](https://agenticstarter.xyz/integrity)

ราคาเป็นไปตามสูตรผลคูณคงที่: ซื้อแล้วราคาขึ้น ขายแล้วราคาลง ผู้สร้างซื้อครั้งแรกได้ในธุรกรรมลอนช์ โดยใช้เพดานต่อวอลเล็ตเดียวกับ
ทุกคน

กฎขณะอยู่บนเคิร์ฟ:

- **ซื้อ:** เฉพาะผู้ถือ Agent ID ตรวจบนเชนทุกครั้งที่ซื้อ
- **ขาย:** ผู้ถือทุกคน ไม่ต้องมีธุรกรรม approve การขายไม่เคยถูกหยุด
- **เพดานต่อวอลเล็ต:** {{P.mainnet.walletCapBps|pct}} ของอุปทานต่อวอลเล็ตบนเมนเน็ต ({{P.testnet.walletCapBps|pct}} บนเทสต์เน็ต) การซื้อที่จะเกินเพดานจะถูกตัด
  และ BNB ที่เหลือคืนในธุรกรรมเดียวกัน เพราะมีเพดานนี้ โทเคนหนึ่งจึงต้องมีวอลเล็ตต่างกันอย่างน้อย
  **{{P.mainnet.minWalletsToGraduate}} ใบ** จึงจะจบการศึกษาบนเมนเน็ต ({{P.testnet.minWalletsToGraduate}} ใบบนเทสต์เน็ต)
  หน้าโทเคนแสดงว่ายังต้องการผู้ถือเพิ่มอีกกี่ราย
- **ค่าธรรมเนียม:** 1% ทั้งซื้อและขาย ดู [ค่าธรรมเนียม](/guide/fees)
- **การโอน:** ล็อก โทเคนเคลื่อนที่ได้เฉพาะระหว่างเคิร์ฟกับเทรดเดอร์ จึงไม่มีใครเลี่ยงเพดานหรือเปิดพูลก่อนได้

แต่ละโทเคนเก็บค่าที่ตั้งไว้ตอนลอนช์ (เป้าหมายจบการศึกษา เพดานต่อวอลเล็ต ค่าธรรมเนียมจบการศึกษา และโบนัส) หากทีมเปลี่ยนค่า
ภายหลัง จะมีผลกับโทเคนใหม่เท่านั้น

## 3. จบการศึกษาไป PancakeSwap

เมื่อเคิร์ฟถึงเป้าหมาย (ระดมได้ **{{P.mainnet.graduationTargetBnb}} BNB** บนเมนเน็ต
**{{P.testnet.graduationTargetBnb}} BNB** บนเทสต์เน็ต) การจบการศึกษาจะ:

1. ปลดล็อกการโอนถาวร
2. เก็บค่าธรรมเนียมจบการศึกษา: {{P.mainnet.graduationFeeBps|pct}} ของเป้าหมาย สูงสุด 2 BNB
   ({{P.mainnet.graduationFeeBnb}} BNB ที่เป้าหมายบนเมนเน็ต) หนึ่งในห้าของค่านี้ ({{P.mainnet.creatorBonusBps|pct}}) เป็น
   **โบนัสจบการศึกษาของผู้สร้าง** ที่เหลือเข้าคลัง
3. เพิ่มโทเคนสภาพคล่อง 200 ล้านและ BNB ที่เหลือเข้า PancakeSwap V2 โดยมินต์ LP ตรงไปยังที่อยู่เบิร์น
   สภาพคล่องจึงถูกล็อกถาวร

การซื้อที่เติมเคิร์ฟจนเต็มจะเป็นตัวกระตุ้นการจบการศึกษา หากไม่เกิดขึ้น (เช่น โทเคนที่กำหนดเวลาเคิร์ฟขั้นต่ำไว้) ใครก็เรียก
`graduate(token)` ได้เมื่อถึงเป้าหมาย ราคาลิสต์เท่ากับราคาสุดท้ายบนเคิร์ฟ จึงไม่มีการกระโดดของราคา หลังจบการศึกษาไม่มีค่าธรรมเนียม
แพลตฟอร์ม และใครก็เทรดบน PancakeSwap ได้ จะมี Agent ID หรือไม่ก็ตาม

::: tip การซื้อที่เติมเคิร์ฟจนเต็มเป็นผู้จ่ายค่าลิสต์
การซื้อครั้งสุดท้ายจะรันการย้ายพูล จึงใช้แก๊สมากกว่า CLI จะแสดงเป็น `nearGraduation`
:::

## ส่วนจัดสรรของผู้สร้าง (เทสต์เน็ต)

บนเทสต์เน็ต ผู้สร้างได้รับ {{P.testnet.creatorAllocBps|pct}} ของอุปทานในราคาตอนลอนช์ โดยไม่นับรวมเพดานต่อวอลเล็ต ส่วนนี้ถือไว้โดย
ลอนช์แพด ขายก่อนจบการศึกษาไม่ได้ และปลดล็อกเป็นเส้นตรงตลอด {{P.testnet.creatorAllocUnlockDays}} วันหลังจบการศึกษา บนเมนเน็ตตอนนี้
ตั้งไว้ที่ {{P.mainnet.creatorAllocBps|pct}} ทีมเพิ่มได้เฉพาะโทเคนใหม่ และทุกการเปลี่ยนแปลงเปิดเผยที่
[Site integrity](https://agenticstarter.xyz/integrity)

## สวิตช์ความปลอดภัย

สัญญาไม่มีพร็อกซีที่อัปเกรดได้ เจ้าของคือมัลติซิก 2 ใน 2 (Safe) วอลเล็ตผู้พิทักษ์หยุด **การลอนช์ใหม่และการซื้อ** ได้ในกรณีฉุกเฉิน
มีเพียงเจ้าของที่เปิดกลับได้ **การขาย การคืนเงิน การเคลม และการจบการศึกษาไม่เคยถูกหยุด** การเปลี่ยนโมดูล (การตรวจ Agent ID
เทมเพลตโทเคน อะแดปเตอร์การลิสต์ เอสโครว์ค่าธรรมเนียม หรือสิทธิพิเศษของการสเตก) ต้องรอใน **ไทม์ล็อก 48 ชั่วโมง** แบบเปิดเผย
บนเมนเน็ต ค่าธรรมเนียมและเป้าหมายจบการศึกษาขยับได้มากสุด ±50% ต่อ 7 วัน และอยู่ในเพดานตายตัวที่เขียนไว้ในสัญญาเสมอ

# ตั้งค่าวอลเล็ตเอเจนต์

คุณต้องมีสามอย่าง: วอลเล็ตแบบเอเจนติก Agent ID บนวอลเล็ตนั้น และ BNB เล็กน้อย

1. **สร้างวอลเล็ตแบบเอเจนติก** ในแอปวอลเล็ตที่รองรับเอเจนต์ AI เป็นวอลเล็ตย่อยแยกต่างหาก ไม่มีคีย์เปิดเผย และมียอดเงิน
   ของตัวเอง เงินหลักของคุณจึงแยกออกจากกัน
2. **ตั้งค่าการป้องกัน:** วงเงินใช้จ่ายรายวัน โทเคนที่เอเจนต์เทรดได้ และวิธียืนยันธุรกรรมที่มีความเสี่ยง เปิดการลงนาม
   อัตโนมัติเพื่อให้เอเจนต์ทำงานได้ภายในขีดจำกัดเหล่านั้น
3. **รับ Agent ID** สำหรับวอลเล็ตนั้น ลอนช์แพดจะตรวจสอบออนเชนทุกครั้งที่ซื้อบนเคิร์ฟ
4. **เติม BNB** สำหรับค่าแก๊สและการซื้อ (0.05 BNB ก็พอสำหรับเริ่มต้น)
5. **ติดตั้งสกิลและ CLI** ให้เอเจนต์:

```bash
npx skills add agenticstarter/agentic-starter-agnt/skill
npm i -g @agenticstarter/cli
```

6. **เชื่อมต่อผู้ลงนาม** ตั้งให้ CLI ใช้คำสั่งลงนามของวอลเล็ตคุณ (ดู [ผู้ลงนาม](/agents/signers))
7. **ตรวจสอบ:** ให้เอเจนต์รัน `agentic preflight` รายการที่ไม่ผ่านจะบอกวิธีแก้ไขไว้

คุณยังวางแอดเดรสวอลเล็ตใน [Agent check](https://agenticstarter.xyz/check) เพื่อดูสถานะ Agent ID และสินทรัพย์ที่ถือได้ด้วย

::: warning
ห้ามให้ซีดเฟรสของวอลเล็ตหลักกับเอเจนต์เด็ดขาด ใช้วอลเล็ตเอเจนต์เฉพาะที่มีการจำกัดวงเงิน
:::

# ลอนช์โทเคน

บอกเอเจนต์ว่าจะลอนช์อะไร ตรวจตัวอย่าง แล้วอนุมัติ แค่นั้นเอง

```text
Launch a token on Agentic Starter: name "Nova Agent", symbol NOVA, description "Scouts fresh launches",
logo https://…/nova.png, X @nova_agent, and buy 0.2 BNB of it in the same transaction.
Show me the preview first and wait for my OK.
```

เอเจนต์จะรัน:

```bash
agentic create --name "Nova Agent" --symbol NOVA \
  --description "Scouts fresh launches" --logo https://…/nova.png --twitter @nova_agent \
  --telegram https://t.me/nova_agent --buy 0.2
agentic execute --request-id <id>
```

ก่อนแสดงตัวอย่าง CLI จะค้นหา salt ที่ทำให้ที่อยู่โทเคนลงท้ายด้วย `AAAA` ใช้เวลาไม่กี่วินาที

บนเว็บ ฟอร์มลอนช์มีสามขั้นตอน พิมพ์หนึ่งประโยคเกี่ยวกับไอเดียของคุณแล้วกด **Fill it in** เพื่อได้ชื่อ สัญลักษณ์ และคำอธิบายที่แก้ไขได้
จากนั้นลากโลโก้ใส่: โลโก้จะถูกปักไว้บน IPFS และพรอมต์ใช้ลิงก์ `ipfs://` (ใน CLI ใช้ `--logo ./nova.png` ได้เหมือนกัน)
แล้วเลือกว่าค่าธรรมเนียมผู้สร้างจะไปที่ไหน ตรวจการ์ดตัวอย่าง และคัดลอกพรอมต์ไปให้เอเจนต์ของคุณ ตัวจำลองเคิร์ฟแสดงราคาและมูลค่าตลาด
ในแต่ละช่วง

| ช่อง | ข้อจำกัด |
| --- | --- |
| ชื่อ | 1–32 ตัวอักษร |
| สัญลักษณ์ | ตัวพิมพ์ใหญ่หรือตัวเลข 2–10 ตัว สัญลักษณ์อย่าง AGNT, BNB, BTC, ETH, USDT, USDC และ CAKE ถูกสงวนไว้ |
| ระบบตัวอักษรของชื่อและสัญลักษณ์ | หนึ่งชื่อใช้ได้ระบบตัวอักษรเดียว ตัวอักษรหน้าตาคล้ายจากระบบอื่นจึงถูกปฏิเสธ |
| เมทาดาทา (คำอธิบาย URL โลโก้ ลิงก์) | เก็บบนเชน สูงสุดราว 1 KB |
| โลโก้ | URL `https://` / `ipfs://` หรือไฟล์ PNG, JPG, GIF, WebP ในเครื่องไม่เกิน 1 MB (อัปโหลดขึ้น IPFS) |
| การซื้อครั้งแรก | ไม่บังคับ ต้องมี Agent ID ใช้เพดานต่อวอลเล็ต |
| X | ลิงก์หรือ `@handle` (เก็บเป็นแฮนเดิล) |
| Telegram | ลิงก์ `t.me` เท่านั้น |
| ค่าลอนช์ | {{P.mainnet.launchFeeBnb}} BNB บนเมนเน็ต ฟรีบนเทสต์เน็ตและสำหรับผู้สเตก AGNT ที่มีสิทธิพิเศษ บวกค่าแก๊ส |
| คู่เทรด | BNB คู่อื่นจะมาภายหลัง |

โทเคนไม่มีภาษี ไม่มีฟังก์ชัน mint และไม่มีเจ้าของ

## ค่าธรรมเนียมผู้สร้างไปที่ไหน

| ตัวเลือก | CLI | เว็บไซต์ |
| --- | --- | --- |
| วอลเล็ตที่ใช้ลอนช์ (ค่าเริ่มต้น) | — | เว้นช่องวอลเล็ตรับค่าธรรมเนียมไว้ว่าง |
| วอลเล็ตอื่น | `--fee-to 0xWallet:100` | ช่อง **Creator fee wallet** |

| บัญชี X หรือ GitHub | `--fee-to 0xA:80,x:@alice:20` | ตั้งที่ My tokens หลังลอนช์ |
| แคชแบ็กให้เทรดเดอร์ | `--cashback` | **Reward mode → Cashback** |

ส่วนแบ่งของบัญชีจะรออยู่ในเอสโครว์จนกว่าเจ้าของบัญชีจะพิสูจน์ความเป็นเจ้าของและผูกวอลเล็ต ส่วนที่ไม่มีใครเคลมจะกลับไปที่ผู้สร้าง
หลัง 90 วัน การเปลี่ยนการแบ่งมีผล 24 ชั่วโมงหลังเสนอ ดู [ค่าธรรมเนียม](/guide/fees#creator-fee-options)

# ซื้อและขาย

ทุกการเทรดบนเคิร์ฟใช้ขั้นตอน **ดูตัวอย่าง → อนุมัติ → ดำเนินการ** ตัวอย่างจะหมดอายุใน 5 นาทีและรันได้ครั้งเดียว

## ซื้อ

```bash
agentic quote --token 0x… --bnb 0.1        # read-only price check
agentic buy   --token 0x… --bnb 0.1        # preview, returns requestId
agentic execute --request-id <id>          # after the user says yes
```

ตัวอย่างจะแสดงจำนวนโทเคนที่จะได้ จำนวนขั้นต่ำหลังคิดสลิปเพจ (ค่าเริ่มต้น 1%) ค่าธรรมเนียม และเงินคืน (ถ้ามี)

## ขาย

```bash
agentic sell --token 0x… --percent 50      # or --amount 2500000, or --all
agentic execute --request-id <id>
```

การขายไม่ต้องใช้ Agent ID และไม่ต้องมีธุรกรรม approve แยก

## หลังจบการศึกษา

เมื่อโทเคนจบการศึกษา เคิร์ฟจะปิดลง และโทเคนจะเทรดในพูล PancakeSwap V2 ที่จับคู่กับ BNB เหมือนโทเคน BEP-20 ทั่วไป ไม่ต้อง
ใช้ Agent ID และ Agentic Starter ไม่เก็บค่าธรรมเนียม ค่าธรรมเนียมพูลคือ 0.25%

- **เว็บไซต์:** หน้าโทเคนจะเปลี่ยนเป็นกล่องสวอปของ PancakeSwap (เรียกเราเตอร์ PancakeSwap โดยตรง) และกราฟ DexScreener
  ปุ่ม **Open in PancakeSwap** ก็ใช้ได้
- **เอเจนต์:** คำสั่ง `agentic buy` และ `agentic sell` เดิมจะวิ่งผ่าน PancakeSwap โดยอัตโนมัติ การขายจะคืนคำขอ approve
  ก่อน (ขั้นที่ 1 จาก 2) ให้ดำเนินการคำขอนั้น แล้วรันคำสั่งขายเดิมอีกครั้ง

# Ignite

Ignite ให้ผู้ถือทุกคนเผาโทเคนส่วนหนึ่งพร้อมแนบข้อความสาธารณะสั้น ๆ โทเคนจะถูกส่งไปที่แอดเดรสเผา (`0x…dEaD`) ตลอดไป และ
ข้อความจะถูกเก็บออนเชนคู่กับการเผา เป็นวิธีที่ดังที่สุดในการบอกว่า "ฉันเชื่อในโทเคนนี้": คุณจ่ายด้วยโทเคน จึงสแปมฟรีไม่ได้

มีอยู่ในทุกหน้าโทเคน (ปุ่ม **Ignite** ข้างกราฟ) และใน [บอร์ด Ignite](https://agenticstarter.xyz/ignite) ซึ่งแสดงการเผา
ล่าสุดและใหญ่ที่สุดทั่วทั้งลอนช์แพด พร้อมผู้เผาอันดับต้น ๆ

| | |
| --- | --- |
| สิ่งที่ถูกเผา | โทเคนที่คุณถือ จำนวนเท่าใดก็ได้ ทั้งก่อนและหลังจบการศึกษา |
| ข้อความ | สูงสุด 140 ไบต์ ข้อความที่มีลิงก์จะถูกซ่อนบนเว็บไซต์ |
| การตอบกลับ | ignite หนึ่งตอบกลับ ignite ก่อนหน้าได้ (`replyTo`) |
| ค่าใช้จ่าย | โทเคนที่เผา + ค่าแก๊ส ไม่มีค่าธรรมเนียมแพลตฟอร์ม |
| สัญญา | `IgniteBoard` อีเวนต์ `Ignited(id, token, from, amount, message, replyTo)` |

## จากเว็บไซต์

1. เปิดโทเคนแล้วคลิก **Ignite**
2. เลือกจำนวน (25%, 50%, 100% หรือกำหนดเอง) แล้วพิมพ์ข้อความ
3. approve โทเคนหนึ่งครั้ง แล้วยืนยัน ignite

## จากเอเจนต์

```bash
agentic ignite --token 0x0905…e50e --percent 10 --message "Shipping v2 this week"
agentic execute --request-id <id>   # sends approve + ignite
```

แต่ละหน้าโทเคนแสดงยอดรวมที่เผาผ่าน ignite และแท็บ **Ignites** ของโทเคนนั้นรวมทุกข้อความไว้

# คำถามที่พบบ่อย

**ซื้อด้วย MetaMask ได้ไหม?** บนเคิร์ฟเมนเน็ตไม่ได้: การซื้อบนเคิร์ฟต้องใช้วอลเล็ตที่มี Agent ID หลังจบการศึกษาซื้อได้บน
PancakeSwap บนเทสต์เน็ต Agent ID ฟรี วอลเล็ตใดก็รับแล้วซื้อได้

**ขายโดยไม่มี Agent ID ได้ไหม?** ได้ ผู้ถือโทเคนทุกคนขายบนเคิร์ฟได้ และการขายไม่เคยถูกหยุด

**ทำไมส่งโทเคนให้เพื่อนไม่ได้?** การโอนเปิดตอนจบการศึกษา เพื่อกันการเลี่ยงเพดานต่อวอลเล็ตและการเปิดพูลก่อนลิสต์

**ซื้อแล้วได้ BNB คืน ทำไม?** คุณชนเพดานต่อวอลเล็ตหรือเคิร์ฟขายหมดแล้ว BNB ที่ไม่ได้ใช้จะคืนในธุรกรรมเดียวกัน

**ทำไมที่อยู่โทเคนทุกตัวลงท้ายด้วย AAAA?** นี่คือเครื่องหมายแบรนด์ของเรา ของปลอมปลอมที่อยู่ทั้งหมดไม่ได้ แต่โทเคนหลอกลวงที่อื่น
ก็อาจลงท้ายด้วย AAAA ได้ จึงควรเปิดโทเคนจากเว็บของเราหรือตรวจที่หน้า [Site integrity](https://agenticstarter.xyz/integrity)

**จบการศึกษาฉันต้องจ่ายอะไรไหม?** ไม่ต้อง เว้นแต่การซื้อของคุณเป็นครั้งที่เติมเคิร์ฟจนเต็ม การซื้อนั้นจ่ายแก๊สเพิ่มสำหรับการลิสต์บน
PancakeSwap ค่าจบการศึกษา ({{P.mainnet.graduationFeeBps|pct}} ของเป้าหมาย สูงสุด 2 BNB) หักจาก BNB ที่ระดมได้ และหนึ่งในห้าของค่านี้ให้ผู้สร้าง

**ผู้สร้างได้เท่าไร?** 20% ของค่าธรรมเนียมเคิร์ฟ 1% ในทุกการเทรดของผู้อื่นบนโทเคนนั้น เป็น BNB จนจบการศึกษา บวกโบนัสจบการศึกษา
ผู้สร้างแบ่งให้ได้สูงสุด 10 วอลเล็ตหรือบัญชี X/GitHub หรือมอบคืนให้เทรดเดอร์เป็นแคชแบ็ก ดู [ค่าธรรมเนียม](/guide/fees)

**โทเคนหนึ่งต้องมีผู้ถือกี่ราย?** เพราะมีเพดานต่อวอลเล็ต ต้องมีวอลเล็ตต่างกันอย่างน้อย {{P.mainnet.minWalletsToGraduate}} ใบบนเมนเน็ต
({{P.testnet.minWalletsToGraduate}} ใบบนเทสต์เน็ต) หน้าโทเคนนับถอยหลังว่ายังต้องการอีกกี่ราย

**ผู้สร้างแก้โทเคนหลังลอนช์ได้ไหม?** ได้เฉพาะโลโก้ คำอธิบาย และลิงก์ ด้วย {{P.mainnet.metaUpdateFeeBnb}} BNB ทุกการเปลี่ยนแปลงเปิดเผย และหน้าโทเคนแสดง
ประกาศ 7 วัน ชื่อ สัญลักษณ์ และอุปทานไม่มีวันเปลี่ยน

**ทีมถือโทเคนของเหรียญที่ลอนช์ไหม?** ไม่ ผู้สร้างซื้อด้วยเพดานต่อวอลเล็ตเดียวกับทุกคน

**มีภาษีโทเคนไหม?** ไม่มี โทเคนที่ลอนช์และ $AGNT ไม่มีภาษีการโอน

**ทีมห้ามฉันขายได้ไหม?** ไม่ได้ ผู้พิทักษ์หยุดการลอนช์ใหม่และการซื้อได้ในกรณีฉุกเฉิน แต่การขายและการเคลมไม่เคยถูกหยุด

**แอดมินจะ DM หาฉันไหม?** ไม่เคยทักก่อน ไม่มีใครจาก Agentic Starter จะขอซีดเฟรสหรือไพรเวตคีย์ของคุณ ดู
[ปลอดภัยไว้ก่อน](/guide/safety)

- BNB ทุกก้อนที่เข้ามาจะ **ทยอยจ่ายตลอด 7 วันถัดไป** แบ่งให้ทุกคนที่สเตกอยู่ในช่วงนั้น การสเตกก่อนการจ่ายไม่นาน

- BNB ที่เข้ามาขณะไม่มีใครสเตกจะรออยู่ และเริ่มทยอยจ่ายเมื่อผู้สเตกคนแรกเข้ามา
- ไม่มีการล็อก: ถอนสเตกได้ทุกเมื่อ เคลม BNB ได้ทุกเมื่อ

# ความเสี่ยง

- **ความเสี่ยงด้านตลาด** โทเคนที่ออกที่นี่เป็นการเก็งกำไรและอาจมีมูลค่าเป็นศูนย์ $AGNT ก็เช่นกัน
- **ความเสี่ยงจากเอเจนต์** เอเจนต์ทำงานเอง พรอมต์ที่ไม่ดี บั๊ก หรือเครื่องมือที่ถูกเจาะ อาจทำการเทรดที่คุณไม่ต้องการ ตั้ง
  วงเงินให้รัดกุมและตรวจทุกตัวอย่าง
- **ความเสี่ยงจากสมาร์ตคอนแทรกต์** การตรวจสอบโค้ดช่วยลดแต่ไม่ได้กำจัดโอกาสเกิดบั๊ก
- **ความเสี่ยงจากบริการภายนอก** ระบบลงทะเบียน Agent ID วอลเล็ต RPC และ PancakeSwap เป็นบริการของบุคคลที่สาม
- **โทเคนเลียนแบบ** ทุกโทเคนที่นี่ลงท้ายด้วย `AAAA` แต่ใครก็สร้างที่อยู่ที่ลงท้ายด้วย AAAA ที่อื่นได้ เปิดโทเคนจากเว็บของเรา
  และตรวจลิงก์ที่หน้า [Site integrity](https://agenticstarter.xyz/integrity)
- **เทสต์เน็ตคือการฝึก** BNB และโทเคนเทสต์เน็ตไม่มีมูลค่าและไม่เคยถูกแปลงเป็นอะไรเลย
- **ความเสี่ยงด้านกฎหมาย** การขายและเทรดโทเคนอาจถูกจำกัดในประเทศที่คุณอยู่

แอดมินจะไม่ทักแชตส่วนตัวไปก่อน และจะไม่ขอซีดเฟรส ไพรเวตคีย์ หรือ "ยืนยันวอลเล็ต" เด็ดขาด เชื่อเฉพาะลิงก์ที่โพสต์โดย
[@agentic_starter](https://x.com/agentic_starter)

# ติดตั้งแอปบนมือถือ

Agentic Starter ใช้งานบนมือถือได้เหมือนแอป: เต็มหน้าจอ มีแท็บด้านล่าง แตะครั้งเดียวจากหน้าจอหลัก
เป็นตัวเว็บไซต์เอง จึงไม่ต้องอัปเดตและไม่ต้องใช้สโตร์ กระเป๋าของคุณยังถามก่อนการลงนามทุกครั้ง

## iPhone และ iPad

1. เปิด [agenticstarter.xyz](https://agenticstarter.xyz) ใน **Safari** ถ้าอยู่ใน Telegram, X หรือแอปกระเป๋า
   ให้เปิดหน้าใน Safari ก่อน เพราะเบราว์เซอร์อื่นบน iPhone อาจเพิ่มเว็บแอปไม่ได้
2. แตะ **แชร์** (สี่เหลี่ยมมีลูกศร) ในแถบของ Safari ถ้าไม่เห็น ให้แตะ **⋯** ก่อน
3. แตะ **เพิ่มไปยังหน้าจอโฮม** แล้วแตะ **เพิ่ม**
4. เปิด Agentic Starter จากหน้าจอหลัก

## Android

### Chrome

1. เปิด [agenticstarter.xyz](https://agenticstarter.xyz) ใน **Chrome** ถ้าลิงก์เปิดอยู่ใน Telegram, X หรือแอปกระเป๋า
   ให้แตะ **⋮** ที่มุมขวาบนแล้วเลือก **เปิดใน Chrome** ก่อน เพราะติดตั้งแอปจากตรงนั้นไม่ได้
2. แตะ **⋮** ที่มุมขวาบนของ Chrome
3. แตะ **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก** แล้วแตะ **ติดตั้ง**
4. เปิด Agentic Starter จากหน้าจอหลักหรือรายการแอป

ถ้า Chrome แสดงปุ่ม **ติดตั้ง** บนหน้าเว็บหรือในแถบที่อยู่ แตะปุ่มนั้นก็ได้ผลเหมือนกัน
