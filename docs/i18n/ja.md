# はじめに

暗号資産や Agentic Starter は初めてですか？このページでは約 15 分でゼロから最初のトークンまで進めます。以下はすべて
**BNB Chain テストネット**で行います。テストネットの BNB は無料のテスト用なので、何も失うことはありません。

<div class="flow">
  <div><b>1. ウォレット</b><small>ウォレットアプリを入れる</small></div>
  <div class="arrow">→</div>
  <div><b>2. テスト BNB</b><small>フォーセットで無料</small></div>
  <div class="arrow">→</div>
  <div><b>3. Agent ID</b><small>テストネットでは無料</small></div>
  <div class="arrow">→</div>
  <div><b>4. 取引</b><small>カーブで売買</small></div>
  <div class="arrow">→</div>
  <div><b>5. ローンチ</b><small>自分のトークン</small></div>
</div>

## 1. ウォレットを用意する

ウォレットは暗号資産を保管し、トランザクションに署名するアプリです。MetaMask、Trust Wallet、Rabby など BNB Chain 対応の
ウォレットを入れてください。

作成時にアプリが**シードフレーズ**（12 または 24 単語）を表示します。紙に書いてオフラインで保管してください。これを持つ人が
ウォレットを支配します。Agentic Starter の誰も、これを求めることはありません。

## 2. 無料のテスト BNB をもらう

1. [agenticstarter.xyz](https://agenticstarter.xyz) を開き **Connect** を押します。サイトがウォレットに
   **BNB Smart Chain Testnet**（chain 97）への切り替えを求めるので、承認します。
2. ウォレットアドレス（`0x` で始まる）をコピーします。
3. BNB Chain テストネットのフォーセットを開き、アドレスを貼り付けて tBNB を申請します。1〜2 分で届きます。 [bnbchain.org/en/testnet-faucet](https://www.bnbchain.org/en/testnet-faucet)

ローンチパッドの [Start ページ](https://agenticstarter.xyz/start)が同じ手順を案内し、終わるたびにチェックを付けます。

## 3. Agent ID を取得する

ボンディングカーブで購入するにはウォレットに **Agent ID** が必要です。テストネットでは無料です。どれかのトークンページを開き
**Get Agent ID** を押してください。少しのテストガスだけかかります。

## 4. 初めての取引

同じトークンページで少し買い、そのあと一部を売ってみましょう。進捗バーが PancakeSwap に向かって進むのが見えます。売却に
Agent ID は不要です。

## 5. 自分のトークンをローンチ

[Launch](https://agenticstarter.xyz/launch) を開き、名前・シンボル・ロゴを入力して **Open in Telegram** を押します。ボットの
Agen があなたのウォレットのためにローンチし、ガスを負担します。詳しくは[トークンをローンチする](/guide/launch#testnet-telegram)。

## ついでに：エアドロップ

これらの各ステップで[エアドロップポイント](/token/airdrop)も貯まります。ローンチ、取引、毎日のクイズなど。

## よく出てくる言葉

「カーブ」「卒業」「ガス」の意味がわからない？[用語集](/guide/glossary)をご覧ください。まだ困ったら、各サイトの隅にある
チャットバブルの Agen か、Telegram グループで質問してください。

# 用語集

| 用語 | 意味 |
| --- | --- |
| **AAAA アドレス** | ここでローンチされたトークンのコントラクトアドレスはすべて `AAAA` で終わります。ブランドの印であって安全チェックではありません。トークンは必ず当サイトから開いてください。 |
| **エージェント** | あなたの代わりに動く AI プログラム。ここでは、あなたが決めた上限内で自分のウォレットからトークンをローンチ・取引します。 |
| **Agent ID** | エージェントウォレットが持つ資格情報。ボンディングカーブでの購入に必要。テストネットでは無料。 |
| **エージェントウォレット** | エージェントが使う別のウォレット。支出上限があり、メインの資金と分けられます。 |
| **エアドロップ** | シーズン終了後、対象ウォレットにポイントの割合で配られる無料の $AGNT。 |
| **BNB** | BNB Chain のネイティブコイン。ガス代の支払いに使い、ここのトークンはすべて BNB 建てです。 |
| **BNB Chain** | Agentic Starter が動くブロックチェーン。 |
| **ボンディングカーブ** | 数式で決まる価格で新しいトークンを売るコントラクト。買うたびに価格が上がり、売るたびに下がります。板は不要です。 |
| **バーン** | 誰も管理しないアドレスへトークンを送り、永久に消すこと。 |
| **作成者** | トークンがローンチされた対象のウォレット。卒業までカーブ手数料の一部を受け取ります（またはトレーダーにキャッシュバックとして渡します）。 |
| **キャッシュバック** | ローンチ時のオプション。カーブ手数料のうち作成者分が、取引のたびにそのトレーダーへ戻ります。 |
| **Featured** | AGNT のバーンで買える Explore の掲載枠。広告であって、レビューではありません。 |
| **ゴールデンアワー** | 1 日 1 時間だけ、エアドロップポイントが 2 倍になる時間。 |
| **カーブ手数料** | ボンディングカーブでの売買ごとに 1%。[手数料](/guide/fees)を参照。 |
| **フォーセット** | テストネットの BNB を無料で配るサイト。 |
| **ガス** | トランザクションごとにネットワークが取る少額の手数料。BNB で支払います。 |
| **Genesis Creator** | メインネットで最初に卒業した 100 トークンの作成者に贈られる永久バッジ。 |
| **卒業** | カーブが満ちた瞬間。トークンはロックされた流動性とともに PancakeSwap に移り、カーブは閉じます。 |
| **Ignite** | トークンの一部を公開メッセージ付きでバーンすること。[Ignite](/guide/ignite)を参照。 |
| **LP トークン** | PancakeSwap プールの持ち分の証明。卒業時にバーンするので、流動性は決して引き出せません。 |
| **メインネット** | 本物のお金を使う本番ネットワーク。 |
| **PancakeSwap** | BNB Chain 最大の取引所。卒業したトークンはそこで取引されます。 |
| **プレセール** | 上場前の $AGNT 最初の公開販売。[プレセール](/token/presale)を参照。 |
| **シードフレーズ** | ウォレットを支配する 12 または 24 単語。誰とも決して共有しないでください。 |
| **スリッページ** | プレビューから取引までに許される価格変動の幅。超えると取引は拒否されます。 |
| **スナップショット** | ポイントが確定し、エアドロップの取り分が計算される時点。 |
| **ステーキング** | BNB で手数料の分配を受けるために $AGNT をコントラクトに預けること。[ステーキング](/token/staking)を参照。 |
| **テストネット** | BNB が無料で価値のない、BNB Chain の練習用コピー。 |
| **TGE** | トークン生成イベント。$AGNT が PancakeSwap に上場し、プレセールの請求が始まる日。 |
| **ウォレット上限** | トークンがカーブ上にある間、1 つのウォレットが保有できる最大量（メインネット {{P.mainnet.walletCapBps|pct}}、テストネット {{P.testnet.walletCapBps|pct}}）。 |

# Agentic Starter とは

::: tip 初めてですか？
[はじめに](/guide/start)のページで、約 15 分でテストネットの最初のトークンまで進めます。
:::

Agentic Starter は、AI エージェントのために作られた BNB Chain 上のトークンローンチパッドです。エージェントがトークンを
発行し、エージェントがボンディングカーブで売買し、あなたは各ステップを承認します。カーブが埋まると、トークンは BNB
ペアで PancakeSwap に上場します。

メインネットでは [agenticstarter.xyz](https://agenticstarter.xyz) に購入ボタンはありません。サイトではマーケット、
チャート、ホルダー、エージェントを表示し、取引は [エージェント CLI](/agents/cli) とエージェントウォレットで行います。

::: tip テストネット
BNB Chain テストネットでは、エージェントなしで誰でも試せます。Telegram ボットで発行し
（[トークンを発行する](/guide/launch#testnet-telegram)）、任意のトークンページで無料のテストネット Agent ID を取得して、
通常のウォレットからテスト用 BNB で購入できます。
:::

## なぜエージェント専用なのか

| 一般的なローンチパッドの問題 | Agentic Starter の対策 |
| --- | --- |
| スナイパーボットが最初のブロックで購入 | カーブで購入できるのは Agent ID を持つウォレットのみ |
| 1 頭のクジラが供給の大半を買い占める | カーブ上では 1 ウォレットあたり最大 1% |
| 発行前のプール作成、OTC での売り浴びせ | 卒業まで送金はロック |
| 上場後に流動性が引き抜かれる | 卒業時に LP トークンをバーン |
| 手数料の行き場がない | 1% の手数料は作成者に支払われ、$AGNT をバーンし、ステーカーに BNB で支払われる |

## 対象ユーザー

- オーナーが決めた範囲内で、エージェントに安全にトークンの発行と取引をさせたい**エージェント開発者**。
- ボットのいない公平なスタートを望む**コミュニティ**。
- すべての発行から手数料の分配を受ける **$AGNT ホルダー**。

## フェーズ 1 の範囲

すべてのトークンは **BNB Chain** 上で **BNB** とペアになります。エージェントウォレットが広まれば他のペアやチェーンが加わる
可能性がありますが、その前にコミュニティに相談します。

=== FILE guide/how-it-works.md ===
# 仕組み

すべてのトークンは同じ道をたどります：**ローンチ → ボンディングカーブ → PancakeSwap へ卒業**。

<div class="flow">
  <div><b>ローンチ</b><small>10 億トークンを作成。8 億はカーブへ、2 億は流動性用に保持。</small></div>
  <div class="arrow">→</div>
  <div><b>ボンディングカーブ</b><small>エージェントが買い、誰でも売れる。買うたびに価格上昇。取引ごとに 1% の手数料。</small></div>
  <div class="arrow">→</div>
  <div><b>卒業</b><small>{{P.mainnet.graduationTargetBnb}} BNB で PancakeSwap に上場。LP バーン、カーブ終了。</small></div>
</div>

## 1. エージェントウォレットを接続する

エージェントは、あなたが日次上限を決めたエージェントウォレットで動きます。カーブで買うにはウォレットに **Agent ID** が必要
です。[エージェントウォレットの設定](/guide/agent-wallet)を参照。テストネットではどのウォレットでも無料で Agent ID を取得
できます。

## 2. ボンディングカーブでローンチ

ローンチすると、総供給量 **1,000,000,000** 固定のトークンが作られます：

| 区分 | 数量 | 用途 |
| --- | --- | --- |
| カーブ | 800,000,000 | ボンディングカーブに沿って販売 |
| 流動性 | 200,000,000 | 卒業時に PancakeSwap へ追加 |

トークンアドレスは必ず **`AAAA`** で終わります。これはブランドの印であって保証ではないので、トークンは必ず
[agenticstarter.xyz](https://agenticstarter.xyz) から開くか、[Site integrity](https://agenticstarter.xyz/integrity) で確認してください。

価格は定積公式に従います。買うと上がり、売ると下がります。作成者はローンチのトランザクションで最初の購入ができ、全員と同じ
ウォレット上限が適用されます。

カーブ上のルール：

- **購入：** Agent ID 保有者のみ。購入のたびにオンチェーンで確認。
- **売却：** 誰でも可。approve のトランザクションは不要。売却は決して停止されません。
- **ウォレット上限：** メインネットでは 1 ウォレットあたり供給量の {{P.mainnet.walletCapBps|pct}}（テストネットは {{P.testnet.walletCapBps|pct}}）。
  上限を超える購入は切り詰められ、残りの BNB は同じトランザクションで返金されます。この上限のため、メインネットで卒業
  するには少なくとも **{{P.mainnet.minWalletsToGraduate}} の異なるウォレット**が必要です
  （テストネットは {{P.testnet.minWalletsToGraduate}}）。あと何人のホルダーが必要かはトークンページに表示されます。
- **手数料：** 売買ごとに 1%。[手数料](/guide/fees)を参照。
- **送金：** ロック。トークンはカーブとトレーダーの間でしか動かないため、誰も上限を回避したり先にプールを作ったりできません。

各トークンはローンチ時の設定（卒業目標、ウォレット上限、卒業手数料とボーナス）を保持します。チームが後で設定を変えても、
新しいトークンにだけ適用されます。

## 3. PancakeSwap へ卒業

カーブが目標（メインネット **{{P.mainnet.graduationTargetBnb}} BNB**、テストネット
**{{P.testnet.graduationTargetBnb}} BNB**）に達すると、卒業が実行され：

1. 送金を永久にアンロックし、
2. 卒業手数料を受け取ります。目標額の {{P.mainnet.graduationFeeBps|pct}}、上限 2 BNB
   （メインネットの目標では {{P.mainnet.graduationFeeBnb}} BNB）。その 5 分の 1（{{P.mainnet.creatorBonusBps|pct}}）は
   **作成者への卒業ボーナス**、残りはトレジャリーへ。
3. 流動性用の 2 億トークンと残りの BNB を PancakeSwap V2 に追加し、LP を直接バーンアドレスにミントして、流動性を永久に
   ロックします。

カーブを満たす購入が卒業を実行します。そうならない場合（たとえばトークンに最低カーブ期間がある場合）は、目標に達したあと
誰でも `graduate(token)` を呼び出せます。上場価格はカーブ最後の価格と同じなので、価格の跳ね上がりはありません。卒業後は
プラットフォーム手数料がなく、Agent ID の有無にかかわらず誰でも PancakeSwap で取引できます。

::: tip カーブを満たす購入が上場コストを払う
最後の購入が移行を実行するため、ガスが多めにかかります。CLI はこれを `nearGraduation` と表示します。
:::

## 作成者への割り当て（テストネット）

テストネットでは、作成者は供給量の {{P.testnet.creatorAllocBps|pct}} をローンチ価格で、ウォレット上限の外で受け取ります。
これはローンチパッドが保管し、卒業前は売却できず、卒業後 {{P.testnet.creatorAllocUnlockDays}} 日かけて
リニアにアンロックされます。メインネットでは現在 {{P.mainnet.creatorAllocBps|pct}} に設定されています。チームが引き上げられるのは
新しいトークンに対してのみで、すべての変更は [Site integrity](https://agenticstarter.xyz/integrity) で公開されます。

## 安全スイッチ

コントラクトにアップグレード可能なプロキシはありません。オーナーは 2-of-2 のマルチシグ（Safe）です。ガーディアンウォレットは
緊急時に**新規ローンチと購入**を停止できますが、再開できるのはオーナーだけです。**売却、返金、請求、卒業は決して停止
されません。**モジュール（Agent ID の確認、トークンテンプレート、上場アダプター、手数料エスクロー、ステーキング特典）の
入れ替えには、公開の **48 時間タイムロック**の待機が必要です。メインネットでは、手数料と卒業目標は 7 日間で最大 ±50% までしか
動かせず、常にコントラクトに書かれた上限の範囲内です。

# エージェントウォレットの設定

必要なのは 3 つ：エージェンティックウォレット、そのウォレットの Agent ID、少しの BNB です。

1. AI エージェントに対応したウォレットアプリで**エージェンティックウォレットを作成**します。鍵が露出しない独立した
   サブウォレットで独自の残高を持つため、メインの資金とは分けて管理できます。
2. **安全設定を行います：** 1 日の支出上限、エージェントが取引できるトークン、リスクのあるトランザクションの確認方法。
   その範囲内でエージェントが動けるよう、自動署名をオンにします。
3. そのウォレットで **Agent ID を取得**します。ローンチパッドはカーブでの購入ごとにオンチェーンで確認します。
4. ガス代と購入用に **BNB を入金**します（始めるなら 0.05 BNB で十分です）。
5. エージェントに**スキルと CLI をインストール**します。

```bash
npx skills add agenticstarter/agentic-starter-agnt/skill
npm i -g @agenticstarter/cli
```

6. **署名者を接続します。** CLI がウォレットの署名コマンドを使うよう設定します（[署名者](/agents/signers)を参照）。
7. **確認します：** エージェントに `agentic preflight` を実行してもらいます。失敗した項目には修正方法が表示されます。

[Agent check](https://agenticstarter.xyz/check) にウォレットアドレスを貼り付けると、Agent ID の状態と保有資産も確認
できます。

::: warning
メインウォレットのシードフレーズは絶対にエージェントに渡さないでください。上限を設定した専用のエージェントウォレットを
使いましょう。
:::

# トークンをローンチする

エージェントに何をローンチするか伝え、プレビューを確認し、承認する。それだけです。

```text
Launch a token on Agentic Starter: name "Nova Agent", symbol NOVA, description "Scouts fresh launches",
logo https://…/nova.png, X @nova_agent, and buy 0.2 BNB of it in the same transaction.
Show me the preview first and wait for my OK.
```

エージェントは次を実行します：

```bash
agentic create --name "Nova Agent" --symbol NOVA \
  --description "Scouts fresh launches" --logo https://…/nova.png --twitter @nova_agent \
  --telegram https://t.me/nova_agent --buy 0.2
agentic execute --request-id <id>
```

プレビューの前に、CLI はトークンアドレスが `AAAA` で終わる salt を探します。数秒かかります。

ウェブサイトのローンチフォームは 3 ステップです。アイデアを 1 文で入力して **Fill it in** を押すと、編集できる名前・
シンボル・説明文が作られます。ロゴをドロップすると IPFS に固定され、プロンプトは `ipfs://` リンクを使います（CLI では
`--logo ./nova.png` で同じことができます）。次に作成者手数料の行き先を選び、プレビューカードを確認して、エージェント用の
プロンプトをコピーします。カーブシミュレーターが各段階の価格と時価総額を示します。

| 項目 | 制限 |
| --- | --- |
| 名前 | 1〜32 文字 |
| シンボル | 大文字の英字または数字 2〜10 文字。AGNT、BNB、BTC、ETH、USDT、USDC、CAKE などのティッカーは予約済み |
| 名前とシンボルの文字種 | 1 つの名前につき 1 種類の文字のみ。他の文字種の似た文字は拒否されます |
| メタデータ（説明、ロゴ URL、リンク） | オンチェーン保存、約 1 KB まで |
| ロゴ | `https://` / `ipfs://` の URL、または 1 MB までのローカル PNG・JPG・GIF・WebP（IPFS にアップロード） |
| 最初の購入 | 任意、Agent ID が必要、ウォレット上限あり |
| X | リンクまたは `@handle`（ハンドルとして保存） |
| Telegram | `t.me` のリンクのみ |

# 購入と売却

カーブ上の取引はすべて **プレビュー → 承認 → 実行** の流れです。プレビューは 5 分で期限切れになり、実行は 1 回だけです。

## 購入

```bash
agentic quote --token 0x… --bnb 0.1        # 価格を確認するだけ
agentic buy   --token 0x… --bnb 0.1        # プレビュー、requestId を返す
agentic execute --request-id <id>          # ユーザーの承認後
```

プレビューには、受け取るトークン数、スリッページ（既定 1%）適用後の最低数量、手数料、返金額（ある場合）が表示されます。

## 売却

```bash
agentic sell --token 0x… --percent 50      # または --amount 2500000、または --all
agentic execute --request-id <id>
```

売却には Agent ID も、別途の approve トランザクションも不要です。

## 卒業後

トークンが卒業するとカーブは閉じ、ほかの BEP-20 トークンと同じように BNB ペアの PancakeSwap V2 プールで取引されます。
Agent ID は不要で、Agentic Starter は手数料を取りません。プール手数料は 0.25% です。

- **サイト：** トークンページが PancakeSwap のスワップ欄（PancakeSwap ルーターを直接呼び出し）と DexScreener チャートに
  切り替わります。**Open in PancakeSwap** も使えます。
- **エージェント：** 同じ `agentic buy` と `agentic sell` コマンドが自動的に PancakeSwap を経由します。売却ではまず
  approve リクエスト（2 ステップ中 1）が返るので、それを実行してから同じ売却コマンドをもう一度実行します。
- BNB Chain 上の**どのウォレットやアグリゲーター**でもプールで取引できます。

## マーケットを追う

```bash
agentic near-grad                          # 卒業に最も近いトークン
agentic watch --max-events 1 --timeout 30m # 次のイベントを待つ（NDJSON）
```

# Ignite

Ignite は、どのホルダーでもトークンの一部をバーンし、短い公開メッセージを添えられる機能です。トークンはデッドアドレス
（`0x…dEaD`）へ永久に送られ、メッセージはバーンと一緒にオンチェーンに記録されます。「このトークンを信じている」と伝える
最も力強い方法です。トークンを支払うので、タダでスパムすることはできません。

すべてのトークンページ（チャート横の **Ignite** ボタン）と [Ignite ボード](https://agenticstarter.xyz/ignite)にあり、
ボードではローンチパッド全体の最新・最大のバーンとトップバーナーを確認できます。

| | |
| --- | --- |
| バーンするもの | 保有するトークンを好きなだけ。卒業の前後どちらでも可 |
| メッセージ | 最大 140 バイト。リンクを含むメッセージはサイト上で非表示 |
| 返信 | 以前の ignite に返信できます（`replyTo`） |
| コスト | バーンするトークン + ガス代。プラットフォーム手数料なし |
| コントラクト | `IgniteBoard`、イベント `Ignited(id, token, from, amount, message, replyTo)` |

## サイトから

1. トークンを開いて **Ignite** をクリックします。
2. 数量（25%、50%、100%、または任意）を選び、メッセージを書きます。
3. トークンを一度 approve してから ignite を確定します。

## エージェントから

```bash
agentic ignite --token 0x0905…e50e --percent 10 --message "Shipping v2 this week"
agentic execute --request-id <id>   # approve + ignite を送信
```

各トークンページには ignite でバーンされた合計が表示され、**Ignites** タブですべてのメッセージを見られます。

## 作成者手数料のオプション {#creator-fee-options}

ローンチ時に、作成者は 2 つのモードから選びます：

| モード | 作成者の 20% の扱い |
| --- | --- |
| **作成者手数料**（既定） | 作成者ウォレット、または最大 10 受取人への分割で支払われます。受取人はウォレットでも **X または GitHub アカウント**でもかまいません。アカウント宛ての分は、持ち主がウォレットを紐づけるまでエスクローで待機します（誰も請求しなければ 90 日後に作成者へ戻ります）。 |
| **キャッシュバック** | 売買のたびにトレーダーへ戻るため、トレーダーの負担が減ります。 |

新しい手数料分割は提案から 24 時間後に適用されるため、ホルダーは変更を事前に見られます。作成者の役割を別のウォレットへ
移すのは 2 段階の移転で、新しいウォレットが承認する必要があります。

## オーナーが超えられない上限

手数料はコントラクトに書かれた範囲内でしか変えられません：卒業手数料は目標額の最大 5% かつ 2 BNB まで、作成者の卒業ボーナスは
その手数料の最大 30%、卒業目標は最大 50 BNB、ローンチ手数料は最大 0.02 BNB、更新手数料は最大 0.05 BNB、作成者の取り分は
最大 30%。メインネットでは、これらはそれぞれ 7 日間で最大 ±50% までしか動かせません。1% のカーブ手数料そのものは固定です。

## グループのルール

- 思いやりを持ちましょう。侮辱、FUD キャンペーン、スパム、他プロジェクトの宣伝は禁止です。
- リンク：公式リンクのみ（[安全のために](/guide/safety)を参照）。それ以外のリンクは削除されます。
- ストライク：ひどい侮辱は即座に 1 ストライク、軽い違反は警告後に繰り返した場合。20 日間で **5 ストライク**になると BAN
  です。ストライクは 20 日で失効します。
- 管理者から先に DM を送ることはなく、鍵、シードフレーズ、BNB を求めることもありません。
- チームを装った名前（admin、support、Agentic Starter、Agen）は発言制限され、「DM して」、シードフレーズ、「ウォレットを認証」といったメッセージは削除されます。

対応が間違っていると思う場合は、グループで管理者に連絡してください。

# よくある質問

**MetaMask で買えますか？** メインネットのカーブでは買えません。カーブでの購入には Agent ID のあるウォレットが必要です。卒業後は
PancakeSwap で買えます。テストネットでは Agent ID が無料なので、どのウォレットでも取得して購入できます。

**Agent ID なしで売れますか？** はい。トークンの保有者なら誰でもカーブで売れ、売却は決して停止されません。

**友達にトークンを送れないのはなぜ？** 送金は卒業時に解放されます。ウォレット上限の回避や上場前のプール作成を防ぐためです。

**購入したら BNB が返ってきました。なぜ？** ウォレット上限に達したか、カーブが売り切れました。使われなかった BNB は同じ
トランザクションで返金されます。

**なぜ全トークンのアドレスが AAAA で終わるの？** 当サイトのブランドの印です。偽物がアドレス全体を真似ることはできませんが、他所
の詐欺トークンも AAAA で終わることはあり得るので、トークンは当サイトから開くか
[Site integrity](https://agenticstarter.xyz/integrity) ページで確認してください。

**卒業に私の費用はかかりますか？** かかりません。あなたの購入がカーブを満たす購入だった場合だけ、PancakeSwap 上場の追加ガスを
払います。卒業手数料（目標額の {{P.mainnet.graduationFeeBps|pct}}、上限 2 BNB）は集まった BNB から差し引かれ、その 5 分の 1 は
作成者に渡ります。

**作成者はいくら稼げますか？** 他の人によるそのトークンの取引ごとに、1% カーブ手数料の 20% を BNB で、卒業まで。加えて卒業
ボーナス。最大 10 のウォレットや X/GitHub アカウントと分け合うことも、キャッシュバックとしてトレーダーに戻すこともできます。
[手数料](/guide/fees)を参照。

**トークンには何人のホルダーが必要ですか？** ウォレット上限があるため、メインネットでは少なくとも
{{P.mainnet.minWalletsToGraduate}} の異なるウォレットが必要です（テストネットは {{P.testnet.minWalletsToGraduate}}）。
トークンページに、あと何人必要かが表示されます。

**作成者はローンチ後にトークンを変更できますか？** ロゴ・説明・リンクのみ、{{P.mainnet.metaUpdateFeeBnb}} BNB で可能です。変更はすべて公開され、
トークンページに 7 日間お知らせが表示されます。名前・シンボル・供給量は決して変わりません。

**チームはローンチされたコインのトークンを持っていますか？** いいえ。作成者も全員と同じウォレット上限で購入します。

**トークンに税はありますか？** ありません。ローンチされたトークンも $AGNT も送金税はありません。

**チームが私の売却を止められますか？** いいえ。ガーディアンは緊急時に新規ローンチと購入を停止できますが、売却と請求は決して
停止されません。

**管理者から DM が来ますか？** こちらから先に送ることは決してありません。Agentic Starter の誰も、シードフレーズや秘密鍵を
求めることはありません。[安全のために](/guide/safety)を参照。

**カーブなしの普通のトークンを作れますか？** はい、[スタンダードトークンファクトリー](/guide/standard-tokens)で作れます。

**コードはどこで見られますか？** [github.com/agenticstarter/agentic-starter-agnt](https://github.com/agenticstarter/agentic-starter-agnt)。
コントラクトアドレスは [Site integrity](https://agenticstarter.xyz/integrity) にあります。

## 価格の仕組み（「250+」）

| 集まった額 | 何が起きるか |
| --- | --- |
| {{P.presale.softCapBnb}} BNB 未満（ソフトキャップ） | セールは不成立。購入者全員がプレセールページで BNB の 100% を返金できます |
| {{P.presale.softCapBnb}}〜{{P.presale.floorCapBnb}} BNB | 全員がフロア価格で購入：**1 BNB = {{P.presale.floorAgntPerBnb|n}} AGNT**。売れ残りの AGNT は確定時にバーン |

| 集まった合計 | 1 BNB で買える量 |

| 250 BNB | 1,000,000 AGNT |
| 500 BNB | 500,000 AGNT |
| 1,000 BNB | 250,000 AGNT |

{{P.presale.floorCapBnb}} BNB を超えている間は、他の人が購入するにつれて受け取れる AGNT の量が少し減ることがありますが、あなたの BNB は
そのままです。

| 項目 | 値 |
| --- | --- |
| フロア価格 | 1 BNB = {{P.presale.floorAgntPerBnb|n}} AGNT、{{P.presale.floorCapBnb}} BNB が集まるまで |
| 販売する AGNT | {{P.presale.saleTokens|n}}（供給量の 25%）。セール開始前にコントラクトへ預け入れ済み |
| ソフトキャップ | {{P.presale.softCapBnb}} BNB |
| 1 ウォレットあたり | 合計で最小 {{P.presale.perWalletBnb.0}} BNB、最大 {{P.presale.perWalletBnb.1}} BNB |

| クレーム | 上場時に 100% |

## あなたの BNB はどう守られるか

1. あなたの BNB はプレセールコントラクトに残ります。セールが終わるまで、チームは引き出せません。
2. ソフトキャップに届かなければセールは不成立となり、購入者全員がプレセールページで 100% を返金できます。
3. セール後、BNB の 80% が上場時に PancakeSwap のプールへ入り、LP はバーンされます。各ステップはプレセールページの上場
   チェックリストからリンクされています。[上場](/token/listing)を参照。

## 友達を招待する

プレセールページでウォレットを接続すると、招待リンク（`presale.agenticstarter.xyz/?ref=<あなたのウォレット>`）を取得
できます。誰かがこのリンクから購入すると、プレセールコントラクトが購入と一緒に招待を記録します（`contributeWithRef`）。
購入者の支払額は増えず、割当量も変わりません。

- あなたのリンクから 0.05 BNB 以上購入したウォレットごとに **エアドロップポイント100** が加算されます（クエスト Q6、最大
  50人）。
- 自分でプレセールに参加するのはクエスト Q5：0.05 BNB から **+500ポイント**、その後 0.01 BNB ごとに +100（最大10,000）、
  最初の48時間の購入は **500** 追加。エアドロップ用と別のウォレットで購入した場合は、エアドロップページで一度連携して
  ください（Q5 カード）。
- ポイントは、あなたのウォレットがエアドロップの必須クエスト 3 つを終えると反映されます。
- 自分のリンクでの購入は対象外で、返金された購入は除外されます。

## セール終了後

1. **確定**：BNB はトレジャリー Safe へ送られ、売れ残りの AGNT はバーンされます。
2. 翌日 14:00 UTC に**上場**：BNB の 80% が最終プレセール価格で AGNT/BNB プールに入り、LP がバーンされ、その後クレームが
   開きます。
3. プレセールページで AGNT（とアーリーボーナス）の 100% をクレームします。

各ステップは、トランザクションへのリンクとともにプレセールページの上場チェックリストでチェックされます。そこでリマインダー
（Telegram またはカレンダー）をオンにすると、クレームが開くタイミングがわかります。

## 返金

拠出は確定扱いですが、例外が 2 つあります。

- **セール不成立**：ソフトキャップに届かずに終了した場合。返金は自動的に開きます。
- **クレームが開く前に、チームが返金モードを開く場合。** 確定後にこれが起きた場合、全購入者が全額返金を受けられるよう、
  チームはまず全額をプレセールコントラクトに戻す必要があります。

どちらの場合も、プレセールページで BNB の 100% を返金できます。

## Agen Gift Hour

毎日 **14:00〜15:00 UTC** に、agenticstarter.xyz でテストネットの $AGNT を **0.01 BNB** 以上買いましょう。その1時間の最初の
購入で、ウォレットに**ギフトボックス**が1つ届きます。サイトにボックスが現れ、開けると中に**本物の $AGNT** がいくら入っているか
わかります。ボックスごとに量は違います。

- 1ウォレットにつき1日1箱：その1時間内の 0.01 BNB 以上の最初の購入が対象です。すぐに開けなかったボックスはサイトで待っています。
- Gift Hour の $AGNT はエアドロップと一緒に、必須クエスト（Q1〜Q3）を終え、不正で除外されていないウォレットに支払われます。
- Gift Hour の合計は、エアドロップページのポイントの横と Agen の /points で確認できます。
- 開けたら、画像を X や Telegram グループでシェアしましょう。
- 時間終了後、その日のボックスから1つがランダムに**ラッキーボックス**に選ばれ、中の $AGNT が2倍（x2）になります。
  Agen がグループで発表し、当選者に知らせます。
- 終了10分前に Agen がグループでリマインドを投稿し、アプリはまだボックスがないウォレットに通知します。
- **グループ目標：**1日にボックスを受け取るウォレットが多いほど、その日のすべてのボックスが増えます：100 ウォレットで **+5%**、250 で **+10%**、500 で **+20%**。時間終了後に加算されます。Gift Hour 帯のバーで次のレベルまでの距離がわかり、グループの Agen の Gift Hour 投稿はレベル達成ごとに自動で更新されます。

## 認証の仕組み

1. **ウォレット。** 接続してメッセージに署名します。無料で、トランザクションは送りません。
2. **X（Q1）。** Follow と Quote ボタンを使い、引用ポストへのリンクを貼り付けます。ほとんどの投稿は数秒で自動的に確認され、

3. **Telegram（Q2）。** **Telegram を開く** をタップし、エアドロップボットで **Start**。Telegram アカウントがウォレットに
   連携され、チャンネルとグループの参加ボタンが表示されます。カードは自動でチェックされます。どちらかを抜けるとポイントは
   消えます。
4. **チャット（Q3）。** Agen がメッセージを数えます。3 文字未満、繰り返し、転送、直前から 5 秒以内のメッセージは数えません。
5. **オンチェーン（Q4–Q6）** は BNB Chain から自動で読み取ります。別のウォレットで購入したプレセールは、そのウォレットが
   無料のメッセージに署名して連携すると加算されます（Q5 カード）。1つのプレセール用ウォレットは1つのエアドロップ用
   ウォレットに永久に紐づきます。

X アカウント、Telegram アカウント、プレセール用ウォレットは、それぞれ1つのエアドロップ用ウォレットにのみ連携できます。

# ステーキング

`AGNTStaking` コントラクトに $AGNT をステークして、ローンチパッドの手数料から BNB を受け取りましょう。

- ステーカーは**すべてのカーブ手数料の 30%** を BNB で受け取ります。
- 届いた BNB は**その後 7 日間にわたって少しずつ流れ**、その間ステークしている全員で分け合います。支払いの直前にステーク
  しても受け取れません。
- 誰もステークしていない間に届いた BNB は待機し、最初のステーカーが参加した時点から流れ始めます。
- ロックなし：いつでもアンステーク、いつでも BNB を請求できます。

## 特典

**7 日以上**ステークされた AGNT が特典の対象になります。AGNT を追加すると、ポジション全体の 7 日間のカウントが再スタート
するため、特典を 1 ブロックだけで手に入れることはできません。

| 特典 | 条件 |
| --- | --- |
| ローンチパッドでの無料ローンチ | 7 日間 100,000 AGNT をステーク |
| スタンダードトークンファクトリーが半額 | 7 日間 100,000 AGNT をステーク |
| Snapshot の投票の重み | 7 日間ステークした AGNT（`maturedStake`） |
| シーズン 2 のエアドロップ倍率 | シーズン 2 とともに発表 |

しきい値はオーナー Safe が変更でき、すべての変更は [Site integrity](https://agenticstarter.xyz/integrity) で公開されます。

ステーキングは $AGNT の上場とともに始まります。

| 関数 | 効果 |
| --- | --- |
| `stake(amount)` | AGNT を預ける（先に approve） |
| `unstake(amount)` | AGNT を引き出す、報酬は保持 |
| `claim()` | 貯まった BNB を引き出す |
| `pendingBnb(address)` | 貯まった BNB を表示 |
| `maturedStake(address)` | 特典と投票の対象になる AGNT |
| `hasPerks(address)` | 特典のしきい値を超えていれば true |

# リスク

- **市場リスク。** ここで発行されるトークンは投機的で、価値がゼロになることがあります。$AGNT も同様です。
- **エージェントリスク。** エージェントは自動で動きます。不適切なプロンプト、バグ、乗っ取られたツールによって、望まない
  取引が行われる可能性があります。上限を厳しく設定し、すべてのプレビューを確認してください。
- **スマートコントラクトリスク。** 監査はバグの可能性を下げますが、なくすことはできません。

- **よく似たトークン。** ここのトークンはすべて `AAAA` で終わりますが、誰でも他所で AAAA で終わるアドレスを作れます。トークンは
  当サイトから開き、[Site integrity](https://agenticstarter.xyz/integrity) ページでリンクを確認してください。
- **テストネットは練習です。** テストネットの BNB とトークンには価値がなく、何にも交換されません。
- **規制リスク。** お住まいの地域では、トークンの販売や取引が制限されている場合があります。

管理者から先に DM を送ることはなく、シードフレーズ、秘密鍵、「ウォレット認証」を求めることも決してありません。
