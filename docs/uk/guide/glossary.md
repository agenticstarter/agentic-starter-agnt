# Глосарій

| Слово | Значення |
| --- | --- |
| **Адреса AAAA** | Кожен запущений тут токен має адресу контракту, що закінчується на `AAAA`. Це фірмовий знак, а не перевірка безпеки: завжди відкривайте токени з нашого сайту. |
| **Агент** | ШІ-програма, що діє за вас; тут вона запускає токени й торгує ними зі свого гаманця в межах ваших лімітів. |
| **Agent ID** | Посвідчення в гаманці агента. Потрібне для купівлі на бондинг-кривій. У тестнеті безкоштовне. |
| **Гаманець агента** | Окремий гаманець, яким користується агент, з лімітами витрат, щоб основні кошти були окремо. |
| **Аірдроп** | Безкоштовні $AGNT, які після сезону отримують відповідні гаманці пропорційно своїм балам. |
| **BNB** | Нативна монета BNB Chain. Нею платять за газ, і всі токени тут оцінюються в ній. |
| **BNB Chain** | Блокчейн, на якому працює Agentic Starter. |
| **Бондинг-крива** | Контракт, що продає новий токен за ціною з формули: кожна купівля піднімає ціну, кожен продаж знижує. Книга заявок не потрібна. |
| **Спалювання** | Надсилання токенів на адресу, яку ніхто не контролює, — вони зникають назавжди. |
| **Творець** | Гаманець, для якого запущено токен. До випуску отримує частку комісій кривої (або віддає її трейдерам як кешбек). |
| **Кешбек** | Варіант запуску: частина комісії кривої, що належала б творцю, повертається трейдеру з кожної угоди. |
| **Featured** | Місце в Explore, яке оплачується спаленням AGNT. Це реклама, а не відгук. |
| **Золота година** | Одна година на день, коли бали аірдропу рахуються вдвічі. |
| **Комісія кривої** | 1% від кожної купівлі й продажу на бондинг-кривій. Див. [Комісії](/uk/guide/fees). |
| **Кран (faucet)** | Сайт, що безкоштовно роздає BNB тестнету. |
| **Газ** | Невелика плата мережі за кожну транзакцію, у BNB. |
| **Genesis Creator** | Постійний значок для творців перших 100 токенів, що вийшли в мейннеті. |
| **Випуск (graduation)** | Момент заповнення кривої: токен переходить на PancakeSwap із заблокованою ліквідністю, крива закривається. |
| **Ignite** | Спалювання частини токена з публічним повідомленням. Див. [Ignite](/uk/guide/ignite). |
| **LP-токени** | Підтвердження частки в пулі PancakeSwap. Ми спалюємо їх під час випуску, тож ліквідність не можна вивести. |
| **Мейннет** | Справжня мережа зі справжніми грошима. |
| **PancakeSwap** | Найбільша біржа в BNB Chain. Там торгуються випущені токени. |
| **Пресейл** | Перший публічний продаж $AGNT до лістингу. Див. [Пресейл](/uk/token/presale). |
| **Сід-фраза** | 12 або 24 слова, що керують гаманцем. Ніколи нікому не повідомляйте. |
| **Прослизання** | Наскільки ціна може зміститися між попереднім переглядом і угодою, перш ніж угоду буде відхилено. |
| **Снапшот** | Момент, коли бали фіксуються й розраховуються частки аірдропу. |
| **Стейкінг** | Блокування $AGNT у контракті заради частки комісій у BNB. Див. [Стейкінг](/uk/token/staking). |
| **Тестнет** | Тренувальна копія BNB Chain, де BNB безкоштовний і нічого не вартий. |
| **TGE** | Подія генерації токена: день, коли $AGNT виходить на PancakeSwap і відкривається отримання токенів пресейлу. |
| **Ліміт на гаманець** | Максимум одного токена, який може тримати один гаманець, поки токен на кривій ({{P.mainnet.walletCapBps|pct}} у мейннеті, {{P.testnet.walletCapBps|pct}} у тестнеті). |
