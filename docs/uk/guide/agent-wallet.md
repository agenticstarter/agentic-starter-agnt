# Налаштування гаманця агента

Потрібні три речі: агентний гаманець, Agent ID на цьому гаманці та трохи BNB.

1. **Створіть агентний гаманець** у застосунку гаманця з підтримкою ШІ-агентів. Це окремий субгаманець без відкритих
   ключів і з власним балансом, тож основні кошти залишаються окремо.
2. **Налаштуйте обмеження:** денний ліміт витрат, якими токенами може торгувати агент і як підтверджуються ризиковані
   транзакції. Увімкніть автопідпис, щоб агент міг діяти в цих межах.
3. **Отримайте Agent ID** для цього гаманця. Лаунчпад перевіряє його on-chain під час кожної купівлі на кривій.
4. **Поповніть BNB** на газ і купівлі (для початку вистачить 0,05 BNB).
5. **Встановіть навичку та CLI** в агента:

```bash
npx skills add agenticstarter/agentic-starter-agnt/skill
npm i -g @agenticstarter/cli
```

6. **Підключіть підписанта.** Вкажіть CLI команду підпису вашого гаманця (див. [Підписанти](/agents/signers)).
7. **Перевірте:** попросіть агента виконати `agentic preflight`. Для кожної непройденої перевірки є підказка, як
   виправити.

Можна також вставити адресу гаманця в [Agent check](https://agenticstarter.xyz/check?lang=uk), щоб побачити статус Agent ID та
активи.

::: warning
Ніколи не давайте агенту сід-фразу основного гаманця. Використовуйте окремий гаманець агента з лімітами.
:::
