# Запуск токена

Скажіть агенту, що запустити, перевірте попередній перегляд і схваліть. Ось і весь процес.

```text
Launch a token on Agentic Starter: name "Nova Agent", symbol NOVA, description "Scouts fresh launches",
logo https://…/nova.png, X @nova_agent, and buy 0.2 BNB of it in the same transaction.
Show me the preview first and wait for my OK.
```

Агент виконує:

```bash
agentic create --name "Nova Agent" --symbol NOVA \
  --description "Scouts fresh launches" --logo https://…/nova.png --twitter @nova_agent \
  --telegram https://t.me/nova_agent --buy 0.2
agentic execute --request-id <id>
```

Перед попереднім переглядом CLI шукає сіль, за якої адреса токена закінчується на `AAAA`. Це займає кілька секунд.

На сайті форма запуску працює в три кроки. Напишіть одне речення про свою ідею й натисніть **Fill it in**, щоб отримати
назву, тікер і опис, які можна редагувати. Перетягніть логотип: його закріплюють в IPFS, а запит використовує посилання
`ipfs://` (у CLI те саме робить `--logo ./nova.png`). Потім оберіть, куди йдуть комісії творця, перевірте картку
попереднього перегляду й скопіюйте запит для свого агента. Симулятор кривої показує ціну й капіталізацію на кожному етапі.

| Поле | Обмеження |
| --- | --- |
| Назва | 1–32 символи |
| Тікер | 2–10 великих літер або цифр. Тікери на кшталт AGNT, BNB, BTC, ETH, USDT, USDC і CAKE зарезервовані |
| Алфавіт назви й тікера | Один алфавіт на назву, тож схожі літери з інших абеток відхиляються |
| Метадані (опис, URL логотипа, посилання) | зберігаються в блокчейні, до ~1 КБ |
| Логотип | URL `https://` / `ipfs://` або локальний PNG, JPG, GIF, WebP до 1 МБ (завантажується в IPFS) |
| Перша купівля | за бажанням, потрібен Agent ID, діє ліміт на гаманець |
| X | посилання або `@handle` (зберігається як нік) |
| Telegram | лише посилання `t.me` |
| Комісія запуску | {{P.mainnet.launchFeeBnb}} BNB у мейннеті, безкоштовно в тестнеті та для стейкерів AGNT з перевагами, плюс газ |
| Пара | BNB. Інші пари з’являться пізніше |

Токени не мають податку, функції мінту й власника.

## Куди йдуть комісії творця

| Варіант | CLI | Сайт |
| --- | --- | --- |
| Ваш гаманець запуску (за замовчуванням) | — | залиште поле гаманця комісій порожнім |
| Інший гаманець | `--fee-to 0xWallet:100` | поле **Creator fee wallet** |
| Розподіл, до 10 отримувачів | `--fee-to 0xA:60,0xB:40` | налаштовується на My tokens після запуску |
| Акаунт X або GitHub | `--fee-to 0xA:80,x:@alice:20` | налаштовується на My tokens після запуску |
| Кешбек трейдерам | `--cashback` | **Reward mode → Cashback** |

Частки для акаунтів чекають в ескроу, доки власник акаунта не підтвердить його й не прив’яже гаманець; незатребувані частки
повертаються творцю через 90 днів. Зміна розподілу діє через 24 години після пропозиції. Див.
[Комісії](/uk/guide/fees#creator-fee-options).

## Тестнет: запуск через Telegram-бота {#testnet-telegram}

У тестнеті BNB Chain можна запустити токен без налаштування агента. Наш бот Agen діє як агент і платить газ; ваш гаманець
записується як творець.

1. Відкрийте [Launch](https://agenticstarter.xyz/launch?lang=uk), підключіть гаманець, який володітиме токеном, і заповніть назву,
   тікер, логотип, опис і посилання.
2. Натисніть **Open in Telegram**. Бот відкриється з вашим кодом запуску й покаже попередній перегляд.
3. Натисніть **🚀 Launch now**. За кілька секунд бот надішле адресу токена, і токен з’явиться на сторінці Explore.

Якщо Telegram не відкрився, скопіюйте рядок `/launch ABCD2345` зі сторінки й надішліть боту. Коди діють 24 години й
працюють один раз. Кожен акаунт Telegram може запускати до 3 токенів на день.

Бот не купує за вас. Щоб купити, відкрийте сторінку токена, отримайте безкоштовний тестовий Agent ID і купіть за тестовий
BNB. У тестнеті токен виходить при **{{P.testnet.graduationTargetBnb}} BNB**.

## Після запуску

Далі сторінка запуску показує **набір після запуску**: готовий пост для X, текст для Telegram, зображення для поширення й
віджет для вашого сайту. На [My tokens](https://agenticstarter.xyz/me?lang=uk) можна:

| Дія | Подробиці |
| --- | --- |
| Стежити за прогресом | Прогрес кривої, зібраний BNB, власники |
| Забрати винагороди творця | 20% кожної комісії кривої за вашим токеном, у BNB, до випуску, плюс бонус за випуск |
| Оновити інформацію | Змінити логотип, опис і посилання за {{P.mainnet.metaUpdateFeeBnb}} BNB у мейннеті. Назва й тікер не змінюються ніколи. Власники бачать сповіщення 7 днів, уся історія лишається публічною. |
| Розподіл комісій | Запропонувати новий розподіл; він діє через 24 години |
| Передати роль творця | Запропонувати новий гаманець творця; він приймає роль на сторінці токена. Уже зароблені винагороди лишаються вашими. |
| Розподіл для творця | Де він застосовується (сьогодні в тестнеті), забрати розблоковану частину після випуску |
| Підтвердити X | Прив’язати акаунт X, щоб на сторінці токена був значок підтвердженого творця |

Творці перших 100 токенів, що вийшли в мейннеті, отримують постійний значок **Genesis Creator**.
