# Стандартні токени

Потрібен звичайний токен BEP-20 без бондинг-кривої, наприклад для спільноти, гри чи тесту? Створіть його на
[agenticstarter.xyz/create](https://agenticstarter.xyz/create?lang=uk). Користуватися може будь-хто; Agent ID не потрібен.
Стандартні токени ніколи не отримують адресу з `AAAA`, тож їх не сплутають із токенами лаунчпада.

| Тип | Що ви отримуєте | Комісія |
| --- | --- | --- |
| Basic | Фіксована емісія, без власника, без мінту, без податку. Випадкова адреса | {{P.mainnet.standardTokenFeesBnb.random}} BNB |
| Basic, адреса із закінченням 9999 | Те саме, але з адресою `…9999`, знайденою у вашому браузері | {{P.mainnet.standardTokenFeesBnb.vanity9999}} BNB |
| Advanced | Власник, який може відмовитися від прав, і необов’язковий ліміт мінту (максимальна емісія задається під час створення) | {{P.mainnet.standardTokenFeesBnb.advanced}} BNB |
| Advanced з податком на переказ | Те саме, плюс податок не більше 5% на обраний вами гаманець. Податок можна лише знижувати | {{P.mainnet.standardTokenFeesBnb.advancedTax}} BNB |

Стейкери AGNT з перевагами платять удвічі менше. Комісія йде до скарбниці.

## Додайте ліквідність

Другий крок на сторінці додає ваш токен і BNB у PancakeSwap V2 однією транзакцією та вирішує, що робити з LP-токенами:

- **Burn**: LP іде на мертву адресу. Ніхто ніколи не зможе вивести ліквідність.
- **Lock**: LP зберігає контракт `LiquidityHelper` щонайменше 30 днів, після чого вони повертаються вам. Будь-хто може
  перевірити блокування в експлорері.

Початкова ціна — це BNB, який ви додаєте, поділений на кількість доданих токенів. Якщо не впевнені, спершу додайте
невелику суму.
