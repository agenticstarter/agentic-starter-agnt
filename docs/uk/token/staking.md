# Стейкінг

Застейкайте $AGNT у контракті `AGNTStaking`, щоб отримувати BNB з комісій лаунчпада.

- Стейкери отримують **30% кожної комісії кривої** в BNB.
- Кожен BNB, що надходить, **розтягується на наступні 7 днів** і ділиться між усіма, хто в стейку протягом цього часу.
  Стейкінг безпосередньо перед виплатою її не захоплює.
- BNB, що надійшов, коли ніхто не стейкав, чекає й починає розтягуватися, коли приєднається перший стейкер.
- Без блокування: виводьте будь-коли; забирайте BNB будь-коли.

## Переваги

AGNT, які були в стейку **щонайменше 7 днів**, враховуються для переваг. Додавання AGNT перезапускає 7-денний відлік для
всієї позиції, тож переваги не можна купити на один блок.

| Перевага | Умова |
| --- | --- |
| Безкоштовні запуски на лаунчпаді | 100 000 AGNT у стейку 7 днів |
| Половина ціни на фабриці стандартних токенів | 100 000 AGNT у стейку 7 днів |
| Вага голосу в Snapshot | Будь-які AGNT у стейку 7 днів (`maturedStake`) |
| Множник аірдропу сезону 2 | Буде оголошено разом із сезоном 2 |

Поріг може змінити власник Safe; кожна зміна публічна на
[Site integrity](https://agenticstarter.xyz/integrity?lang=uk).

Стейкінг відкривається разом із лістингом $AGNT.

| Функція | Дія |
| --- | --- |
| `stake(amount)` | Внести AGNT (спершу approve) |
| `unstake(amount)` | Вивести AGNT, винагороди зберігаються |
| `claim()` | Забрати накопичений BNB |
| `pendingBnb(address)` | Переглянути накопичений BNB |
| `maturedStake(address)` | AGNT, що враховуються для переваг і голосувань |
| `hasPerks(address)` | True вище порога переваг |
