# Лістинг і використання коштів

$AGNT виходить на PancakeSwap V2 наступного дня після завершення пресейлу, о 14:00 UTC.

## Правило лістингу

| | |
| --- | --- |
| Ціна лістингу | Фінальна ціна пресейлу. Покупці пресейлу та перші покупці на ринку платять однаково |
| BNB у пул | {{P.presale.listing.bnbToPoolPct}}% усього зібраного BNB |
| AGNT у пул | 80% зібраного BNB ÷ фінальна ціна: {{P.presale.listing.maxPoolAgnt|n}} AGNT, якщо зібрано {{P.presale.floorCapBnb}} BNB або більше, 800 000 AGNT за BNB, якщо менше |
| Звідки беруться AGNT | З Liquidity Safe (150 млн) плюс до 50 млн із 60 млн резерву на лістинги. Непотрібні AGNT лишаються в Liquidity Safe |
| LP-токени | Спалюються на тому самому кроці. Ніхто не може вивести ліквідність |

Решта {{P.presale.listing.bnbToTreasuryPct}}% BNB іде до Treasury Safe.

## Зобов’язання щодо блокування

| Розподіл | Правило |
| --- | --- |
| Команда (120 млн) | Контракт вестингу: кліф 12 місяців, далі лінійно 24 місяці. Власник може лише відкласти початок |
| Скарбниця й екосистема | Жодних продажів на ринку до лістингу + 6 місяців |
| Ліквідність (Liquidity Safe) | Використовується лише для пулу й лістингів |
| Спільнота (Community Safe) | Використовується лише для аірдропів і раннього бонусу пресейлу |

Якщо будь-який проєктний Safe переказує AGNT на пару DEX, роутер чи відому депозитну адресу біржі, у каналі й групі Telegram
автоматично з’являється публічне сповіщення.

- Чекліст лістингу на сторінці пресейлу: Фіналізація → BNB додано в пул → LP спалено → клейм відкрито, кожен крок з
  транзакцією.
